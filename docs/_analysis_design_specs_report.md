# 设计文档体系分析报告（9 份文档结构化总结 + 总体评价）

## 一、各文档摘要

### 1. 模块化框架设计（08-15，已确认）
- **目的**：解决 13 个单体脚本互相直调、交互全压底部按钮区（20 商品=20 按钮）、代码生成 UI、加系统需改核心四大痛点；为商店/公会/任务/仓库/锻造等远期设施铺路。
- **核心决策**：四层单向依赖架构（表现→应用→领域→数据）；EventBus 类型化事件（日志也是事件、handler 异常隔离）；ServiceRegistry 显式注入可换假实现；「服务=无 UI 能力 / 设施=有 UI 交互壳」二分；设施=「定义 JSON+逻辑类+UXML」三块积木，工厂+注册表+地点挂接索引装配，新增零改核心；UI Toolkit 铁律（禁代码 new 元素，只克隆模板+赋数据+订阅）；按钮区专属剧情选项、其余全面板化；ViewManager 导航栈≤3 层。
- **实现细节**：`文字RPG.*` 命名空间临时隔离旧代码（M6 后转无 namespace）；`facilities.json` 字段（标识/逻辑类型/视图/数据/地点）；`IFacility`（进入/退出/刷新/导出状态）；`IFacilityState` 存档片段；v1=迁移商店/训练场/任务板/酒店+新增仓库/种植。

### 2. 角色系统设计（08-16，待实现）
- **目的**：为装备/锻造打底，建立完整成长链。
- **核心决策**：4 大属性+升级自由加点（每级+3）；**品质 6 档横切**（普通×1.0→传奇×3.0，物品/技能通用）；技能多途径获取但**统一属性达标校验**；熟练度 1~5 级（每级 +10% 伤害/−5% 消耗，训练 30×N 金）；训练场改「属性+熟练」双修。
- **细节**：派生公式（生命=20+体力×5+等级×5）；`已学技能` 改 `List<技能掌握>`；角色面板四区（属性/加点/装备/背包）全局可开；战斗改物理/魔法分流、暴击×1.5、闪避。范围外：品质掉落分布、武馆 UI、旧档兼容。

### 3. 地图编辑器设计（08-16，待实现）
- **目的**：告别手改 map.json，场景视图可视化编辑大/小地图并反向导出。
- **核心决策**：纯 Editor 工具不改运行时；三组件围绕**内存副本**协作（`地图编辑数据`/`地图设计器窗口`/`地图设计器场景绘制`）；覆盖保存+`.bak` 单份备份；0-100 归一化坐标与运行时 `地图渲染.归一化` 互逆。
- **细节**：场景 Handle 拖圆盘改位置、A→B 拖放建双向连接（去重）、右键删节点并清理悬挂连接；窗口=层下拉+属性表单+增删保存。不做撤销/热编辑/强制校验。

### 4. 三级导航设计（08-16，待实现）
- **目的**：补「设施内部」中间层，替代设施直达。
- **核心决策**：大地图→小地图→设施内部图；设施内部=节点图（NPC+功能物），复用地图面板基类；**对话面板从主视窗剥离**（主视窗只留战斗/探索/结局）；功能接口（教学/买卖/训练/恢复/睡觉）跨设施复用。
- **细节**：`facilities.json` 扩展 `NPC[]`/`内部节点[]`（类型/功能/x,y 0-100/连接/剧情节点）；双击 NPC→对话、双击功能物→功能面板；新增 `打开设施内部事件`。范围外：随机任务、NPC 随机对话、睡觉时间推进。

### 5. 功能面板重设计（08-17，逐面板进行）
- **目的**：破除「通用按钮行+创建行」单一形态锁死内容。
- **核心决策**：基类瘦身（只留上下文/标题/返回/`回退()`，子类自定义 `渲染内容()`）；**每面板=场景手工专属结构+Inspector 拖拽绑定**（不用路径字符串）；行模板化；一次只做一个面板。
- **已实现**：商店买卖面板（购买/卖出共用列表+4 键排序+详情区）、角色面板（薄编排器+`属性子面板`静态引用+`装备背包子面板` 8 槽+分类 Tab）、对话打字机、侧边栏系统面板（取消/设置/音量/存档/暂停/角色，`回退()` 改 bool、取消文本动态、按钮图标化）、**三进制经济**（内部铜币存储、JSON×10000）、探索面板。**待设计**：训练/教学/任务/恢复/睡觉面板。

### 6. 探索系统设计（08-17，已实现）
- **目的**：闯关式野外面板升级为深度分层区域。
- **核心决策**：每区 5 层+Boss 底层；搜索阈值（默认 3）满后掷通路概率（0.5）解锁「深入」；HP/MP 带入不恢复制造「再搜 or 见好就收」张力；通关标记存档案、可再刷但 Boss 不再出现；岔路层（安全/危险）。
- **细节**：`regions.json` 重构为 `层[]`（事件表=遭遇/资源/发现/无事，岔路，Boss 组）；`探索服务` 状态机（进入/选岔路/搜索/深入/返回）；探索面板=信息条+正文+动作区。内容规划 3 区域，**古战场 regions 数据缺失需补**。

## 二、总体体系评价

**一致性**：高度自洽。数据驱动 JSON（全中文字段）贯穿所有文档；「逻辑永不调 UI、事件驱动刷新」从框架 spec 贯彻到角色/探索/主线；uGUI「面板基类+Inspector 拖拽绑定」风格统一（商店/角色/探索/侧边栏同一套）；0-100 归一化坐标贯通地图编辑器与设施内部节点；设施「三块积木」理念延伸为功能接口跨设施复用。

**贯穿理念**：①数据即积木（新内容=新 JSON 零代码）；②交互面板化（按钮区只留剧情）；③场景手工搭建+代码仅填数据/订阅（拒绝代码生成 UI 与路径字符串查找）；④领域层纯 C# 可 EditMode 测试；⑤中文命名、显式依赖、YAGNI（明确不做清单）。

**设计变更轨迹**：UI Toolkit→uGUI（M2 被否，里程碑记录防绕回）；两级导航→三级导航（设施直达→设施内部图）；闯关式野外面板→深度分层探索；通用按钮行→面板专属结构+行模板；金币→三进制铜币；单体脚本→服务/设施四层架构；装备系统从无到 8 槽+品质横切；主线从节点链→阶段状态机+自动剧情路由。

**待办/未实现**：地图设计器全套（计划未执行）；训练/教学/任务/恢复/睡觉面板待设计；武馆 UI、品质掉落分布、随机任务、NPC 随机对话、睡觉时间推进、技能收费启用、图标网格增强、旧档兼容均挂起；古战场 regions 数据缺失、大草原空壳占位待补；UI Toolkit 数据绑定与中文字体为记录在案的风险。
