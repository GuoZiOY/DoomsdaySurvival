# 文字奇幻 RPG 内容数据层分析报告

> 分析对象：`Assets\Resources\Data\` 下 13 个 JSON（键名均为中文）。引用完整性经 PowerShell 解析逐项程序化校验 + 人工复核。

## 一、各文件结构骨架

| 文件 | 顶层键 | 数组元素关键字段 |
|---|---|---|
| story.json | 区域剧情 / 节点 | 节点：标识、文本、选项[{文本,目标,效果,需要物品}]、效果、下一节点、主线阶段；区域剧情：区域、阶段、节点、需要任务 |
| map.json | 地点 | 标识、x/y、类型(城镇/荒野)、区域、入口节点、目标、解锁物品/阶段、连接、小地图[标识、设施、内部[类型(设施/NPC/功能物)、剧情节点、连接]] |
| regions.json | 区域 | 标识、危险度、层[编号、描述、事件表{遭遇/资源/选择/发现/无事文本}、岔路{安全/危险}、Boss、通关后] |
| enemies.json | 敌人 | 标识、五行属性、物理弱点、生命/攻击/防御/魔防/速度、等级、目标策略、行动表[{行动,权重,条件}]、抗性、货币/经验奖励、掉落物品+概率 |
| items.json | 物品 | 标识、类型(食物/材料/药剂/战斗/技能书/武器/防具/宝石/饰品/图纸/任务)、价格、品质、恢复量、战斗内使用、挂载Buff、技能、指定词缀属性、槽位+攻击/防御/生命加成 |
| quests.json | 任务 | 标识、章节、目标类型(主线阶段/击败/获得物品)、目标标识、目标数量、奖励金币/经验 |
| skills.json | 技能 | 标识、消耗魔力、类别(攻击/增益/治疗/减益/净化)、目标、伤害类型/方式、派系、五行属性、数值、挂载Buff、价格、品质、需要属性、熟练度字段 |
| buffs.json | Buffs | 标识、类型(增益/减益/异常)、属性、数值、持续回合、最大层数、控制 |
| affixes.json | 词缀 | 标识、品质(普通→传奇)、属性、最小/最大、权重 |
| recipes.json | 配方 | 标识、产物、产物数量、材料[{物品,数量}]、类型(食物/药剂/装备)、图纸 |
| encounters.json | 敌人组 / 助战组 | 敌人[{敌人,数量}] / 成员[{标识,数量}] |
| facilities.json | 设施 | 标识、逻辑类型(商店/训练场/任务板/武馆/学堂/家/制作)、数据、地点 |
| training.json | 训练项目 | 标识、属性(力量/体力/智力/敏捷)、加成、花费 |

## 二、内容盘点

- **剧情**：85 个节点 + 6 条区域剧情入口。**主线链路**：序章_醒来→（可选 查看四周/检查伤口/休息）→序章_走出石屋→灰烬镇→第一章_镇口卫兵(待见镇长)→镇长府→第一章_出发(穿越橡木林)→[区域剧情]穿越_遇袭→战斗:穿越遇袭组→危局→老李救场→抵达风谷村→[区域剧情]村中_呼喊→小烛遇袭→战斗:村外魔物组→老李认可(特训，学横扫斩/蛇咬之刺/猎人直觉)→特训结束→(村中支线)→[区域剧情·需支线_粗麻绳]深入_出发→巡逻遭遇→战斗:哥布林巡逻组(助战老李)→部落→撤退→断后→战斗:哥布林侦查队→独行→桥通回镇→[区域剧情]骑士团_出发→幻影→记忆碎片→女主同行→[区域剧情]决战_进入→杂兵→战斗:哥布林杂兵组(助战小烛)→地下室→圣剑→王前→战斗:哥布林王战组(决战助战队)→胜利→终章(第一章_完成)。**分支**：序章三选一、村中呼喊双路、镇长府出示羊皮纸(需物品)、结局分支（点燃圣火/屠龙，均不可达）。**死节点**：酒馆_购买、酒馆_防具、哥布林胜利、研究羊皮纸、镇长府_交差（无入边）。
- **地图**：6 地点（灰烬镇、风谷村为城镇带小地图，共 19 个小地图节点；橡木林/古战场/黑石山/大草原为荒野）；4 区域各 5 层，Boss 依次为野猪王、亡灵骑士、幼龙、狼王。
- **敌人**：29 个（26 普通 + 3 助战 NPC），Lv1-6；物理弱点按武器种类（剑/斧/锤/匕首/弓）分布，五行属性覆盖金木水火土。
- **物品**：140 个——防具 38、材料 27、食物 25、武器 17、药剂 10、宝石 9、战斗 4、任务 4、图纸 3、饰品 2、技能书 1。
- **任务**：14 个（7 主线章节任务 + 7 支线：杀魔物、采药、修桥三件套、清营地、猎狼）。
- **技能**：20 个（玩家 13 个含五行术法，敌人专用 7 个）；**Buff** 10 个；**词缀** 46 个（6 品质 × 属性阶梯）。

## 三、数据引用关系

- **story→map**：`地图:灰烬镇/风谷村/小地图/大地图`；小地图 NPC 的"剧情节点"直接指向 story 节点。
- **story→regions**：`区域:橡木林/古战场/黑石山`、`探索:橡木林/黑石山`；regions 的"发现"事件指向 story 地点节点（废弃猎屋、精灵泉水、古树洞窟、旧军营、龙巢）。
- **story→encounters/enemies**：`战斗:<遭遇组>:<胜利节点>[:<助战组>]`，8 处战斗全部命中。
- **story→items**：`购买:治疗药水/木剑/铁剑/皮甲/链甲`、需要物品（龙之羊皮纸、骑士团指令、麻绳）、获得/失去物品表。
- **story→quests/skills**：效果"接取任务/学习技能"；quests 的"主线阶段"目标标识 ↔ story 节点的"主线阶段"字段一一对应；"击败/获得物品"目标指向敌人/物品 id。
- **enemies→skills/buffs**：行动表技能（重击、撕咬、骨刺、灼烧吐息、小治愈术等）、抗性表；技能→挂载 Buff（防御架势、蛇毒、灼烧、中毒、防御削弱等）全部存在。
- **items→skills/affixes/buffs**：技能书→技能；宝石→词缀属性（攻击/魔攻/防御/生命/抗性/暴击/命中/闪避/速度）；战斗消耗品→Buff。
- **recipes→items**：67 配方产物/材料/图纸全部存在；设施"数据"（装备/食物/药剂）过滤配方类型。

## 四、内容质量评价

- **主线完整度**：第一章为完整闭环（序章→决战→终章，剧情量扎实，含人物弧光与伏笔）。
- **引用断裂**：程序化校验全库仅 **1 处**——story「第一章_村医_对话」接取任务 `支线_采集草药` 不存在（应为 `支线_采集止血草`），会导致接受空任务。
- **结构性风险**：`龙之羊皮纸` 仅由死节点链（哥布林胜利→研究羊皮纸→镇长府_交差）发放，而黑石山解锁正依赖它 ⇒ **龙巢剧情与双结局（圣火重燃/弑龙者）在当前剧情图中实际不可达**；大草原仅第一章完成后开放，属后日谈性质。
- **数值**：敌人曲线合理（Lv1 巨鼠 8 血/攻 3 → Lv6 沉睡之龙 80 血/攻 17、哥布林王 72 血）；奖励曲线（巨鼠 35 金→Boss 2.5-8 万金）陡但可接受；治疗药水 300 金/回 18 与酒馆"3 银"一致，但死节点文案中木剑 5 银/铁剑 25 银/链甲 80 银与 items 价格（300/8000/15000）不符；**合成食物定价（7000-13000）远超治疗药水（300）且恢复量更低，性价比倒挂**，经济系统需复核。
- **规模与文档**：140 物品/67 配方体量充足；项目内**未发现 README/GDD**（仅 Library 插件自带文档），无法与设计文档比对。

## 五、世界观与叙事

- **世界设定**：故事发生在"余烬/灰烬镇"——被废墟围裹的老镇，守护"圣火"的守火人一族千年前在北方战争中陨落，圣火熄灭；巨龙吞下最后火种沉睡于黑石山，等待继承者。古战场埋着守火人历"余烬不灭，火种西撤"的军令；亡灵骑士执念"我仍在守，但火已熄"。
- **主要 NPC**：镇长巴隆、老猎人李叔（老李）、女主小烛、骑士团长韩如炎、村医林杏、独眼老板娘、铁匠老铁、厨娘翠嫂、药师徐半仙、武馆陈武、学堂慧明。
- **主题**：火种不灭、传承与责任；"龙不会死，它只是在沉睡，火必须被重新点燃"贯穿全局；双结局（点燃圣火 vs 弑龙）预留了叙事抉择，但需先修复可达性。

**修复优先级建议**：① quests 补 `支线_采集草药` 或 story 改引用；② 为 `龙之羊皮纸` 增加可达获取途径（如村长府委托或哥布林营地掉落）以解锁黑石山结局；③ 清理死节点或接回剧情；④ 复核合成食物定价与酒馆旧文案价格。
