## 架构演进轨迹

```
M1 框架 → M3 服务 → M4/M4B 设施+战斗+探索 → MA/MB 地图导航
        ↘  M2 UI Toolkit 被否（改走 uGUI）  → 面板基类/面板管理器
        ↘  地图设计器（编辑器可视化编辑地图 JSON）
        ↘  三级导航（大地图→小地图→节点内部）取代早期两级+设施直达
        ↘  探索系统（深度分层区域）取代早期闯关式野外面板
```

## 关键设计转向（记录为什么，避免绕回）

1. **UI 技术栈**：UI Toolkit 方案被否，全程 uGUI——面板基类 + Inspector 拖拽绑定 + 事件路由，**不用路径字符串查找**。
2. **主视窗定位**：从"共用内容面板"改为"纯容器"——对话/战斗/探索等专属面板放其内，由面板管理器路由切换。
3. **导航层级**：从"大地图→小地图→设施直达面板"演进为三级导航 + 节点内部图（任意节点可有 NPC/功能物）。
4. **野外面板**：从"闯关式"升级为"探索系统"（深度分层区域，见 specs/探索系统）。
