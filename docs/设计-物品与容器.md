## 一 物品通用口径（8 条，全部物品共用）

| # | 口径 | 规则 |
|---|---|---|
| 1 | **品质倍率** | `品质工具.倍率` = 普通1.0 / 优秀1.2 / 稀有1.5 / 史诗1.8 / 英雄2.2 / 传奇3.0。**同槽位同类的数值按此拉开**（该倍率真的参与恢复量与技能伤害计算） |
| 2 | **价值 = 稀缺 + 效用** | 手工自制 < 民用 < 工装/户外 < 安保 < 警用 < 消防 < 军用 < 实验级。**数值高的一定不便宜**（修掉"土制火枪 攻15 价12"） |
| 3 | **重量 = 现实手感** | 匕首/布1 · 菜刀/警棍2 · 钢管/撬棍3 · 消防斧4 · 步枪/防弹衣5~6 |
| 4 | **耐久 = 材质** | 木 15~25 / 民用金属 25~35 / 军警 40~60 / 实验级 70~120。`0` 只表示"这类东西没有耐久概念"（弹挂/腰封/部分背包） |
| 5 | **近战三型（攻速 ↔ 伤害反向）** | **快·低伤**：攻速 **+4~+6**、伤害 4~6；**均衡**：攻速 **0~+2**、伤害 6~9；**慢·高伤**：攻速 **−2~−4**、伤害 8~13。品质与稀缺度可以打破基线（`武士刀` = 又快又重的稀有例外，代价是价格 26 与只能搜刮） |
| 6 | **近战射程 = 形态维度（短兵 1 / 长柄 2）** | 长柄武器（真实长度 ≥1.5m）**`攻击距离 = 2`**，可以隔一格打：`长木棍 · 草叉 · 自制长矛 · 撬棍 · 钢管`。代价是 **攻速 −1**（挥动幅度大、笨重）。**近战/远程不由 `攻击距离>1` 判定，改由 `武器种类` 判定** —— 已落地：`Assets/Scripts/Data/数据模型.cs` 的 `武器种类判定` + `Assets/Scripts/Data/配件槽.cs` 的按种类分槽（枪械 / 弓弩 / 近战 / 防具插板） |
| 7 | **防具取舍** | `潜行加成 = −重量×3`；`移速加成` 只出现在**脚部（轻便鞋 +1~3）与重甲（−1~−6）**，头盔/手套/护腿不再给正移速（装甲不会让人跑更快）；`抗性` 消防 15 · 军用 5~10 · 防暴 10 · 棉袄 10；`负重加成` 只给 弹挂 +5~10 · 腰封 +3~5 · 背包 +10~35 |
| 8 | **现实红线** | 自制件一定低耐久低精度；军用/警用/消防/战术款**只能搜刮**、不进配方；不出现"防弹斗篷"这类；弓弩**无声**（给潜行加成）是唯一允许的"隐性优势" |

> 两条**逐类专项口径随逐件表走**，见 `docs/数据-物品清单.md`：
> · **腐坏**：现做熟食 8~36h / 风干腌渍 720h / 生鲜 72h / 密封·干燥·酒水 = 0（明确不腐坏）。

## 二 堆叠规则（网格背包）

> 状态：**已实现**。判定与执行在 `Assets/Scripts/Domain/网格/网格服务.cs`；上限值在 `items_*.json`。

### 2.1 核心原则

**不是所有同种物品都能合并。** 每个物品在 `items_*.json` 显式定义 `堆叠上限`：

- `堆叠上限 > 1` → 可堆叠（同格合并，受上限约束）
- `堆叠上限 = 0/缺省/1` → 不可堆叠（每格恒为 1 件独立实例）

判定入口（领域层，纯 C#）：

| 方法 | 作用 |
|------|------|
| `可堆叠(标识)` | 该物品是否允许合并（上限 > 1） |
| `堆叠上限(标识)` | 单格堆叠上限（0 = 不可堆叠） |
| `可合并(目标, 来源)` | 两堆叠能否合并（拖拽投影蓝/绿判定） |
| `合并堆叠(目标, 来源)` | 执行合并，返回实际并入数（受上限限制） |
| `放入网格(标识, 数量)` | 加入背包：**先填已有未满堆叠，满额再开新堆叠**，返回实际放入数 |
| `放入网格堆叠(堆叠)` | 把已有堆叠实例（带配件的装备/掉落/换装回包/旧存档迁移）放入网格找空位 |
| `拆分(源, 拆出数量)` | 拆出独立新堆叠（同标识/旋转/耐久/品质/配件），自动找空位；无空位返回 null |

### 2.2 各类别堆叠上限（定稿）

| 类型 | 堆叠上限 | 理由 |
|------|:---:|------|
| 武器 | 1（不可） | 独立实例：品质/耐久/配件，一把刀 = 一件 |
| 防具（含背包类） | 1（不可） | 同上，装备实例不合并 |
| 弹药 | **100** | 子弹大量携带 |
| 食物（面包/罐头） | **20** | 消耗品可叠但有限 |
| 水 | **10** | 瓶装水占重 |
| 医疗品（绷带/医疗包/急救包） | **10** | 消耗品可叠但有限 |
| 材料（木板/胶带/零件/调料） | **50** | 制作消耗量大 |
| 任务品 | 1（不可） | 任务道具独立（相机/记事本/教科书） |
| 技能书 | 1（不可） | 学了即消耗 |

> 逐件实际上限以 `items_*.json` 现值为准（本文只定"按类别"的口径）。

### 2.3 合并条件（全部满足才可合并）

1. 标识相同；
2. 双方都可堆叠（上限 > 1）；
3. 目标未满（目标.数量 < 上限）；
4. **双方均无配件** —— 配件（**改装件**）是装备上的真实物品实例，绝不并入普通堆叠；
5. 品质覆盖相同（两者品质覆盖都为空则忽略该条件；防止"合成提升过的"与普通混叠）。

> 第 4 条原文写的是"双方均无**词缀**"：**词缀系统已按拍板删除**，改成**配件/改装件**（真实物品、占背包格、有重量、可拆卸，效果来自物品数据自己的加成字段）。合并口径不变 —— **带配件就不合并**。

### 2.4 交互（网格背包面板）

- **拖拽到同标识堆叠** → 自动叠入（淡蓝投影提示"可合并"）；超出上限的余量留在**原格**。
- 投影颜色：淡蓝 = 可合并 / 淡绿 = 可移动、可换位 / 淡红 = 不可。
- 详情面板：可堆叠物品显示 `堆叠 x/上限`；不可堆叠显示 `数量 x`；拖拽代理标签带 `×数量`。
- 数量拆分走右键「拆分」（滑条/输入数量），落点无空位时不拆。

### 2.5 放置路径统一（网格即背包）

所有"获得"路径统一走网格：开局物资 · 战斗掉落 · 换装/卸下旧装备回包（背包满 → 回滚换装）· 制作产物 · 任务奖励/日常/效果结算/购买 · 旧存档迁移（`列<0` 的堆叠重新入格）。

`放入网格` 返回**实际放入数量**（背包满时部分放入），调用方据此提示"背包已满"。

### 2.6 品质着色（网格底座）

**架构约定：品质色永远属于"物品框层"，不属于内容层。** 物品框（全尺寸 Image，点击/拖拽挂这里）铺品质底层色；内容层（内缩 6px 的 Image）现在放深色占位块，将来贴美术图 —— **加图零改动，品质色不丢**（图片四周露出品质色环）。

- 色板复用 `品质.cs`（普通灰白/优秀绿/稀有蓝/史诗紫/英雄橙/传奇红），与列表/日志一致。
- 有效品质 = `堆叠.品质`（合成覆盖）优先，否则模板品质档。
- 拖拽代理：非普通 = 品质色（α0.85），普通 = 内容层色。

## 三 容器（塔科夫式嵌套容器）

> 状态：**已实现**。领域层 = `Assets/Scripts/Domain/容器/容器服务.cs`；UI = `Assets/Scripts/UI/物品/面板/容器面板.cs`。

**容器（Container）= 一个有内部网格空间的物品。** 容器本身是网格里的一格物品，**双击打开**显示内部网格，可往里放东西；容器随物品存档。穿戴容器（弹挂/腰封/背包）也是容器（装备记录的 `容器物品` = 其内容）。

**复用原则**：容器内部就是"迷你网格背包"，完全复用 `网格服务` 的网格机制（可放置/移动/换位/堆叠/布局安全/区域互换），不另造轮子。**家具容器（冰箱 等）与物品容器共用同一套 `容器服务` + `网格服务`** —— 网格承载与算法只有这一份（主背包 / 仓库 / 容器内部 / 穿戴容器 / 安全屋家具 各持一个 `网格服务` 实例，都走它）。

### 3.1 已确认的设计决策

| # | 决策 | 定稿 |
|---|---|---|
| 1 | 负重 | 容器内物品**计入玩家负重**（递归累加：穿戴容器 + 各容器内部；仓库不占负重） |
| 2 | 嵌套深度 | **2 层**：背包 → 容器（第1层）→ 容器（第2层）；第 2 层容器内**不能再放容器** |
| 3 | 容器容量 | **各容器模板固定**容量（数值在 `items_*.json`）；不随背包装备变化 |
| 4 | 打开交互 | **双击打开**；UI 上额外生成一个独立容器面板（可拖动位置，塔科夫式），可与主背包互相拖拽 |
| 5 | 容器堆叠 | 容器类物品**不可堆叠**（每格一个实例，含独立内部内容） |
| 6 | 跨网格转移 | 主背包 ↔ 容器、容器 ↔ 容器，**统一走 `容器服务.跨网格转移` 一个函数** |
| 7 | 关闭容器 | 关闭只丢弃视图，**数据仍在**容器的 `容器物品` 里，随物品存档（重开即复原） |
| 8 | 存档 | `容器物品` 被 `JsonUtility` 自动序列化 → 容器内物品随外层堆叠**递归存档**，`SaveService` 零改动；旧档 `容器物品 == null` = 非容器 |

### 3.2 数据模型

```csharp
// 物品数据（模板，items_*.json 配置）
public bool 是容器;              // 背包/弹药箱/医药箱/保险箱...
public int 容器列 = 0;           // 内部网格列数（0 = 非容器）
public int 容器行 = 0;
public string 容器允许类型;       // 可选：仅允许某类物品进入（"弹药"/"医疗"…）；空 = 任意

// 物品堆叠（领域/存档）
public int 容器列 = 0;                  // 实例网格尺寸（缺省用模板）
public int 容器行 = 0;
public List<物品堆叠> 容器物品 = null;   // 容器内部物品；null = 非容器/空容器
```

> `容器物品` 与 `网格服务.网格物品` 完全同构（都是 `List<物品堆叠>`）→ 数据结构上可无限嵌套（运行时限制 2 层）。

### 3.3 跨网格转移（核心 API）

```csharp
// 容器服务：从 源网格 把 堆叠 移到 目标网格 的 (列,行)。返回 0 = 失败；>0 = 转移数量。
public int 跨网格转移(网格服务 源, 物品堆叠 堆叠, 网格服务 目标, int 目标列, int 目标行)
```

- 每个可拖拽网格 = 一个 `网格服务` 实例（主背包 / 容器打开后的视图 / 穿戴容器视图 / 仓库视图）。
- **物品堆叠的 列/行 永远是"所在网格的局部坐标"** —— 各视图各持自己的 `网格物品` 列表，坐标天然不冲突。
- 分支：① 目标格同标识可合并 → 部分或全部并入（余量留源）；② 目标格可放置（排除自身）→ 源移除、写入目标坐标；其余情况返回 0。
- **类型限制**（目标容器 `容器允许类型` 不符）与**嵌套限制**（自己套自己 / 循环引用 / 超套娃上限）在拖拽落地前由调用方拦（面板的 `允许放入` / `禁放入` 校验 + `容器服务.允许放入`）。
- 拖拽流程：拖起记 `(源网格服务, 堆叠)` → 拖动代理跟随鼠标 → 放下时算落点面板：**同面板**走原逻辑（移动/换位/合并），**跨面板**走 `跨网格转移`。跨网格移动的是**整个堆叠对象**（保留配件/耐久/品质/容器内容实例）。

### 3.4 现有容器（模板值）

- `弹药箱` 3×3（只放弹药）· `医药箱` 4×4（只放医疗）· `工具箱` 3×3（任意）—— 数值在 `Assets/Resources/Data/物品/items_容器.json`。
- 穿戴容器（弹挂/腰封/背包）各自有固定内部网格；**家具容器**（冰箱 等）走 `容器服务` 的家具分支，容量按家具等级取。
