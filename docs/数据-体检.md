## 二 设计层体检

### 2.1 装备的取舍已经成立

- **近战三型**：快·低伤（匕首 攻4/攻速+6/暴击+5/**潜行+6**）· 均衡（狗腿刀/砍刀/武士刀）· 慢·高伤（木斧 攻8/耐久18、消防斧 攻13/命中−2/**潜行−9**）
- **长柄 5 件射程 2**（长木棍/草叉/自制长矛/撬棍/钢管），代价 攻速 −1；引擎口径为**按 `武器种类` 判近战/远程**，`攻击距离` 只表射程
- **弓弩无声**：猎弓/复合弓/十字弓/手弩 潜行 **+8~+10**
- **移速去伪**：头盔/手套/护腿上的 `+2` 一律改 0，正移速只留脚部轻便鞋，负移速给重甲（防弹背心 −4 / 动力甲 −6）
- **土制火枪** = 真正的自制枪：攻 12 · 命中 −10 · 弹匣 1 · 耐久 15 · 价 26（单发、精度极差、易坏，但近距离一枪很重 —— 与手枪 攻8/弹匣12/价20 形成取舍）

| 情报系统 | 5 件情报物品现在当**区域解锁钥匙**（功能已落地）；"使用后得情报"要情报系统 → 剧情不做，搁置 |
| 物品落点冗余 | 门禁里没有「物品出现在 ≥2 个容器」这一条（见 §1.4） |
| 临时建筑不许漏战力 | 门禁里没有「临时建筑的敌人组不许掉书/史诗装备」这一条 |
| 技能"专向/弱向" | 字段与代码**都有**，但 `武器种类` 0 件有值、`武器规则` 全"通用" → 死代码（纯数据可修） |
| 道具挂 Buff | 字段与读取方**都有**，`使用效果`/`挂载Buff` 0 件配值 → 死代码（纯数据可修） |

### 2.8 口径债与命名债

1. **`货币奖励` 语义漂了** —— 实际是"补给值"（`BattleService.伤害与结算`：面包 = 补给/4、水 = 补给/8）。建议改名为 `补给值`。
2. **`解析属性()` 默认返回"体质"** —— 已用门禁（天赋目标口径校验）兜住，但代码本身仍是"写错就静默"。
3. **两套"速度"口径并存**：`buff.属性` 里速度只能写"敏捷"（门禁守着），而 `物品数据.速度加成` 是独立字段。
4. **`套装` 字段：47 件有值、全仓库 0 个读取方** —— 按拍板**保留为预留**。
5. **`容器形状掩码`：0 件在用** —— 旧兼容字段，留着无害。
6. **`容器允许类型` 只 2 件配值** —— 弹药箱/医药箱这类限制型容器很少，其余容器"任意"。
7. **区域解锁口径**：居民区/西区开局可达；商业区=`城市地图`、东区=`旧地图`、医院区=`账本`、警察局区=`机密文件`、
   工厂区=`相机` 且 ≥10 天（终局区双门槛）—— 让「搜刮 → 拿到线索 → 敢去新区域」成为主循环。
