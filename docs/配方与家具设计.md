## 〇 审计先逮到 3 个真问题（当前版本就存在）

### ★ 问题 1：**`医药箱` 零来源 → 医疗站根本建不出来**（活 bug）

`医疗站.建造` 要 `医药箱×1`，而 **`医药箱` 在搜刮表里出现 0 次**（脚本核实）。

## 一 制作配方（62 → 67 条）

### 1.1 成本比口径改为**按类别分档**（原"一刀切 0.6~1.6"会误伤"

| 类别 | 允许区间 | 理由 |
|---|---|---|
| 装备类（武器 / 防具 / 医疗 / 容器 / 配件） | **0.6 ~ 1.6** | 不能比搜刮还划算，否则没人出门 |
| 弹药 / 材料加工 / 饮食 | **0.4 ~ 1.6** | 花**时间 + 精力**换材料，本就该略赚 |

## 二 家具建造 / 升级配方（11 件）

### 2.1 三条硬规则

1. **建造材料必须"开局就能凑"**（木板/钉子/金属零件 可造，铁皮能搜到）—— 否则第一个制作站就卡住。
2. **升级材料才逐步引入功能件**（电子/电力/贵金属/日用品）—— 让"搜到的杂物"有去处。
3. **禁止循环**：家具的建造/升级材料，不许是"需要这台家具本身（或更高等级）才能做出来的东西"。

## 三 链路审计结论

### 3.1 唯一"必须靠搜刮"的关键料 = `铁皮`（**有意的节奏设计，不是漏洞**）

`制作_铁皮` 需要 **工作台 Lv2**，而 工作台/灶台/冰箱/净水器 的**建造**都要铁皮。
→ 玩家必须**先搜到铁皮**才能起步。搜刮里铁皮有 **7 个容器**（工厂/五金店/街区…）→ 够。
**这条要写进文档**：铁皮 = 前期最重要的搜刮目标。

### 3.2 修掉 2 处循环

| 循环 | 修法 |
|---|---|
| 医疗站 升2 要 `医用医疗包`（需 Lv3 医疗站） | 升2 材料改成 `医用绷带×2`（Lv2 可制） |
| 灶台 建造 要 `铁锅`（1 个容器 + 硬门） | 铁锅移到 **升1**，并同时作为"煮类配方的工具" |

### 3.3 补单点依赖（家具要的关键件只有 0~1 个容器）

| 物品 | 现容器数 | 目标 | 加到哪里 |
|---|---|---|---|
| **医药箱** | **0（零来源！）** | **3** | 医院/急诊·医院储物柜 · 药店/后间·药品柜 · 医院/药房·精麻药柜 |
| 收音机 | 1 | 3 | 居民房/客厅·电视柜（已有）+ 警察局/接待·值班台 · 医院/病房·病床柜 |
| 铁锅 | 1 | 3 | 居民房/厨房·橱柜（已有）+ 便利店/库房·货架 · 工厂/办公室·更衣柜 |
| 碗 | 1 | 3 | 居民房/厨房·调料架（已有）+ 便利店/货架 · 学校/食堂（刀58 新增） |
| 牙膏 / 牙刷 | 各 2 | 各 3 | 居民房/洗浴间·洗手池柜（已有）+ 医院/病房·病床柜 · 工厂/办公室·更衣柜 |
| 毛线团 | 2 | 3 | 居民房/卧室·衣柜（已有）+ 居民房/杂物间 · 工厂/办公室·更衣柜 |

### 3.3b ★ 奢侈品 = 交易硬通货（**不做配方材料、不做家具材料**）

按拍板：`贵重物品` 8 件（金币 · 金表 · 金项链 · 银戒指 · 钻戒 · 玉镯 · 珠宝项链 · 古董怀表）
**不是生产资料，是商品** —— 用途是**等交易/以物易物系统上线后当硬通货**。

| 处置 | 说明 |
|---|---|
| **不进任何配方** | 原设计的 `制作_镀金触点`（金饰→电子原件）已删：与"奢侈品"定位冲突 |
| **不进任何家具升级** | 原先塞进 储物箱 / 床 / 医疗站 的三处，换成 `金属零件` / `毛线团` / `注射器` |
| **保留在搜刮表**（×1~×10） | 稀有度天然分层：`金表`×10 常见 → `珠宝项链/古董怀表/钻戒`×1 稀有 |
| **价值就是它的用途** | 15~40（材料类最高），将来交易/兑换直接读 `价值` |

> **验收口径随之调整**：
> **无用途物品 = 47 − 39（接上出口）− 8（奢侈品 → 交易预留）= 0**。
> 门禁给 `种类 = 贵重物品` 开**交易预留白名单**（不报缺口），但**同时硬校验它们不许出现在任何
> `配方.材料` / `家具.材料` / `家具.升级[].材料` 里** —— 防止以后有人随手把钻戒塞回配方。
