# 武器图片手动挂载对照清单

> 目的：把 `武器精灵图.png` 挂到网格背包里。**你只需手动命名放好图片，代码已按 `items.json` 的 `"图片"` 字段自动加载。**（`物品图标服务` 读取，已在 `网格背包面板` 内容层/拖拽代理接入。）

## 一、手动挂图步骤（两种任选其一）

### 方式① 整张精灵图（推荐，一张图管所有武器）
1. 把 `武器精灵图.png` 移动到 `Assets/Resources/物品图标/`（若目录没有可新建）。
2. 在 Unity 选中该图 → Inspector 里设置：
   - Texture Type = **Sprite (2D and UI)**
   - Sprite Mode = **Multiple**
   - Pixels Per Unit = **16**（避免过度像素化）
3. 打开 **Sprite Editor** → `Slice` → Type = **Grid By Cell Size**，Cell Size = **64 × 32** → 自动切成 **10 列 × 5 行 = 50** 个子精灵（640÷64=10，160÷32=5，正好整除）。
4. 把**各武器对应**的子精灵，**重命名为物品标识**（见下表），与 `items.json` 的 `"图片"` 值一致。
5. 保存，回游戏即可显示。

### 方式② 单文件（每个武器一张图）
把每张图重命名为 `标识.png`，放 `Assets/Resources/物品图标/`（如 `军刀.png`），代码 `Resources.Load<Sprite>("物品图标/军刀")` 自动加载。

## 二、武器标识 ↔ 图片引用 ↔ 切片命名对照

> 单格 64×32（横向 2:1）正好贴合 2×1 武器。**这 7 件就是你已裁好并命名的子精灵名，需与 `items.json` 的 `"图片"` 值一字不差。**

| 物品标识 | 类型 | `items.json 图片` | 子精灵名 |
|------|------|------|------|
| 木棍 | 武器 · 棍棒 | `木棍` | 木棍 |
| 木琴 | 武器 · 棍棒 | `木琴` | 木琴 |
| 狼牙棒 | 武器 · 棍棒 | `狼牙棒` | 狼牙棒 |
| 碎酒瓶 | 武器 · 匕首 | `碎酒瓶` | 碎酒瓶 |
| 自制长矛 | 武器 · 棍棒 | `自制长矛` | 自制长矛 |
| 钢管 | 武器 · 棍棒 | `钢管` | 钢管 |
| 锯子 | 武器 · 刀 | `锯子` | 锯子（优秀） |

> 武器之外的物品（食物/水/医疗/材料/任务品/防具）暂未配图：`"图片"` 字段缺省为空 → 内容层显示色块，品质环不受影响。以后补图只要在 `items.json` 填引用名即可。

## 三、显示要点（已自动处理）

- 内容层 Image 加载 sprite 后 `preserveAspect = true`，按比例居中、不拉伸（武器横向图标在格内等比缩放，1×1 物品略扁但不失真）。
- 品质色永远在**物品框层**（全尺寸底层），图片在内容层——图片四周露品质色环，加图零改动。
- 手动挂图前：无图物品显示原深色块，属正常占位。
