## 〇、每刀的操作口径（照做，别走样）

1. **改任何 C# → 先编译**：`powershell -NoProfile -ExecutionPolicy Bypass -File "Tools\编译校验.ps1"`（不打开 Unity）
2. **再跑离线验证器**（四个 dotnet 工程 + 两个 ps1）：见 §三 命令原文
3. **`.ps1` 改完必须补 UTF-8 BOM**（`edit` 工具会吃掉 BOM；PS 5.1 读无 BOM 的 .ps1 按 GBK 解）
4. **提交**：把消息写进仓库根的临时文件，用 `git commit -F <文件> -- <paths>`，**然后删掉临时文件**（否则会被 `git add -A` 卷进提交）
5. **文档同步**：口径改变 / 新增裁决 → 更新对应设计文档，并在本文件 §一 勾进度
6. **不要凭记忆写"已删/已改/已验证"**（我在刀10 犯过，被审计抓住：见 `工作移交报告` §六 #41）

  **不要去换 `System.Random`**；要做的只是"给**战斗**注入可播种随机源"（为了可复现）。
