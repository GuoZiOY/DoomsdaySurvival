## 〇、每刀的操作口径（照做，别走样）

1. **改任何 C# → 先编译**：`powershell -NoProfile -ExecutionPolicy Bypass -File "Tools\编译校验.ps1"`（不打开 Unity）

## 一之四十、刀61 · 大世界敌人 AI（三态 + 噪音 + Flow Field 流场）

**关键设计三处**：① **"回巢"不是第四个状态**，而是巡逻步进的**归家偏置**（权重偏向离出生点更近的格）—— 一条规则同时表达"在家门口溜达 / 从远处走回来 / 被小噪音吸引时往噪音方向偏"；② **流场把"追踪玩家"和"追踪噪音"统一成一个结构**（都是以目标格为源的积分场）→ **这才是选流场的决定性理由**，性能只是第二条；③ **不破连通用"硬保证"而不是"论证"**（生成期那条"切比雪夫 ≥2 → 凑不出 8 连通屏障"的前提是**占格物从不移动**）→ 每移动一批跑一次早退 BFS，破了就整体撤销那一步（⚠ 校验用的 `敌人挡路` 必须是 `true`）。
**★ 验证器抓到的 3 个真 bug（设计时都没想到）**：① **敌人沿"切比雪夫等距圈"原地打转、永远回不了家** → 在范围外只禁"往外走"不够，**必须连"平距"一起禁**（保留"一个近的都没有时退回普通权重"的兜底）；② **看得见玩家时"追击上限"被整个绕过**（实测追到离出生点 21 格 > 上限 16）→ 根因是"看见"是**提前 return**，**缰绳必须先于视觉**判定；③ **敌人能走到玩家那一格** → 遭遇判据是"正交相邻"、同格 = 距离 0 → **遭遇永不触发**（"静态敌人不占格 → 玩家穿过去"的孪生兄弟，两头都得堵）。第 ③ 条由**谓词自检**（不依赖模拟的真值表）报出 → `能落子 / 碰世界门口 / 流场.可走 / 流场吸附 / 玩家能回营地 / AI 三态` 各钉一张真值表，**自检不过就不跑模拟**。
**性能实测**（100×100 开阔场 × 各 50 次）：流场一次 BFS（服务**所有**动因）**0.13~0.18 ms** / A\* 单点查询 3.2~3.6 ms / 16 只敌人各自 A\* ≈ 50~58 ms。⚠ **诚实注释**：这 20 倍里有一部分不是算法的功劳 —— A\* 那 3.5ms 绝大部分花在 `网格数据.占位` **对全部实体线性扫描**，而流场把占格物足迹**一次摊平成位图**（`建挡表` 3.481 ms → 0.144 ms）；流场真正不依赖实现质量的胜点只有两条：**随动因数量摊薄** + **与噪音机制共用数据结构**。
