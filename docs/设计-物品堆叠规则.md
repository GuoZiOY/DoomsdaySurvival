# 设计 · 物品堆叠规则（网格背包）

> 状态：已实现（20260823v8 起）。配套实现：`玩家档案`（堆叠规则/合并/放入网格）、`网格背包面板`（拖拽合并）、`items.json`（堆叠上限）。

## 一、核心原则

**不是所有同种物品都能合并。** 每个物品在 `items.json` 显式定义 `堆叠上限`：

- `堆叠上限 > 1` → 可堆叠（同格合并，受上限约束）
- `堆叠上限 = 0/缺省/1` → 不可堆叠（每格恒为 1 件独立实例）

判定入口（领域层，纯 C#）：

| 方法 | 作用 |
|------|------|
| `可堆叠(标识)` | 该物品是否允许合并（上限 > 1） |
| `堆叠上限(标识)` | 单格堆叠上限（0 = 不可堆叠） |
| `可合并(目标, 来源)` | 两堆叠能否合并（拖拽投影蓝/绿判定） |
| `合并堆叠(目标, 来源)` | 执行合并，返回实际并入数（受上限限制） |
| `放入网格(标识, 数量)` | 加入背包：**先填已有未满堆叠，满额再开新堆叠**，返回实际放入数 |
| `放入网格堆叠(堆叠)` | 把已有堆叠实例（词缀装备/掉落/换装回包/旧存档迁移）放入网格找空位 |

## 二、各类别堆叠上限（定稿）

| 类型 | 堆叠上限 | 理由 |
|------|:---:|------|
| 武器 | 1（不可） | 独立实例：随机词缀/品质/耐久，一把刀 = 一件 |
| 防具（含背包类） | 1（不可） | 同上，装备实例不合并 |
| 弹药 | **100** | 子弹大量携带 |
| 食物（面包/罐头） | **20** | 消耗品可叠但有限 |
| 水 | **10** | 瓶装水占重 |
| 医疗品（绷带/医疗包/急救包） | **10** | 消耗品可叠但有限 |
| 材料（木板/胶带/零件/调料） | **50** | 制作消耗量大 |
| 任务品 | 1（不可） | 任务道具独立（相机/记事本/教科书） |
| 技能书 | 1（不可） | 学了即消耗 |

> 数值均在 `items.json` 内，改 JSON 即可调平衡，无需改代码。

## 三、合并条件（全部满足才可合并）

1. 标识相同；
2. 双方都可堆叠（上限 > 1）；
3. 目标未满（目标.数量 < 上限）；
4. 双方均无词缀（词缀 = 装备实例，绝不并入普通堆叠）；
5. 品质覆盖相同（两者品质覆盖都为空则忽略该条件；防止"合成提升过的"与普通混叠）。

## 四、交互（网格背包面板）

- **拖拽到同标识堆叠** → 自动叠入（淡蓝投影提示"可合并"）；超出上限的余量留在**原格**（拖拽源数据位置未动）。
- 投影颜色：淡蓝 = 可合并 / 淡绿 = 可移动、可换位 / 淡红 = 不可。
- 详情面板：可堆叠物品显示 `堆叠 x/上限`；不可堆叠显示 `数量 x`。
- 拖拽代理标签带 `×数量`。

## 四·五、品质着色（网格底座）

**架构约定：品质色永远属于"物品框层"，不属于内容层。** 物品两层结构：

```
物品框（全尺寸 Image）   ← 品质底层色：普通=透明 / 优秀~传奇=深底混合品质色 55% + 黑描边；点击/拖拽挂这里
  └─ 内容层（内缩6px Image） ← 现在=深色占位块；将来=美术图 sprite（赋值给该 Image 即可）
      └─ 名称×数量标签
```

- 现在没美术图：品质色整块着色，视觉为"品质色块"。
- 将来有美术图：内容层内缩 6px → 图片四周露出品质色环（暗黑/POE 式品质框），**加图零改动，品质色不丢**。
- 色板复用 `品质.cs`（普通灰白/优秀绿/稀有蓝/史诗紫/英雄橙/传奇红），与列表/词缀/日志一致。
- 有效品质 = `堆叠.品质`（合成覆盖）优先，否则 `items.json` 模板品质。
- 拖拽代理：非普通 = 品质色（α0.85），普通 = 内容层色；选中色、落点投影、原位置影子不受影响。
- 将来美术资源接入建议：`items.json` 增 `"图片": "路径"` 字段，或约定 `Resources/物品图标/{标识}.png`，面板加载 sprite 赋给内容层 Image。

## 五、放置路径统一（网格即背包）

所有"获得"路径统一走网格（修复旧版 `添加物品/添加堆叠` 创建 `列=-1` 隐形容器的缺陷）：

| 路径 | 实现 |
|------|------|
| 开局物资（面包×2/水/绷带） | `应用背包装备()` 后 `放入网格` |
| 战斗掉落（面包/水/掉落物） | `放入网格` / 词缀装备 `放入网格堆叠` |
| 换装/卸下旧装备回包 | `放入网格堆叠`（背包满 → 回滚换装，旧装备穿回） |
| 制作/合成产物 | 词缀装备 `放入网格堆叠`，其余 `放入网格` |
| 任务奖励/日常/效果结算/购买 | `添加物品`（已等价于 `放入网格`） |
| 旧存档迁移 | 读档时 `列<0` 的堆叠尝试 `放入网格堆叠` |

`放入网格` 返回**实际放入数量**（背包满时部分放入），调用方据此提示。

## 六、边界情况

- 背包满：`放入网格` 返回 0/部分数 → 调用方提示"背包已满"；换装回包失败 → 整体回滚。
- 词缀装备永不合并：`可合并` 显式排除。
- 部分合并：拖拽 30 水 到 8/10 的堆叠 → 目标 10/10，来源余 28 留原格。
- 目标已满：蓝/绿不出现，投影红色，松手播失败音。
