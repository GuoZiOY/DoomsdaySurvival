# 地图设计器（可视化地图编辑工具）设计

> 日期：2026-08-16
> 状态：已确认需求，待实现
> 关联：[[2026-08-15-map-navigation-design]]（地图导航系统）、`Assets/Resources/Data/map.json`

## 1. 目标

运行时继续读 `map.json`（数据驱动不变），但**编辑端**从「手改 JSON」换成**可视化设计**：在场景视图直接拖节点、拖连线、改属性、增删节点，然后**反向导出**回 `map.json`。让地图（大世界 + 城镇小地图）的调整不再依赖手改 JSON。

## 2. 已确认的关键决策

| 决策点 | 选择 |
|---|---|
| 编辑形态 | **场景视图拖拽**（Scene View Handle 拖节点、拖连线） |
| 编辑范围 | **完整设计器**：位置 + 连接 + 节点属性 + 增删节点 |
| 承载方式 | **方案 A**：菜单窗口（EditorWindow）承载属性列表 + 场景视图拖拽 |
| 保存策略 | **覆盖 + 自动备份**：保存前把旧 `map.json` 复制成 `map.json.bak`（仅留一份） |

## 3. 架构与组件

纯**编辑器工具**（`Editor/` 目录，`using UnityEditor`），不改任何运行时脚本。

| 组件 | 职责 |
|---|---|
| `地图设计器窗口.cs`（EditorWindow） | 菜单 `工具 > 地图设计器` 打开；顶部层下拉、中部节点属性列表、底部按钮 |
| `地图设计器场景绘制.cs`（静态，订阅 `SceneView.duringSceneGui`） | 在场景视图画节点 Handle 圆盘 + 连线；拖拽改位置、拖线建连接、右键菜单删除 |
| `地图编辑数据.cs`（内存副本） | 持有 `地图根` 反序列化副本 + 当前编辑层 + 选中节点；提供 加载/保存/增删/改连接/像素↔0-100 换算 |

三个组件围绕**内存副本**协作：窗口改属性 → 内存副本；场景绘制改位置/连接 → 内存副本；保存 → 内存副本序列化写文件。

## 4. 编辑器窗口布局

- **顶部**：编辑层下拉 —— `大地图` + 每个城镇的 `小地图`（按 map.json 的 `地点` 中 `类型=="城镇"` 动态列出）
- **中部**：当前层节点列表（ScrollView），每行 = 节点名（点选高亮）；选中后在下方表单编辑属性：
  - 大地图节点：名称 / 类型（城镇|荒野）/ 描述 / 入口节点（城镇）/ 区域（荒野）/ 目标 / 解锁物品 / 连接（多选）
  - 小地图节点：名称 / 类型（入口|设施|剧情|空地）/ 设施 / 剧情目标 / 位置(x,y) / 连接（多选）
- **底部**：`新增节点` / `删除选中` / `保存到 map.json`

## 5. 场景视图编辑画布

- 打开工具时，自动激活当前层对应面板（`Canvas/大地图面板` 或 `Canvas/小地图面板`），让 `地图区` 成为可见画布；找不到或 rect 为 0 时提示先搭好
- 每个节点画一个 **Handle 圆盘**，位置 = `地图区.rect` 内按归一化坐标映射（复用 `地图渲染.归一化` 的换算公式）
- **拖圆盘** = 改位置：像素偏移 → 0-100 坐标，写回内存副本
- **从 A 圆盘拖到 B 圆盘释放** = 建立连接：A、B 的 `连接` 数组互加，去重（连接视为双向）
- **右键圆盘** = 菜单：删除该节点 / 清除与该节点的全部连接
- 已有连接画线显示（Scene View Handles 画线，与运行时 `地图渲染.画线` 视觉一致）

## 6. 数据流

```
打开工具 → JsonUtility 反序列化 Assets/Resources/Data/map.json → 内存副本（地图根）
编辑（窗口改属性 / 场景拖拽改位置连接）→ 全改内存副本
保存到 map.json → 旧文件复制为 map.json.bak → JsonUtility.ToJson → 覆盖写入 → AssetDatabase.Refresh
关闭工具（有未保存修改）→ 弹窗提示
```

## 7. 坐标换算

- 编辑器换算公式与运行时 `地图渲染.归一化` 互逆：`0-100 ↔ 地图区.rect` 内像素
- 存储统一为 0-100 归一化坐标，面板尺寸变化不影响数据正确性

## 8. 运行时关系（不污染场景）

- 纯编辑模式工具；节点只用 Scene View Gizmos/Handle 画，**不生成任何运行时 GameObject**
- 运行时（Play）仍读 `map.json`，保存后重进 Play 生效
- 不提供 Play 模式热编辑（本期范围外）

## 9. 错误处理

- 找不到对应面板 / `地图区` rect 为 0 → 工具内提示，不崩溃
- `map.json` 缺失或反序列化失败 → 提示创建新的空地图根
- 删除节点时同时清理其它节点 `连接` 数组里的引用，避免悬挂连接

## 10. 范围外（本期不做）

- Play 模式热编辑 / 实时同步
- 地图数据校验（复用 `DataService.重新校验` 可在保存后手动触发，但不强制）
- 撤销/重做
