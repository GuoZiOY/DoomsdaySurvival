# 地图-设施-野外-剧情 导航系统设计规格

> 项目：文字奇幻rpg ｜ 日期：2026-08-15 ｜ 状态：已确认
> 前置：已定技术栈为 uGUI（用户手动搭面板）+ 服务层事件驱动

## 1. 目标与原则

补全玩法骨架：**地图驱动的自由移动** 取代「主视窗选项包办一切」。明确原则：

1. **主视窗选项只服务剧情分支**（移动/进设施不再走剧情选项）。
2. 移动走**地图面板**，设施走**设施面板**，野外走**闯关式野外面板**。
3. 地图是**节点图**：节点（坐标）+ 连线（连接），拓扑可为网格/交叉树/网状，由统一渲染引擎支持。
4. 逐步移动：只能沿连线从当前节点走到相邻节点。

## 2. 三地图模型

| 地图 | 形态 | 移动 | 进入后 |
|---|---|---|---|
| **大地图** | 节点图（城镇/荒野节点+连线） | 逐步移动 | 点城镇→进城镇小地图；点荒野→开野外面板 |
| **城镇小地图** | 设施节点图（商店--酒馆--家+连线） | 逐步移动 | 点设施节点→弹设施面板 |
| **野外面板** | 闯关式（非节点图） | 反复探索 | 探索/收集/遭遇敌人/偶遇特殊事件/触发支线，有进度感，面板单独设计 |

## 3. 数据层（JSON）

      "类型": "城镇",          // "城镇" / "荒野"
      "入口节点": "镇口",       // 进城镇小地图后的起始节点

### 3.2 数据模型新增

- `地图地点` 增加字段：`类型`、`区域`(荒野关联区域标识)、`入口节点`、`小地图`(地图节点数组)。
- 新增 `地图节点`：`标识`、`名称`、`类型`("空地"/"设施"/"入口")、`设施`(可选设施标识)、`x`、`y`、`连接[]`。
- `设施定义` 保留（商店/训练场/任务板），UI管理器 switch 已按标识分发。

### 3.3 移动事件表（低概率，按地图类型）

- 大地图事件：`遇敌`(低)、`特殊发现`(低)、`无事`(高)。
- 城镇事件：`NPC事件`(低)、`无事`(高)。
- 权重表可硬编码于 `地图服务`（先），后续可下沉 JSON。

## 4. 服务层

### 4.1 地图服务（新增 `Services/地图服务.cs`）

状态：
- `当前大节点`：大地图位置。
- `所在模式`：`大地图` / `城镇`(某城镇) / `野外面板`(某区域)。
- `当前小节点`：城镇内位置（城镇模式时）。

接口：
- `打开大地图()`：进入大地图模式（玩家在大节点上）。
- `移动(目标节点)`：仅限相邻节点 → 更新位置 → 按地图类型低概率触发移动事件 → 到达处理。
- `进入城镇(大节点)`：切到该城镇小地图，玩家置于 `入口节点`。
- `离开城镇()`：回大地图（玩家在该城镇大节点）。
- `进入区域(区域标识, 返回节点)`：切到野外面板（复用 探索服务）。
- `移动事件抽取()`：按地图类型权重抽事件（复用 探索服务 权重逻辑）。

到达处理：
- 大地图移动到达 `城镇` 大节点 → 发 `打开城镇地图事件`（UI 切到城镇小地图）。
- 大地图移动到达 `荒野` 大节点 → 发 `打开野外面板事件`（UI 切到野外面板，内部进入区域探索）。
- 城镇内移动到 `设施` 节点 → 发 `打开设施事件`（UI 弹设施面板）。
- 城镇内移动到 `空地` 节点 → 无事（显示节点描述/触发可选剧情）。

### 4.2 探索服务（复用+扩展）

- 现有权重事件（遭遇/发现/资源/无事）作为野外面板核心。
- 新增：`收集`、`支线` 事件类型（数据 + 处理，先留占位）。
- 野外面板为闯关式：反复 `深入`，事件驱动；面板内容用户后续细化。

## 5. 事件（新增）

- `打开大地图事件`
- `打开城镇地图事件 { 城镇标识, 入口节点 }`
- `打开野外面板事件 { 区域标识, 返回节点 }`
- `地图位置事件 { 所在模式, 大节点, 小节点 }`（HUD 地点栏更新用）

## 6. UI 层（uGUI，用户搭面板容器，代码生成节点/连线）

- **大地图面板**：容器 + 代码按 `x/y` 摆节点按钮 + 连线（细 Image 旋转拉伸）；可移动节点高亮，点击相邻节点 → `地图服务.移动`。
- **城镇地图面板**：同上，渲染 `小地图` 设施节点；点击设施节点 → 进设施面板。
- **野外面板**：闯关式（复用 探索显示事件 + 深入/返回按钮），内容用户细化。
- **主视窗**：剧情（选项只服务分支）/ 设施面板。
- **HUD 地点栏**：订阅 `地图位置事件` 更新当前地点名。

## 7. 流程

1. **序章**：纯线性剧情（无地图），选项推进。
2. **序章结束** → 发 `打开大地图事件`，进入自由移动。
3. 大地图逐步移动 → 到达城镇 → 城镇小地图 → 进设施 → 设施面板交互 → 返回城镇小地图。
4. 大地图移动 → 到达荒野 → 野外面板（闯关探索）。
5. 剧情触发：到达节点/进设施时，剧情片段以主视窗剧情模式呈现（选项推进后回地图）。

## 8. 实施范围（里程碑）

- **M-A 地图骨架**：数据模型(map.json 增强 + 地图节点)、地图服务（状态/移动/到达处理）、导航事件、大地图面板渲染（节点+连线）、序章结束开地图。
- **M-B 城镇小地图**：小地图数据、城镇面板渲染、设施节点→设施面板、离开城镇回大地图。
- **M-C 野外面板**：荒野大节点→野外面板、闯关式交互（探索/收集/遭遇/支线占位）、复用探索服务。
- **M-D 移动事件与剧情触发**：低概率移动事件（遇敌/NPC事件）、到达/进设施触发剧情片段。

## 9. 明确不做（YAGNI）

- 不做寻路 AI（逐步移动是手工点击相邻）。
- 不做地图缩放/拖拽（先固定视口，够用再加）。
- 不做多存档位。
