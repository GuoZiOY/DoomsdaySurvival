## 二、主线阶段（玩家档案新字段 `主线阶段`）

阶段即"下一步待触发的剧情"；剧情节点进入时更新（`剧情节点.主线阶段` 字段，进入即设置）。

| 阶段 | 触发剧情 | 进入条件 | 设置该阶段的节点 |
|------|---------|---------|-----------------|
| 第一章_序章 | （初始） | — | — |
| 第一章_穿越橡木林 | 进橡木林→穿越被救 | 镇长府接主线 | 镇长府节点 |
| 第一章_抵达风谷村 | 进风谷村→魔物袭击救小烛 | 穿越剧情结束 | 第一章_抵达风谷村 |
| 第一章_特训 | 特训 + 支线（击杀/采药/修桥） | 救下小烛 | 第一章_老李认可 |
| 第一章_深入调查 | 进橡木林→深入撤退（需修桥完成） | 特训完成 | 第一章_特训结束 |
| 第一章_骑士团 | 进灰烬镇→骑士团出发 | 回镇 | 第一章_桥通回镇 |
| 第一章_决战 | 家中记忆碎片→女主同行→进橡木林决战 | 碎片剧情 | 第一章_记忆碎片 |
| 第一章_完成 | 橡木林纯探索 | 战胜哥布林王 | 第一章_决战胜利 |

辅助工具：`主线阶段工具.序(阶段)` 返回序号，`主线阶段工具.达到(当前, 目标)` 用于「主线阶段」类任务完成判定。

## 三、自动剧情触发（区域剧情路由）

**玩家永远不选择模式**；进入大地图地点时自动判定：

```json
"区域剧情": [
  { "区域": "橡木林", "阶段": "第一章_穿越橡木林", "节点": "第一章_穿越_遇袭" },
  { "区域": "橡木林", "阶段": "第一章_深入调查",   "节点": "第一章_深入_出发", "需要任务": "收集粗麻绳" },
  { "区域": "橡木林", "阶段": "第一章_决战",       "节点": "第一章_决战_进入" },
  { "区域": "风谷村", "阶段": "第一章_抵达风谷村", "节点": "第一章_村中_呼喊" },
  { "区域": "灰烬镇", "阶段": "第一章_骑士团",     "节点": "第一章_骑士团_出发" }
]
```

命中条件（全满足）：`区域==当前地点标识 && 档案.主线阶段==阶段 && (无需要物品 || 持有) && (无需要任务 || 该任务已完成)`。
命中 → `DialogueService.进入节点(节点)`（自动开剧情对话，不切探索/小地图）。阶段更新后路由行不再匹配 → 天然防重复。

- 地图服务 `进入荒野` / `进入城镇` 前先查路由。
- 路由行数据存 story.json 顶层 `区域剧情`（`剧情根.区域剧情`）。

## 四、第一章剧情节点流（story.json 新增/改造）

### A·余烬镇（改 镇长府 节点）
走遍镇子 NPC（对话给线索）；镇长府：
- `镇长府`（改文本）：魔物频繁、黑石山异动、人手不够 → 派玩家去风谷村找老猎人；桥被毁只能横穿橡木林
- 接主线（选项 效果：接取任务 + 主线阶段=第一章_穿越橡木林）→ 出发 → `地图:大地图`

### B·穿越（自动触发）
`第一章_穿越_遇袭`（狼群+哥布林伏击，敌方先手强制战）→ `第一章_穿越_危局`（被围）→ `第一章_穿越_老李救场`（老李射箭，恢复生命）→ `第一章_抵达风谷村`（阶段更新）→ 选项：`地图:风谷村`

### C·风谷村（自动触发）
进村 → `第一章_村中_呼喊`（听到呼救）→ 循声赶去 → `第一章_村中_小烛遇袭`（战斗:村外魔物组:第一章_村中_救下，被偷袭）→ `第一章_村中_救下`（救下小烛）→ 自动 → `第一章_老李认可`（阶段=第一章_特训；老李答应特训）→ 选项：去老李屋 → `地图:小地图`

### D·特训（老李屋 NPC）
`第一章_特训_开始`（老李特训说明）→ 选项三连：学横扫斩 / 学猎手标记 / 学疾风刺（效果.学习技能）→ `第一章_特训_结束`（阶段=第一章_深入调查）→ 支线提示。
支线（风谷村任务栏/村医/木桥）：击杀村外魔物、采集草药、修桥材料 3 件。
木桥交付：木桥内部 NPC 修桥工头 → `第一章_木桥_交付`（需持有 桥板木料/铁件/粗麻绳；交付选项 需要物品=粗麻绳，效果：失去三种材料 + 修桥完成文本）→ 桥通。

### E·深入（自动触发，需 收集粗麻绳 任务完成）
`第一章_深入_出发`（与老李同行）→ 自动 → `第一章_深入_巡逻遭遇`（战斗:哥布林巡逻组:第一章_深入_部落:老李，老李助战）→ `第一章_深入_部落`（发现哥布林部落，推断哥布林王）→ 自动 → `第一章_深入_撤退`（被侦查兵发现）→ 自动 → `第一章_深入_断后`（老李掩护，玩家独战：战斗:哥布林侦查队:第一章_深入_独行，被偷袭）→ `第一章_深入_独行`（老李陷入包围，玩家独退回村）→ 自动 → `第一章_桥通回镇`（桥已修好，阶段=第一章_骑士团）→ 选项：`地图:灰烬镇`

### F·骑士团（自动触发）
进灰烬镇 → `第一章_骑士团_出发`（团长韩如炎带骑士团出发；玩家留守；提示回家）→ 选项：`地图:小地图`
家内部 NPC「守火人幻影」→ `第一章_记忆碎片`（守火人记忆传承，获得 守火人记忆碎片；阶段=第一章_决战）→ 自动 → `第一章_女主同行`（村口遇小烛同行）→ 选项：`地图:大地图`

### G·决战（自动触发）
进橡木林 → `第一章_决战_进入`（与女主深入）→ 自动 → `第一章_决战_杂兵`（战斗:哥布林杂兵组:第一章_决战_地下室:小烛）→ `第一章_决战_地下室`（意外进入神秘地下室，发现圣火余烬）→ 自动 → `第一章_决战_圣剑`（触发记忆碎片，获得 圣火余烬 + 圣剑残骸）→ 自动 → `第一章_决战_王前`（骑士团/老李/镇长/团长鏖战文本）→ 战斗:哥布林王战组:第一章_决战_胜利:决战助战队（老李+小烛+韩如炎助战）→ `第一章_决战_胜利`（战胜哥布林王）→ 自动 → `第一章_决战_终章`（阶段=第一章_完成；存档提示）→ 选项：`地图:灰烬镇`

## 六、系统改动

1. **玩家档案**：`public string 主线阶段 = "第一章_序章";`（可序列化存档）
2. **主线阶段工具**（新 Domain 文件）：阶段→序表 + `达到()`
3. **数据模型**：
   - `剧情根`：+ `区域剧情路由[] 区域剧情`
   - `区域剧情路由`（新类）：区域/阶段/节点/需要物品/需要任务
   - `剧情节点`：+ `主线阶段` + `下一节点`（选项为空时自动进入）
   - `剧情效果`：+ `学习技能` + `接取任务`
   - `敌人组根`：+ `助战组`（`助战组数据[]`，独立结构：`成员[{标识,数量}]`——伙伴语义，不复用敌方「敌人」字段）
   - `地图地点`：+ `解锁阶段` + `解锁提示`
   - `显示剧情事件`：+ `自动目标`（下一节点）
4. **DialogueService**：进入节点 → 设置主线阶段 → 效果结算（+学习技能/接取任务）→ 发布显示事件（含自动目标）→ 更新阶段后调 `QuestService.检查阶段任务()`
5. **QuestService**：+ `检查阶段任务()`（主线阶段类任务完成判定）+ `任务已完成(标识)`
6. **地图服务**：`进入荒野`/`进入城镇` 前查区域剧情路由；`移动` 加解锁阶段判定
7. **BattleService 轻量助战**：
   - `开始战斗(组, 胜, 返, 先手=0, 助战组="")`：助战组单位以 `战斗单位.从助战生成`（是否我方=true，源数据保留供 AI）加入我方
   - `玩家回合` 改为 `当前行动单位 == 玩家`（助战回合不算玩家回合）
   - `继续()`：玩家回合返回；敌方/助战回合都自动执行 AI
   - 失败判定：`玩家` 倒下即败（助战倒下无碍）
   - 技能目标=敌方全体时对所有存活敌方生效（横扫斩）
8. **战斗单位**：+ `从助战生成(敌人数据)`（复用从敌人生成，是否我方=true）
9. **战斗面板**：`处理行动轮换` 用 `战斗.玩家回合` 而非事件 `是否玩家回合`（助战回合也走敌方节奏自动推进）
10. **对话面板**：无选项且 `自动目标` 非空 → 打字完成后自动 `处理选项(自动目标)`
11. **DataService**：加载 助战组/区域剧情；校验：区域剧情路由（区域/节点/任务/物品存在）、助战组敌人存在、剧情节点.下一节点 存在、战斗:目标 4 段助战组存在
12. **GameBootstrap**：无新服务注册

## 七、剧情战斗目标格式（扩展）

- `战斗:敌人组:胜利节点`（原）
- `战斗:敌人组:胜利节点:助战组`（新，助战组可空=无助战）
- 剧情战斗由"剧情选项"触发（`节点.战斗` 字段维持未用状态）

## 八、数值平衡（货币压低）

- 敌人金币：第一章新敌 8000~20000 铜（0.8~2金）；哥布林王 80000（8金）
- 任务奖励：支线 1~3金；主线 10金
- 材料价格：1500~3000 铜（银级）
- 助战单位：金币/经验奖励 0（不给玩家刷钱）
