# 三级导航设计（设施内部图 + 对话面板 + 功能面板）

> 日期：2026-08-16
> 状态：需求已确认，待实现
> 前置：设施架构①（设施工厂 + 数据路由）、角色系统（品质/属性/技能）

## 1. 目标

建立 **大地图 → 小地图 → 设施内部图** 三级导航。设施内部也是节点图（NPC + 功能物节点）：点 NPC 弹**对话面板**（交谈/触发剧情），点功能物弹对应**功能面板**。对话面板独立于主视窗，职责分离清晰。

## 2. 已确认决策

| 决策点 | 选择 |
|---|---|
| 导航层级 | 大地图 → 小地图 → 设施内部图（三级） |
| 设施内部 | 节点图（NPC 节点 + 功能物节点），复用 `地图面板基类` |
| 对话面板 | **独立**，从主视窗剥离 剧情/对话 渲染 |
| 功能面板 | **设施功能面板基类 + 功能接口**（跨设施复用，如教学面板=武馆+学堂共用） |

新增数据类：
```csharp
// 设施 NPC：交谈触发剧情
[Serializable] public class 设施Npc { public string 名称; public string 描述; public string 剧情节点; }
// 设施内部节点：NPC 或 功能物
[Serializable] public class 设施内部节点
{
    public string 标识; public string 名称;
    public string 类型;       // "NPC" / "功能物"
    public string 功能;       // 类型=功能物 时：教学/买卖/训练/恢复/睡觉
    public string 剧情节点;   // 类型=NPC 时：交谈进入的剧情节点
    public float x, y;        // 0-100 坐标
    public string[] 连接;
}
// 设施定义 加字段
public 设施Npc[] NPC;
public 设施内部节点[] 内部节点;
```

## 4. 设施逻辑 扩展

- `设施逻辑` 基类加：`设施内部节点[] 内部节点`、`设施Npc[] NPC`（设施工厂从 `设施定义` 注入）
- 功能接口（放 `设施逻辑.cs`）：
```csharp
public interface 教学功能 { 技能数据[] 可学技能(); bool 尝试学习(string 标识); }
public interface 买卖功能 { 物品数据[] 可购商品(); bool 尝试购买(string 标识); 物品堆叠[] 可卖物品(); bool 尝试卖出(string 标识); }
public interface 训练功能 { 训练项目[] 可训项目(); bool 尝试训练(string 标识); }
public interface 恢复功能 { string 恢复描述(); bool 尝试恢复(); }
public interface 睡觉功能 { string 睡觉描述(); bool 尝试睡觉(); }
```
- 武馆设施/学堂设施 implements 教学+买卖+训练；教堂 implements 恢复；家 implements 睡觉

## 5. 对话面板（新，独立）

- **职责**：渲染剧情（`显示剧情事件`：正文 + 选项），NPC 交谈也走这里
- 从主视窗剥离剧情模式；主视窗只留 战斗/探索/结局
- 从设施内部进来时带「返回设施内部」按钮
- `面板管理器` 路由：`显示剧情事件` → 对话面板

## 6. 设施内部面板（新，extends 地图面板基类）

- 复用 地图面板基类（节点渲染/平移缩放/双击选中 全继承）
- 双击 NPC 节点 → `DialogueService.进入节点(剧情节点)` → 对话面板
- 双击 功能物 节点 → 打开对应功能面板（按 功能 标识路由）
- 返回 → 小地图

## 7. 设施功能面板基类 + 功能接口

见已确认设计（基类骨架 + 功能接口 + 子类只写 标题文字/渲染列表）。功能面板从设施内部功能物节点打开，上下文 `设施打开上下文(逻辑, 返回节点)`，返回设施内部。

## 8. 现有改造

- **小地图**：设施节点 → `打开设施内部事件(设施标识, 返回节点)`（不再直接开设施面板）
- **主视窗**：移除剧情模式（`显示剧情事件` 路由到对话面板）
- **现有面板**：商店/训练场/任务板 改成 `设施功能面板基类` 子类（瘦身为只写生成行）
- **导航事件**：新增 `打开设施内部事件`

## 9. 实施顺序

1. **数据模型 + 设施逻辑扩展**（NPC/内部节点/功能接口）
2. **对话面板** + 剧情迁移（主视窗剥剧情）
3. **设施内部面板** + 打开设施内部事件 + 小地图改造
4. **功能面板基类** + 现有设施改造（商店/训练场/任务板）
5. **新设施接入**（武馆/学堂/教堂/酒馆/任务栏/家，各写 逻辑类 + 功能面板/节点数据）
