# 角色系统设计（属性 / 加点 / 训练 / 技能 / 品质）

> 日期：2026-08-16
> 状态：需求已确认，待实现
> 前置：[[2026-08-16-map-editor-design]]（设施架构①已完成：设施工厂 + 数据路由）

## 1. 目标

建立完整角色成长系统：**四大基础属性 + 自由加点、训练场双修（属性/技能熟练度）、技能多途径获取且属性达标才能学、技能有熟练度等级与品质、品质横切物品与技能**。为后续 装备/材料/锻造/掉落 打底。

## 2. 已确认决策

| 决策点 | 选择 |
|---|---|
| 成长方式 | 升级获得**自由属性点**，玩家自行分配到 4 大属性 |
| 训练场 | **属性训练** + **技能熟练训练**（不再教技能） |
| 技能获取 | 多途径（剧情奖励 / 技能书 / 武馆），**任何途径都需属性达标才能学** |
| 技能熟练度 | 学会=1 级，上限 **5 级**；每级 **+10% 伤害 / -5% 消耗**；训练花费递增 `30×N` 金 |
| 品质系统 | 6 档横切（物品/技能/未来材料装备），倍率 ×1.0→×3.0 |
| 加点/查看 UI | 并入**角色面板**（属性 + 加点 + 装备 + 背包，全局可开） |

## 3. 品质系统（横切）

```csharp
public enum 品质 { 普通, 优秀, 稀有, 史诗, 英雄, 传奇 }
```

| 品质 | 颜色 | 效果倍率 |
|---|---|---|
| 普通 | 白 #ffffff | ×1.0 |
| 优秀 | 绿 #7fae6a | ×1.2 |
| 稀有 | 蓝 #4a8bd6 | ×1.5 |
| 史诗 | 紫 #9e5fd6 | ×1.8 |
| 英雄 | 橙 #d98f4a | ×2.2 |
| 传奇 | 红 #d64545 | ×3.0 |

- `物品数据` 加 `品质`：恢复品 `恢复量` × 倍率；武器 `攻击加成` × 倍率；防具 `防御加成` × 倍率
- `技能数据` 加 `品质`：基础伤害 × 倍率
- `游戏主题` 加品质色映射（`品质色(品质)`），物品/技能名按品质着色
- 产出分配（掉落/商店/锻造）后续各系统定

## 4. 角色属性

`玩家档案` 新增：

```csharp
public int 体力 = 5, 力量 = 5, 智力 = 5, 敏捷 = 5;   // 4 大基础属性
public int 自由属性点 = 0;                            // 升级获得，自行分配
```

**派生公式**（总属性 = 基础 + 属性 + 装备）：
```
最大生命上限 = 20 + 体力×5 + 等级×5
最大魔力上限 = 20 + 智力×3 + 等级×3
物理伤害     = 力量×2 + 武器加成（武器攻击解析）
魔法伤害     = 智力×2（法杖类装备加成后续系统再加，本期无）
暴击概率     = 敏捷×1%
闪避概率     = 敏捷×1%
```

**升级**：`获得经验` 升级时 `自由属性点 += 3`（每级 3 点）。
**加点**：角色面板把自由属性点分配到 4 大属性；只能加不能减，自由属性点不能为负，消耗 1 点 → 所选属性 +1。

## 5. 技能系统

`技能数据` 新增字段：
```csharp
public int 需要体力, 需要力量, 需要智力, 需要敏捷;   // 学习/释放前提（0=无要求）
public 品质 品质;
public int 熟练伤害加成 = 10;   // 每级 +% 伤害
public int 熟练消耗减少 = 5;    // 每级 -% 消耗
```

`玩家档案.已学技能` 从 `List<string>` 改为 `List<技能掌握>`：
```csharp
[Serializable]
public class 技能掌握 { public string 标识; public int 熟练等级 = 1; }
```

**学习规则**：`学习技能(标识)` 统一校验——先查 `技能.需要*` ≤ 当前属性，不满足返回失败并日志提示缺哪项。**任何获取途径（剧情奖励 / 技能书 / 武馆）都走这一个校验**。

**熟练度**：等级 1~5。战斗中释放技能：
```
伤害 = 基础数值 × 品质倍率 × (1 + 熟练等级×10%)
消耗 = 基础消耗 × (1 - 熟练等级×5%)，最低 1
```

## 6. 训练场（改造）

`训练场设施` 提供两类训练（花金币）：

**属性训练**（数据 `training.json`）：
| 项目 | 效果 | 花费 |
|---|---|---|
| 力量训练 | 力量 +1 | 50 金 |
| 体力训练 | 体力 +1 | 50 金 |
| 智力训练 | 智力 +1 | 50 金 |
| 敏捷训练 | 敏捷 +1 | 50 金 |

**技能熟练训练**：已学技能 +1 熟练等级（练到第 N 级花 `30×N` 金，N=当前等级，5 级封顶）。

`训练场面板` 分两区：属性训练列表 + 技能熟练训练列表。

## 7. 角色面板（全局面板，全局可开）

- **属性区**：4 大基础属性 + 派生数值（生命/魔力上限、物理/魔法伤害、暴击/闪避）
- **加点区**：剩余自由属性点，分配到 4 大属性
- **装备区**：查看/换装 武器、防具
- **背包区**：查看持有物品（堆叠 + 数量）

## 8. 战斗系统改动（依赖项）

- 物理/魔法伤害分流：普攻走物理，技能按 `类型` 走物理或魔法
- 暴击判定：`总攻击 × (1 + 暴击概率)`，命中暴击时 ×1.5
- 闪避判定：受击时按 `闪避概率` 免伤
- 技能应用：品质倍率 + 熟练度加成/减耗

## 9. 范围外（本期不做）

- 装备/材料的品质掉落分布、锻造（后续系统）
- 武馆设施 UI（技能获取设施，本期只做数据与校验，武馆面板后续）
- 保存迁移（`已学技能` 结构变更，旧档兼容后续处理）

## 10. 依赖与顺序

1. 品质系统 + 玩家档案属性改造（数据地基）
2. 训练场改造（属性 + 熟练训练）
3. 技能系统（前提校验 + 熟练度 + 品质）
4. 战斗系统改造（物理/魔法/暴击/闪避）
5. 角色面板（属性/加点/装备/背包）
