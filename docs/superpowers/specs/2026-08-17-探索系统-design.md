# 探索系统设计

日期：2026-08-17
项目：文字奇幻rpg（Unity）
状态：已确认，待实现

## 1. 定位与目标

探索是"以深度分层"的野外区域系统：

- 浅层 = 补给 / 练手
- 中层 = 战斗 / 拾取
- 深层 = 发现剧情 / Boss 压轴

每区域固定层数（默认 5 层），底层放 Boss。通关后区域标记通关、仍可再刷（Boss 不再出现）。

## 2. 核心循环

```
进入区域 → 第1层 → 反复[搜索]触发本层事件表 → 探索到阈值后随机触发"发现通路"
  → [深入]解锁 → 下探 → … → Boss层 → Boss战 → 通关(可再刷)
```

关键张力：**HP/MP 带入不恢复** → 血线下降 → 玩家主动决策"再搜 or 见好就收"。

### 通路机制（阈值 + 概率）

- 每层搜索满 `搜索阈值`（默认 3）次后，"发现通路"进入候选
- 之后每次搜索掷 `通路概率`（默认 0.5）：
  - **成功** → 触发"发现通路"事件，显示通路文本，[深入] 按钮解锁
  - **失败** → 该次搜索正常抽层内事件表（不浪费这次搜索）
- [返回] 始终可用；[深入] 仅在通路出现后可用

## 3. 数据模型（每层独立表）

### 区域数据（regions.json）

```
区域数据:
  标识 / 名称 / 描述 / 危险度(1低/2中/3高) / 通关文案
  层[ ]                     // 第1层 → 底层
```

### 层

```
层:
  编号 / 描述
  搜索阈值? (默认3) / 通路概率? (默认0.5)
  事件表 或  岔路{ 文本, 安全事件表, 危险事件表 }   // 岔路层
  Boss敌人组?                                    // Boss层：遭遇表只放 boss 组
```

### 事件表

```
事件表 = {
  遭遇[](敌人 + 权重)
  资源[](剧情效果 + 文本 + 权重)
  发现[](剧情节点 + 权重)
  无事文本[](权重1)
}
```

说明：
- 现有 `区域数据` 顶层 遭遇/发现/资源/无事文本 字段**移入各层**，删除顶层旧字段
- 发现绑定具体层（到达该层搜索才能碰到）
- 通关标记存运行时（玩家档案），非 JSON 内容

## 4. 探索服务状态机

### 状态

```
当前区域 / 当前层 / 本层已选岔路(安全|危险) / 本层已搜索次数
本层通路已解锁 / 区域通关标记 / 返回节点
```

### 动作

- **进入区域**(区域标识, 返回节点)：层=1，显示层1描述；层1若是岔路层→先选路
- **选岔路**(路)：锁定本层事件表，显示层描述
- **搜索**()：
  1. 若已搜次数 >= 阈值 → 掷通路概率；成功 → 触发"发现通路"（解锁深入），结束本次
  2. 否则正常抽本层事件表，已搜次数++：
     - **遭遇敌人** → `战斗.开始战斗(敌人组, "__探索胜利", "__探索返回")` → 战斗面板
     - **发现地点** → `DialogueService.进入节点(剧情节点)` → 对话面板 → 回到区域
     - **获得资源** → `效果结算.应用`（金币/获得物品）
     - **无事发生** → 显示文本
- **深入**()：层+1；新层若是岔路层→先选路；显示新层描述
- **返回**()：撤离回来源（城镇/大地图），保留所得
- **Boss战胜利**回调：若当前层是 Boss 层 → 通关标记=true，显示通关文案

### 事件流

```
探索显示事件 → 探索面板（替换当前 → 主视窗 的路由）
战斗开始事件 → 战斗面板
显示剧情事件 → 对话面板 → 回到区域
```

## 5. 探索面板 UI（主视窗内新面板，场景手动搭建）

```
┌──────────────────────────────┐
│ 橡木林 · 危险度:低    层 2/5   │ ← 信息条(区域名+危险度+层进度)
│──────────────────────────────│
│  林间雾气流动，地面湿软。      │ ← 正文区(层描述/事件文本)
│                              │
│──────────────────────────────│
│  [搜索] [返回]                │ ← 动作区(初始)
│  [搜索] [深入] [返回]         │ ← 通路解锁后
└──────────────────────────────┘
岔路层: 正文区显示岔路描述，动作区换成 [走安全小路] [走危险捷径]
```

- 事件结果走主日志（复用），正文区保持层描述
- 战斗切战斗面板，回来刷新层状态
- 大地图荒野节点显示"已通关"角标（可选）

### 面板接线

- `面板管理器` 增加 `探索面板` 字段；`探索显示事件` 路由到探索面板（替换当前 → 主视窗）
- `打开探索事件` → 显示探索面板
