# M-A 地图骨架 Implementation Plan

> 依据规格 `docs/superpowers/specs/2026-08-15-map-navigation-design.md`

**Goal:** 落地大地图移动骨架：数据模型、地图服务（状态/逐步移动/到达处理）、导航事件、大地图面板渲染、序章结束开地图。

## Global Constraints
- 全局命名空间；全中文命名 + `//` 行内注释；逻辑不调 UI（发事件）。
- 地图 = 节点图：节点(x/y)+连接，代码按坐标摆按钮、画线（动态内容可代码生成）。
- 用户按指南搭面板容器（空面板），代码填充节点/连线。

## Task 1: 数据模型增强
- `数据模型.cs`：`地图地点` 加 `类型`/`区域`/`入口节点`/`小地图`；新增 `地图节点{标识,名称,类型,设施,x,y,连接[]}`。
- `map.json`：灰烬镇加 `类型:"城镇"`,`入口节点`,`小地图`(镇口/酒馆/商店/家)；橡木林/黑石山加 `类型:"荒野"`,`区域`。

## Task 2: 导航事件（Events/导航事件.cs 追加）
- `打开大地图事件`、`打开城镇地图事件{城镇标识,入口节点}`、`打开野外面板事件{区域标识,返回节点}`、`地图位置事件{所在模式,大节点,小节点}`。

## Task 3: 地图服务（Services/地图服务.cs）
- 状态：`所在模式`(大地图/城镇/野外)、`当前大节点`、`当前小节点`。
- `打开大地图()`、`移动(目标节点)`(相邻校验+低概率事件占位+到达处理)、`进入城镇()`、`离开城镇()`、`进入区域()`。
- 到达处理：城镇→发`打开城镇地图事件`；荒野→发`打开野外面板事件`；城镇设施节点→发`打开设施事件`。

## Task 4: UI管理器 大地图渲染 + 接线
- `UI管理器`：抓 `大地图面板/地图区` 容器；`渲染大地图()` 按 x/y 摆节点按钮（`按钮预制体`）+ 连节点画线（细 Image）；点击相邻节点→`地图服务.移动`。
- 订阅 `打开大地图事件`(显示大地图面板+渲染)、`打开城镇地图事件`(显示城镇面板，M-B 实现渲染)、`地图位置事件`(HUD 地点)。
- 面板切换加入 `大地图面板`。

## Task 5: 装配 + 序章开图 + 指南
- `GameBootstrap` 注册 `地图服务`。
- 序章结局「保存并返回主菜单」后 → 发 `打开大地图事件`（进入自由移动）。
- 更新 `docs/ugui搭建指南.md`：加「大地图面板」容器搭建说明（空面板+地图区子物体）。

## 验证
- 编译零错误；Play 无报错；序章结束开大地图（面板容器未搭则控制台警告，不崩）。
