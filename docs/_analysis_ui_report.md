# 文字奇幻 RPG · UI 层代码分析报告

## 1. 面板系统架构

**面板基类**（抽象 MonoBehaviour，每面板=一个组件）提供：
- **生命周期**：`显示面板(上下文, 上下互切, 返回方向)` = SetActive + 记录初始锚点 + 播入场（static `跳过下次动画` 支持自切免动画）+ 调抽象 `刷新(上下文)`；`隐藏面板` 播完退场才 SetActive(false)。
- **过渡动画**（DOTween 全 `SetUpdate(true)` 免暂停、`SetLink` 随销毁）：默认「对向滑入滑出」（上下分层+0.2s 队列延迟+OutBack 回弹+淡入淡出）；侧边式「右侧滑入右滑出」；侧边↔侧边互切专用「上下滑动」。每次动画先 Kill 旧 tween；`记录初始位置` 用 bool 防重（因全屏面板正常位常在 (0,0)）。
- **回退协议**：虚方法 `回退()` + `取消文本`，由玩家输入系统（右键）与侧边栏取消按钮统一调用——全局唯一"返回"入口，各面板覆写语义。
- **行构建工具**（static，子面板也能用）：`创建行`（克隆共享按钮预制体、找"文字"子节点、自动注册音效）、`创建模板<T>`（克隆行模板）、`清空`、`创建标签`、`设文本`、`设选中缩放`（经 `悬停反馈.设基座` 做选中放大）、`返回设施`（"城镇:"前缀回地图，否则回剧情节点）。

**面板管理器**=导航路由器：单例、17 个面板全部 Inspector 拖入。Awake 装配 `GameBootstrap.装配()`（幂等）并注入共享预制体；Start 统一订阅导航事件路由到 `显示()`：`打开设施事件`→查城镇设施节点→节点内部；`打开功能面板事件`→switch 功能标识（买卖/训练/任务/教学/恢复/睡觉/制作）→对应面板+`设施打开上下文`；`打开对话/显示剧情/打开结局`→对话；`打开大地图/小地图`；`打开战斗`→战斗；`探索显示/打开探索/打开野外面板`→探索；`打开角色/任务面板`→侧边全局面板。`显示()` 处理：自切免动画、侧边↔侧边互切（不覆盖"上一个面板"，保证互切后仍能返回原内容面板）、`_返回意图` 标记返回方向、先激活主视窗容器+常驻UI 再切子面板、其余面板静默 SetActive(false)、发布 `面板切换事件`。返回三入口：`返回上一面板`（单层）、`关闭全局面板`（回主视窗，防平级互切成环）、`回主菜单`。

**三级 UI 落地**：①主菜单（唯一活动面板，常驻UI 全收）；②主视窗容器+常驻UI（HUD 顶栏、日志面板、侧边栏、状态栏、时钟）——内容面板是主视窗子节点；③内容面板层级：大地图→小地图（城镇）→节点内部→功能/对话面板；战斗、探索为独立内容面板。

## 2. 各面板职责与交互流程

- **主菜单**：新游戏/读档→`PlayerService` + 进入当前节点。
- **HUD**：不进路由常驻；订阅 生命/魔力/精力/经验/金币/时间变化+`地图位置事件` 刷新 TMP，数值变化 `DOPunchScale` 脉冲；`战斗结束/面板切换` 时按玩家档案兜底重刷三层。
- **日志面板**：常驻左侧；订阅 `日志事件` 运行时生成 TMP 条目（上限 200、自动滚底），渲染=时间戳+彩色徽章+正则提亮数字；`日志折叠` 协程平滑收展。
- **侧边栏**：常驻右栏；取消（调当前面板`回退()`，未消费播失败音）、设置弹窗（OnEnable 驱动动画，不走路由）、音量/暂停图标切换、存档（`SaveService.保存`，空节点禁止）、角色/任务按钮发事件；`刷新显隐` 主菜单隐藏取消/暂停/角色/任务、战斗隐藏角色/任务；Update 轮询取消文案。
- **战斗**：见第 4 节。
- **角色面板**：薄编排器——标题+属性/装备背包 Tab，内容委托两个子面板自刷新；**属性子面板**（静态引用，订阅属性/生命/魔力变化，加点按钮显隐）；**装备背包子面板**（8 装备槽单击选中/双击快卸、5 分类 Tab、无界克隆行、详情区操作；操作全部走 `面板操作` 静态域操作类：加点/换装/卸下/学技能书/用恢复，只改领域+发事件，UI 自刷新）。
- **系统任务面板**：侧边式；主线（按主线阶段过滤"已完成+当前"、章节可折叠、中文序号）/支线（仅已接取）/日常（悬赏板已接取）三 Tab + 详情区 + 行动按钮（接取/提交）；详情区未接线退化为日志展示。
- **对话面板**：TMP `maxVisibleCharacters` 打字机（打字中点击任意处立即完成），打完生成选项，剧情链 `自动目标` 0.8s 连播；结局渲染；回退三态：结局→回主菜单、打字中→跳过、NPC 交谈→回节点内部。
- **买卖面板**：设施基类；购买/卖出共用列表+Tab 切换；4 键排序（默认/价格/品质/名称，同键反方向换箭头）；金币变化覆写为只刷余额（保滚动位置）；旧样式回退。
- **制作面板**：配方行（可制绿/缺材灰/选中金）+详情+制作按钮（材料足够才可点）。
- **日常任务面板**：按设施范围（装备/食物/药剂/通用）列当天日常，接取/提交/已结算三态行动按钮。
- **训练/教学/恢复/睡觉**：极简旧样式，`创建行` 直出。
- **地图三面板**（共用 `地图面板基类`：拖拽平移 0.5 灵敏度、滚轮光标锚点缩放 0.6~2、边缘限位；`双击检测` 0.3s 判定 单击移动/双击进入）：**大地图** 订阅位置事件重绘高亮，双击未到站播失败音；**小地图** 城镇节点网络，回退=离开城镇；**节点内部** 三级末级，单击无操作，双击 NPC→对话、功能物→`设施工厂.创建`+功能面板事件，回退按返回节点（城镇/剧情）。
- **探索面板**：固定信息条+正文+三按钮，点击时实时读 `服务.当前显示` 的动作字符串，switch 路由到探索服务；**唯一**在 OnDestroy 显式取消订阅的面板。

## 3. 信息链路

数据获取统一 `ServiceRegistry.Get<T>()`（DataService 读表、PlayerService 档案、BattleService/地图/探索/日常/任务服务）。**UI 纯事件驱动**：逻辑层发布、面板订阅刷新，服务层不碰 UI。关键订阅关系：导航事件→面板管理器；`生命/魔力/精力/经验/金币/时间/地图位置变化`→HUD；`日志事件`→日志面板；`战斗开始/行动轮换/伤害/治疗/状态变化/目标变化/回合开始/战斗结束`→战斗面板；`属性/背包/生命/魔力变化`→角色、装备背包、属性子面板；`任务进度/任务完成/日常任务变更/金币变化`→任务面板；`背包变化`→买卖/制作；`日常任务变更`→日常面板；`面板切换/战斗开始结束`→侧边栏。**日志复用**：任何层发 `日志事件(类型,文本)` 即进左侧日志，主题色徽章分类；未接线详情区（任务/日常面板）也降级发日志，是全项目兜底输出通道。EventBus 是类型化字典总线（订阅/发布/解绑，发布快照+单订阅者异常隔离）。

## 4. 战斗 UI 交互细节

状态机：行动选择→技能/道具子菜单→点卡牌选目标→执行→结算。**行动序**：`刷新信息条` 单文本富文本旋转呈现——当前金▶、已行动淡删除线、下一个我方亮青、其余灰，带缓存防每帧 settext。**演出**：所有时序事件（伤害/治疗/阵亡/敌方行动/结束）压成 IEnumerator 片段入队，单驱动协程串行 `MoveNext`（一帧只推进一格，逻辑 `战斗.继续()` 也作为片段挂队尾）；敌方回合=强调+跳跃+0.8s 停顿再继续；受击=震颤（暴击/真实更狠）+飘字（暴击红放大、魔法蓝、闪避灰小字）；阵亡=右倾倒下+右移+淡出后隐藏；玩家行动先播卡牌跳跃再结算逻辑（先动画后判定）。**选目标**：目标为自己免选、多目标存活数≤所需自动判定；卡牌蒙版金/灰标识可选，点后校验 `当前可选集合`。**子菜单**：技能行/道具行各自模板，冷却与战斗可用过滤。**回退**=右键反悔回动作栏。卡牌演出参数全 Inspector 可调。

## 5. 亮点与问题

**亮点**：中文命名+详尽注释可读性极高；事件驱动解耦彻底（`面板操作` 纯领域+发事件典范）；静态共享工具（按钮预制体/行构建）复用充分；DOTween 纪律统一（SetUpdate/SetLink/Kill）；多处"未接线降级"（旧样式回退、详情区退日志）保证场景改造前可玩；战斗演出队列设计精巧。

**问题**：
1. **订阅泄漏不一致**：仅探索面板 OnDestroy 解绑，其余 Awake 订阅永不退订（常驻对象尚可，若面板动态销毁会悬挂）。
2. **NRE 风险**：日志面板 `当前时间()` 直接取 `玩家.档案` 无空判（主菜单时可能崩）；战斗面板 `攻击/技能/道具/逃跑/继续` 按钮无空判，与 `切换武器/增幅` 的判空不一致。
3. **耦合点**：面板管理器按字符串路由"功能标识"、探索面板 switch 服务动作字符串、`创建行` 依赖"文字"子节点路径——均为隐式约定。
4. **轮询**：侧边栏 Update 每帧比对取消文案（廉价但可事件化）。
5. **陈旧注释/路由**：主视窗注释称"战斗/探索暂路由到空框架"，实际已拆出独立面板。
6. **隐患**：面板未激活时 `入队演出` 会积压片段（`处理行动轮换` 有 inactive 分支但伤害事件没有）；`设施工厂.创建` 每次双击新建逻辑实例；买卖面板价格比较内联 `/2` 与卖出价公式重复实现。
7. **一致性**：旧样式残留（训练/教学/恢复/睡觉未升级新布局），与新面板两套范式并存；`双击检测` 用 `Time.time` 暂停时会失效（影响轻微）。

---

**结论**：UI 层架构清晰、事件驱动彻底、过渡与演出打磨精细，是典型的"逻辑/UI 强分离"实践；主要债务在空安全不统一、订阅生命周期管理与两套面板范式并存，属于可渐进重构的局部问题，不影响整体可维护性。
