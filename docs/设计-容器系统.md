# 设计 · 容器系统（塔科夫式嵌套容器）

> 状态：设计中。配套：`背包服务`（网格算法复用）、`容器服务`（新增）、`容器面板`（新增 UI）、`物品堆叠`（容器实例字段）。

## 一、核心概念

**容器（Container）= 一个有内部网格空间的物品。** 容器本身是背包里的一格物品，双击打开显示内部网格，可往里放东西；容器随物品存档。背包本身也是容器（`背包` 槽物品的 `容器物品` = 主背包内容）。

**复用原则**：容器内部就是"迷你网格背包"，完全复用 `背包服务` 的网格机制（可放置/移动/换位/堆叠/布局安全/区域互换），不另造轮子。

## 二、已确认的设计决策

| # | 决策 | 定稿 |
|---|---|---|
| 1 | 负重 | 容器内物品**计入玩家负重**（递归累加：主背包 + 各容器内部） |
| 2 | 嵌套深度 | **2 层**：背包 → 容器（第1层）→ 容器（第2层）；第 2 层容器内**不能再放容器** |
| 3 | 容器容量 | **各容器模板固定**容量（如 弹药箱 3×2、医疗包 2×2、背包 4×3）；不随背包装备变化 |
| 4 | 打开交互 | **双击打开**；UI 上额外生成一个独立容器面板（可拖动位置，塔科夫式），可与主背包互相拖拽 |
| 5 | 容器堆叠 | 容器类物品**不可堆叠**（每格一个实例，含独立内部内容） |


## 五、转移机制（容器层与背包层分离时的物品搬运）

### 网格视图抽象

每个可拖拽网格 = 一个 `背包服务` 实例：

| 视图 | 绑定 |
|---|---|
| 主背包 | `档案.背包服务` |
| 容器（打开） | `容器服务.打开(堆叠)` → 背包服务 |

**物品堆叠的 列/行 永远是"所在网格的局部坐标"**——主背包与容器内物品各在各的 `背包服务.背包` 列表，坐标天然不冲突。

### 拖拽流程

1. **拖起**：源面板记录 `(源背包服务, 堆叠)`
2. **拖动**：代理跟随鼠标
3. **放下**：
   - 计算鼠标落在哪个面板网格 → `(目标背包服务, 目标列, 目标行)`
   - **同面板** → 原逻辑（移动/换位/合并，走 `区域互换`/`合并堆叠`）
   - **跨面板** → `容器服务.跨网格转移(源, 堆叠, 目标, 列, 行)`

### 跨网格转移逻辑

```csharp
bool 跨网格转移(背包服务 源, 物品堆叠 堆叠, 背包服务 目标, int 列, int 行)
{
    // ① 目标格同标识可堆叠 → 并入目标堆叠，剩余留源（部分转移）
    // ② 目标格可放置（排除自身）→ 源.移除该堆叠；目标.放入网格堆叠(堆叠)（保留词缀/耐久/品质实例）
    // ③ 嵌套限制：目标 是第2层容器 且 堆叠 是容器 → 拒绝
    // ④ 类型限制：目标容器 容器允许类型 非空 且 堆叠 不符合 → 拒绝
}
```

### 关键点

- **实例保留**：跨网格转移移动整个堆叠对象，用现成 `放入网格堆叠`（已支持"已有实例找空位"）
- **整格转移**：先做整格；数量拆分（Shift 分半）后续扩展
- **关闭容器**：丢弃视图，数据仍存于 `容器堆叠.容器物品`，随物品存档

## 六、UI：容器面板（新增，复用网格背包面板）

- **主背包面板**：现状
- **容器面板**：双击容器物品生成独立面板（可拖动位置），数据源 = 该容器的 `背包服务` 视图
- 拖拽跨面板 = 走 `跨网格转移`（同面板走原逻辑）
- 层级：可同时打开多个容器（各自独立面板）；受 2 层嵌套限制

## 八、存档

`物品堆叠` 新增字段自动被 `JsonUtility` 序列化 → 容器内物品随外层堆叠**递归存档**，`SaveService` 零改动。旧档兼容：`容器物品 == null` → 非容器；`是容器` 的旧物品迁移时初始化空 `容器物品`。

## 九、与现有系统关系

| 现有 | 容器接入 |
|---|---|
| `背包服务` | 容器内部复用同一套网格算法 |
| `网格背包面板` | 容器面板复用渲染/拖拽逻辑 |
| `装备` 背包槽 | 背包槽物品的 `容器物品` = 主背包内容（背包即容器） |
| `负重占用` | 递归含容器内部 |
| `物品数量/持有物品` 等查询 | 后续：可递归查容器内（做"整理/搜索"时） |

## 十、实现顺序（建议）

1. 数据层：`物品数据` 容器字段 + `物品堆叠` 容器字段
2. 领域层：`容器服务`（打开/允许放入/占用格数/跨网格转移）
3. 领域层：`负重占用` 递归
4. UI：`容器面板`（复用渲染）+ 双击打开 + 跨面板拖拽
5. 存档兼容迁移 + 测试
