# 《灰烬镇 · 余烬传说》GDD 改进版（2026-08-17）

> 基于四视角深度分析（独立开发者/架构师/玩法策划/文案数值）产出的**目标版本设计**。
> 现状事实以 `docs/GDD.md` 为准；本文档 = 现状 + 改进方向，逐节标注 `[现状]` / `[改进]` / `[新增]`。
> 优先级符号：🔴P0（阻断，先做） 🟠P1（高） 🟡P2（中） 🟢P3（低/收尾）

---

## 1. 游戏概述与愿景

- 类型：文字奇幻 RPG（回合制战斗 + 地图探索 + 剧情驱动）
- 世界观：余烬 / 守火人——"龙不会死，它只是在沉睡。火必须被重新点燃。"
- **目标体验时长**：主线 ~4-6 小时，全内容 + 刷取 10+ 小时（现状仅 1-2 小时）
- **核心体验升级**：探索资源管理张力（HP/MP 不恢复）× 有记忆点的 Boss 战 × 可重复的掉落/收集循环

### 目标核心循环（完整闭环）

```
剧情 → 地图导航 → 设施强化(收费) → 探索(深度分层+Boss) → 战斗(数值有博弈)
  ▲                                                        │
  └── 成长(属性/技能收费/装备强化/词缀/熟练度) ◄── 金币/材料 ◄─┘
```

## 4. 角色 / 成长系统

### 属性（现状保持 + 平衡修正）
- 体力：+5 生命；力量：+2 物攻；智力：+2 魔攻 +3 魔力；敏捷：+1% 暴击 +1% 闪避 +2 速度
- 🟠**[改进] 敏捷重定价**：暴击系数随敏捷成长（基础 1.5 → 敏捷 10 时 2.0），并给逃跑成功率 +2%/点（配合 `BattleService.逃跑` 的速度差公式）

### 升级
- 🟠**[改进] 升级改为回 50% 生命魔力**（现状满血满蓝，抵消探索血线张力）

### 装备品质（关键修正）
- 🟠**[改进] 装备品质倍率真正生效**：武器/防具加成 × `品质工具.倍率`（`PlayerService` 装备解析改乘品质），拉开优秀/稀有差距
- 🟡**[新增] 装备词条/随机词缀**：史诗以上装备随机 1-2 条词缀（暴击+3%/闪避+3%/速度+2/生命+10/魔力+10），掉落生成并显示；给后期金币真实消耗（重铸/鉴定费），解决"品质 6 档是摆设"与"后期金币通胀"

### 技能学习（经济修正）
- 🟠**[改进] 启用 `技能.价格`**：`技能服务.尝试学习` 按价格扣费（重击 80/防御 60/治愈术 100/火球 150）
- 🟠**[改进] 技能书定位**：火球术书 = 跳过属性前提 / 提前获取的溢价捷径（价格×0.7），与学堂收费教学并存

### 熟练度（降 grind）
- 🟡**[改进]** 训练 +20→+25 点、花费 `30×N`→`25×N`（1→5 级 ~1000 金）；战斗熟练 +1→+2

## 5. 战斗系统

### 数值基线重做（🟠P1）
| 项 | 现状 | 改进 |
|----|------|------|
| 伤害公式 | `攻×倍率 - 防`（平砍、无浮动） | 启用 `战斗规则`：`攻×倍率 - 防/2 + 随机(0..3)`，减防系数 /2 |
| 初始数值 | 50 血 / 攻 11 | 压到 ~35 血，前两场需用药/技能 |
| 重击倍率 | 2.0 | 降到 1.5（缩小与火球的差距） |
| 巨鼠/灰狼/哥布林 | 6/11/14 血 | 10/14/16 血 |
| 火球术 | 倍率 3→×1.5=4.5 碾压 | 数值 3→2（倍率 3）或加冷却 1 |
| 治愈术 | 12×1.2=14（=药水） | 提到 18，或按 `智力×3+基础` 成长 |
| 升级 | 满血满蓝 | 回 50% |

### Buff 全部上岗（🟠P1）
- 🟡**[改进] 新技能挂载 Buff**：淬毒剑（中毒 3 回合）、石肤术（护盾 15）、祝福（攻击强化）、骨蚀（防御削弱）
- 🟡**[改进] 敌人技能化**（复用 `AI行动表/条件/冷却`）：灰狼「撕咬」挂中毒、山怪「重锤」挂眩晕(低命中)、骷髅「骨刺」挂防御削弱、Boss 龙「龙息」全体+自 buff

### Boss 战机制化（🟠P1）
- 🔴[现状] 沉睡之龙 = 大号杂兵（只会普攻）
- 🟠**[改进] 二阶段设计**：血量 <50% 进入"苏醒"，每回合先"龙息蓄力"读条（信息条提示），玩家本回合需防御/喝药否则吃高伤。文字游戏做"读条/预判"成本低、记忆点强
- 🟠**[改进] 敌人抗性表扩大战术分化**（现状只有山怪/骷髅有抗性）

### 战斗面板（现状保持）
信息条旋转行动序 / 卡牌蒙版选目标 / 子菜单 / 右键回退。探索遭遇时序修正见 §6。

## 6. 探索系统（🔴P0 落地 + 丰富化）

### 落地三步（现状：服务旧平面模型 + 无 UI）
1. `区域数据` 重构为 `层[]`（岔路/搜索阈值/通路概率/事件表/Boss）
2. `探索服务` 重写状态机（进入/选岔路/搜索/通路/深入/返回/Boss通关）

### 遭遇时序修正（🔴）
- **[现状]** `探索服务` 遭遇敌人时先开战再发选项 → 战斗在后台静默打完
- **[改进]** 先发"遭遇了X"选项（战斗/逃跑），玩家点战斗才 `打开战斗事件`+`开始战斗`

### 内容规划（🟠）

|------|--------|------|--------|--------|------|
| 橡木林 | 1 | 灰狼/哥布林 | 2、4 | 废弃猎屋→3、精灵泉水→4、**哥布林营地→主线钥匙** | 狼王(HP40/攻12/速16, 低血召唤狼群) |
| 古战场 | 2（补） | 骷髅/亡灵系 | 2、4 | 旧军营遗迹→3/4 | 亡灵骑士(HP45/攻13/物抗0.7, 吸血) |

- 🟡**[新增] 选择类事件**：拾到宝箱→打开可能陷阱/获物；岔路选安全小路 vs 危险捷径（复用剧情选项多分支能力）

## 16. 设计规范速查（保持现状）

- 中文命名参数/函数/注释；`//` 行内注释；不用 `_` 前缀
- UI 场景手动搭，代码只克隆模板+填数据+订阅事件；不用路径字符串
- JSON 存中文，运行时解析枚举；新增内容先过 DataService 校验
- 面板继承 `面板基类`；全局右键=回退
- 地图单击移动/双击进入；战斗点卡牌选目标
