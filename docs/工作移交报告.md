## 一、项目结构

### 1. 代码分层（四层架构，UI ← 事件 ← Services ← Domain ← Data）

```
Assets/Scripts/
├── Core/          组合根与基础设施（3 脚本）
│   ├── GameBootstrap.cs    装配根：注册全部服务 + 挂载时间驱动（幂等，数据校验失败停装）
│   ├── ServiceRegistry.cs  服务注册表（Get<T>/Register）
│   └── EventBus.cs         事件总线（订阅/发布）
├── Data/          数据模型与加载（3 脚本）
│   ├── 数据模型.cs         全部数据类（物品/配方/家具/分区/净化/职业/剧情…）
│   ├── DataService.cs      Resources.Load 加载 JSON + 交叉校验（配方/家具/搜索容器）
│   └── 数据解析.cs         JsonUtility 兼容（中文枚举名 → 字符串）
├── Domain/        领域逻辑（14 脚本，纯 C# 零 UnityEngine 依赖）
│   ├── 玩家档案.cs         数据 + 子管理器装配 + 门面转发（含 物品堆叠：新鲜/生长/净化分钟）
│   ├── 生存管理器.cs       状态增减/睡觉/派生数值（时间结算已迁管理器）
│   ├── 网格服务.cs         塔科夫网格算法（放置/换位/区域交换/堆叠/容器形状块）
│   ├── 容器服务.cs         嵌套容器（弹挂/腰封/背包/弹药箱/冰箱/种植箱）+ 分区容器（净水器 3 区）
│   ├── 持有管理器.cs       统一持有（3 穿戴容器+仓库+嵌套容器递归）
│   ├── 装备管理器.cs       8 槽装备/词缀/穿戴容器
│   ├── 效果结算.cs         剧情/物品效果 → 玩家状态 + 事件发布
│   └── 战斗单位/成长管理器/任务管理器/品质/五行/主线阶段/货币工具
├── Services/      业务服务（19 脚本）
│   ├── 世界时间管理器.cs   ★ 时间中枢：推进/结算/跳时/时钟同步/腐坏/生长/净化/事件（内嵌驱动）
│   ├── PlayerService.cs    新游戏/读档/解析器接线/初始状态发布
│   ├── 工作台制作服务.cs   制作（全局版 + 会话版：输入/输出网格、批量 ×数量）
│   ├── 安全屋管理器.cs     家具建造/升级/修复/拆墙/收音机（含容器家具初始化/拆除保护）
│   ├── 安全屋户型.cs       程序化随机户型（BSP 切块 + 墙可拆）
│   └── 探索服务/搜索服务/地图服务/战斗服务/对话/任务/技能/天赋/词缀/音效/图标/存档/自动存档/物品图标
├── Events/        事件定义（5 脚本：事件定义/剧情/导航/战斗/探索）
├── UI/            面板层（64 脚本，全场景手动搭建 + 引用位）
│   ├── 框架/       面板基类/面板管理器/UI工具/游戏主题/背景模糊/玩家输入/悬停反馈
│   ├── 背包/       网格面板基类（4 partial）+ 物品/家具 子类（输入/输出网格）+ 浮动面板基类
│   │              + 容器/净水器/制作面板（浮层宿主）+ 安全屋/持有/仓库/搜索/建造…
│   ├── HUD/        状态栏 + 侧边栏 + 日志
│   └── 战斗/探索/地图/角色/主菜单/功能面板/浮层
└── Editor/        地图设计器工具
```

### 2. 网格组件与浮层宿主（v35 后架构归位）

## 二、功能系统

### 已实现（v1\~v35 基础上 + v35 后）

| 系统               | 说明                                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **HUD 状态栏**      | 常驻顶栏 6 项：生命(红)/精力(金)/饱食(绿)/水分(蓝)/时间(灰蓝)/地点(灰)。数字去标签，饱食/水分一位小数。事件驱动 + 轮询兜底双保险实时刷新                                                      |
| **世界时间管理器**      | 统一时间中枢：挂机推进（1现实分=30游戏分，一天48现实分）、整点结算、制作跳时、睡觉跳时、跨天随机天气、时钟同步防重复结算。**另挂 腐坏结算/生长结算/净化推进**                                                 |

| **塔科夫式网格背包**     | 3 穿戴容器 + 仓库 + 嵌套容器；拖拽/旋转/换位/堆叠/存入容器；容器形状块 + **格子投影**（逐格贴合口袋）                                                                          |
| **物品体系**         | 九大类型 + 二级分类；字段三合一；按 类型/部位/种类 一文件一组织                                                                                                   |
| **装备系统**         | 8 槽位 + 穿戴容器；品质/词缀；耐久                                                                                                                  |
| **安全屋**          | 程序化随机户型（种子存档）；家具建造/升级/修复/拆除（0级破损=效率减半；容器家具拆除前必须取空）                                                                                    |

| **净水器（3 分区）**    | 脏水区(3×3)/过滤区(3×2 木炭)/净水区(3×3)；**自动净化**：每 60 游戏分钟 脏水1+木炭1 → 水1（时间驱动，缺料/满冻结，进度随档）；灶台净化水配方并存（脏水+木炭→水）                                    |
| **制作系统（会话版）**    | 浮动 制作面板：配方列表 → 材料拖入 输入网格 → 点制作 → 进度条动画（Slider+文本）→ 产物入 输出网格 → 拖回背包；**一次做多个**（数量滑条/加减/输入框）；材料放多也允许（只扣需要量）；关闭自动返还输入剩料+输出成品；制作中关闭=取消（回滚） |
| **浮层面板体系**       | 容器面板/净水器面板/制作面板 统一浮动壳（Canvas 顶层、防重、拖拽、置顶、限屏）；浮层底座空白拦截拖拽，不穿透下层网格                                                                       |
| **生存循环**         | 饱食/水分/疲劳/伤病/天气/睡觉推进次日                                                                                                                 |
| **探索/搜索/战斗**     | 区域探索 + 地图搜索（箱中箱；家用冰箱可得 生鲜/脏水/种子）；回合制战斗                                                                                                |
| **存档**           | PlayerPrefs JSON 快照（v4）；自动存档；物品堆叠 新增 新鲜/生长/净化分钟 随档（旧档缺省=0 惰性初始化）                                                                      |

## 三、工作流程（信息链路）

### 1. 状态变化链路（数据 → 事件 → UI）

```
玩家档案（数据源）
   ↓ 修改（生存管理器/世界时间管理器/效果结算…）
EventBus（事件总线）
   ↓ 发布
HUD面板 / 各浮动面板（订阅事件：生命/魔力/生存状态/时间/背包变化…）
   ↓ 兜底
Update 轮询（对比档案缓存；净水器面板 0.5s 刷净化进度）
```

### 2. 时间链路（统一走 世界时间管理器）

```
世界时间管理器（唯一入口）
├── 推进(现实秒)        ← 挂机驱动（每帧）→ 净化推进 + 生长推进
├── 结算时间段(分,含饱水) ← 整点结算 / 制作补副作用 → 腐坏 结算（生长/净化 不在此——已逐帧）
├── 跳时(游戏分钟)      ← 制作动画 → 净化推进 + 生长推进（两条时间流都覆盖）
└── 同步整点基准()      ← 外部跳时/取消回滚
        ↓
玩家档案.游戏分钟数 + 饱食度/水分度(float) + 堆叠.新鲜/生长/净化分钟
        ↓
事件发布 → HUD 刷新
```

### 3. 制作链路（会话版，两步 + 动画）

```
选配方 → 拖材料入 输入网格（真实移入会话）
   ↓ 点制作（数量 = 滑条/输入框）
开始制作_会话（校验 输入网格×数量 + 扣精力×数量）
   ↓ 动画（进度条 0→100% + 跳时推进时间）
结算制作_会话（输入网格扣料×数量 → 产物入 输出网格 ×数量）
   ↓ 输出区满 → 回滚（材料退回输入区/精力/时间/饱水全返还）
   ↓ 关闭面板 → 输入剩料+输出成品 自动返还玩家（背包/仓库）；背包满 → 拒绝关闭
```

### 4. 净化链路（时间驱动，无按钮）

```
世界时间管理器 推进/跳时
   ↓ 净化推进(净水器.净化分钟 -= 时间；惰性初始化补满)
材料齐（脏水区有脏水 且 过滤区有木炭）且 净水区可放 → 倒计时
   ↓ 到 0 → 自动：脏水-1 + 木炭-1 → 净水区 +水1 → 自动续下一批
缺料/净水区满 → 冻结进度（条件恢复继续，不浪费）
   ↓ 出水面板 0.5s 轮询刷新（滑条 + 距下批出水 X 分钟）
```

### 5. 服务装配链路（GameBootstrap）

```
EventBus → DataService（校验）→ SaveService → PlayerService（初始化+解析器接线）
→ 世界时间管理器 → 容器/搜索/安全屋/制作/对话/任务/战斗/探索/技能/天赋/词缀/地图
→ 自动存档器 → 挂载时间驱动
```

### 6. 存档链路

```
保存：玩家档案 → JsonUtility → PlayerPrefs(v4 键)
读取：反序列化 → 接线解析器 → 清理非法值 → 发布初始状态
版本：v4（饱食/水分 float；物品堆叠 新增 新鲜/生长/净化分钟——缺省 0 惰性初始化，无需升档）
```

### 7. 日志链路（v39 后）

```
各系统 发布 日志事件(类型, 文本, 过程?)
   ├─ 类型：8 类 → 徽章色（游戏主题.日志色/日志标签）
   ├─ 过程=true：战斗逐条 —— 仅展示 不沉淀历史
   └─ 非过程：显示 + 沉淀 会话历史（内存，不随档）
        ↓ 日志面板（左下消息流）
   显示壳(alpha=1) → 条目 创建 → 停留 6s → 淡出销毁
        ↓ 条目全空
   壳自动隐藏（alpha=0）
调试/接线错误 → 不走日志事件，直接 Console（Debug.Log/Warning）
```

### 家具数据

```
标识 / 名称 / 描述 / 材料[] / 最大等级 / 功能类型(睡觉|制作|仓库|情报|取暖|…|净化)
形状宽高 / 升级[](材料+容器列行) / 效果[](按等级)
容器列行 / 容器允许类型(类型|类型) / 容器允许种类(种类|种类) / 保质期倍率[3,5,8]
容器分区[]（名称/列行/允许类型/允许种类）   ← 分区容器（净水器 3 区）
净化间隔分 / 净化材料A / 净化材料B / 净化产物 / 净化产物数量   ← 自动净化
0级=破损（可用但效率减半）；未建=无效果；储物箱例外不缩水
```

### 家具升级需求（v38 新增字段）

```
材料 / 形状宽高(-1=不变) / 容器列行(-1=不变) / 容器分区[]（升级后 分区容器 各 子区 尺寸）
净水器 等 分区容器 升级：按 升级需求.容器分区 更新 子容器 网格 列/行（容器服务.更新分区尺寸）——允许 类型/种类 沿用 家具定义.容器分区
```

### 关键约定

- **图标 = 标识**（`Resources/物品图标/<标识>.png`）

- **网格格尺寸 = 90**；**块缝隙宽 = 10**；容器物品必须落单块内

- **浮动面板**：锚点居中、宽高以预制体为准（代码不覆盖）；显隐用父节点

- **时间速率**：1 现实分 = 30 游戏分；一天 48 现实分

- **基础消耗**：每游戏时 饱食2 / 水分2（float 精确 0.1）

- **制作动画**：时长 = 制作时间分 ÷ 10 现实秒

- **净化速率**：净水器 = 每 60 游戏分钟 1 单位（家具数据可调）

- **场景搭建**：UI 全场景手动搭建 + `[SerializeField]` 引用位（无代码找路径）

## 六、开发注意事项（坑与约定）

1. **编码**：全中文命名；JSON/C# 必须 UTF-8 无 BOM；pwsh 读写中文需显式编码；字符串插值中文用 `${变量}`
2. **场景**：UI 手动搭建 + 引用位；浮动面板 宽高以预制体为准、锚点居中；代码不覆盖 sizeDelta
3. **数据**：改物品标识 → 同步 配方/图标文件名/快速测试面板/搜索容器引用；json+meta 成对（GUID 固定）；家具字段名变动会断预制体引用（抽壳时引用留子类原名）
4. **时间**：任何推进时间必须走 世界时间管理器（禁止直接改 游戏分钟数）；腐坏 在 结算时间段（整点批量）、**生长/净化 在 推进+跳时**（两条时间流都覆盖，逐帧平滑；勿把 生长/净化 放回 结算时间段——会与逐帧双扣）
5. **存档**：物品堆叠新增字段缺省 0 → 惰性初始化兼容（无需升档）；结构破坏性变动才升版本
6. **动态面板**：动态创建/销毁的面板（浮动面板/网格）必须 OnDestroy 取消 EventBus 订阅，否则残留订阅撞已销毁实例（MissingReferenceException）
7. **网格**：改渲染前先查 块偏移 链路（计算块偏移→格x/格y→定位→投影→边界线）；浮层命中判定找 `浮动宿主`（GetComponentInParent<浮动面板基类>）防穿透
8. **验证**：Unity 刷新运行验证；数据校验看 GameBootstrap 日志（校验错误停装）
9. **HUD 调控**：HUD 须挂 Canvas 顶层独立（非任何面板子物体），由 面板管理器.HUD 引用位 控制显隐（主菜单/角色创建 隐藏）；场景 未 接线 需 手动 拖 引用
10. **分区容器升级**：净水器 等 升级 改 子区 尺寸 走 家具升级需求.容器分区（升级时 容器服务.更新分区尺寸）；允许 类型/种类 沿用 家具定义.容器分区
