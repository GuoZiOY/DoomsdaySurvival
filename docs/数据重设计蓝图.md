## 一 设计总纲

1. **每件物品至少一条消费方**：直接使用 / 配方材料 / 家具建造·升级材料。做不到就**删掉**，不挂着当垃圾。
2. **梯度必须单调**：品质↑数值↑；敌人等级↑威胁↑；天赋点数↑强度↑；家具等级↑效果↑。
3. **取舍优于堆数值**：用负值制造选择（重甲潜行↓、消音器攻击↓潜行↑）。
4. **末日口径**：干燥/罐头/密封不腐坏、现做熟食短保；军用/警用/消防/战术款只能搜刮，低级基础款能自制。
5. **不发明机制之外的数据**：没系统的功能只用现成机制（家具材料/配方/区域解锁）承接。
