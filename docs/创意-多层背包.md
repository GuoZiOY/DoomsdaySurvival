# 创意备忘 · 多层背包（Multi-Layer Backpack）

> 状态：**未实现 · 待定**。仅作创意想法记录，后续想实现时再评估。
> 提出背景：单页网格容量受仓库宽限制（格尺寸 150 时背包宽最多 6），想突破容量。

## 概念

把单一网格背包拆成**多个「页/层」子网格**，每页是一个格子区，玩家通过**翻页/页标签**切换查看和使用。类似 塔科夫多容器、暗黑多 tab、我的世界多页。

与现有体系关系：背包装备（腰包/战术/登山包/多层背包）决定「页数 + 每页尺寸」，即多层背包是**一种背包装备类型**。

## 优点

- **容量突破**：多页累加，能塞大量物资，契合生存囤货需求。
- **装备维度丰富**：不同背包等级对应不同页数/页尺寸，区分度更强。
- **检索直观**：翻页/标签比超大单页更快定位。

## 代价（需先考虑）

| 项 | 影响 |
|---|---|
| 数据结构 | 背包从一维 `(列,行)` → 三维 `(页,列,行)`；网格操作（放置/移动/换位/合并/放入/可放置）都要带页号；堆叠合并、找空位需**跨页** |
| 拖拽跨页 | 拖到另一页需换页拖拽；限同页拖拽则体验受限 |
| UI | 加 页标签/翻页控件 + 当前页渲染 + 切换刷新（物品/线/底座按当前页） |
| 存档 | 旧档单页 → 迁到第一页 |
| 全局操作 | 物品数量/使用/装备/背包词缀 等要遍历所有页 |

**波及**：玩家档案（背包结构）、网格背包面板（页渲染/拖拽/换页）、面板操作/换装缩容、BattleService 掉落放置、合成/制作产物放置。

## 建议模型（若实现，先冻结）

- 每页尺寸**相同**（简化）。
- 页数**随背包装备变**：腰包 1 页 / 战术 2 页 / 登山 3 页 / 多层背包 N 页。
- 先做**同页拖拽**，跨页拖拽后续。
- 页 UI：标签 或 左右翻页。

## 分步路径（若做）

1. 数据层：背包 → 多页（每页尺寸+堆叠），物品堆叠加 页号；放入网格 跨页找空位。
2. 面板：页标签/翻页 + 当前页渲染 + 切换刷新。
3. 拖拽跨页（后续）。

## 备选方案（成本更低）

- **单页大网格 + 滚动**：Content 尺寸手动撑 + 滚动视窗（已有思路）。容量够、无换页逻辑、改动最小。多数生存游戏够用。
