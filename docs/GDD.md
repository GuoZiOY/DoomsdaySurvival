## 1. 游戏概述

- **类型**：文字奇幻 RPG（回合制战斗 + 地图探索 + 剧情驱动）
- **平台**：PC（Unity 6000，uGUI）
- **题材**：暖暗"余烬"世界观——灰烬镇在龙灾余烬中重建，龙沉睡于山脉深处
- **一句话**：在灰烬余烬的大陆上，走过城镇与荒野，提升自我，追猎沉眠之龙
- **核心体验**：深度分层的探索张力（资源管理 + 随机事件） × 回合制战术战斗 × 剧情分支选择

### 核心玩法循环

```
剧情/对话 ──► 地图导航（大地图→小地图→节点内部）──► 设施强化 / 探索战斗
    ▲                                                    │
    └──────────── 成长（属性/技能/装备/金币） ◄────────────┘
```

## 2. 世界与导航

### 2.1 三级导航（当前基准，见 specs/three-level-navigation）

```
大地图（城镇/荒野大节点）
  └─► 小地图（城镇内：入口/设施/空 节点）
        └─► 节点内部图（任意节点可有 NPC + 功能物）
```

- **大地图**：节点图（灰烬镇/橡木林/古战场/黑石山），逐步沿连线移动
- **小地图**：城镇内部设施节点网络
- **节点内部**：任意节点的内部图——NPC（对话触发剧情）、功能物（打开功能面板）
- **三级内功能面板**：从节点内部的功能物进入（买卖/训练/教学/任务/恢复/睡觉）

### 2.2 地图交互

| 操作 | 行为 |
|------|------|
| 单击节点 | 沿互通路径移动一步（非互通 → "那里无法直接到达。"失败反馈） |
| 双击节点 | 进入节点（需已站在该节点；未到达 → 失败反馈） |
| 拖拽空白 | 平移地图 |
| 滚轮 | 缩放（0.6×~2×，以光标为锚点） |
| 平移限制 | 内容边缘不超出可视范围；缩小可拖、放大贴边 |

- 数据模型：`map.json`——`地图地点`（城镇/荒野，含 连接/解锁物品/区域/入口节点/小地图）+ `地图节点`（类型/设施/内部图）
- 编辑工具：地图设计器（编辑器可视化编辑，反写 JSON，`map.json.bak` 备份）

### 2.3 荒野节点 → 探索系统

荒野大节点进入后打开**探索系统**（见 §7），不再用旧的闯关式野外面板。

## 3. 角色系统（见 specs/character-system-design）

- **四维基础属性**：体力 / 力量 / 智力 / 敏捷
- **升级**：每级 +3 自由属性点，自行分配（只能加不能减）
- **派生属性**：生命、魔力、物理/魔法攻击、物理/魔法防御、暴击率、闪避率（由基础属性推导）
- **装备**：武器 / 防具（物品类型驱动，购买直接装备）
- **角色面板**：全局面板（属性 + 加点 + 装备 + 背包），从 HUD 打开

### 技能系统

- **获取途径**：武馆教学 / 学堂 / 技能书 / 剧情——属性前提达标才能学
- **熟练度**：1~5 级，每级 +10% 伤害 / -5% 消耗；训练花费 `30×N` 金
- **品质**：6 档（普通→传奇）×1.0→×3.0，横切物品与技能
- **技能数据**：类别（物攻/魔攻/辅助）、目标（单体/全体/自己/敌方）、伤害类型、消耗魔力、冷却、挂载 Buff

## 4. 战斗系统（已实现）

### 4.1 回合制流程

- **速度队列**：按速度排行动序，每回合（全员各动一次）重新排序
- **敌人 AI**：行动表 + 权重 + 条件，按目标策略选目标
- **敌方节奏**：敌方行动停顿 + 行动跳跃动画，让玩家看清

### 4.2 伤害管线

```
命中判定 → 暴击判定 → 伤害类型分流（物理/魔法/真实）
  → 抗性表 → 防御减免 → 应用
```

- **伤害类型**：物理 / 魔法 / 真实（留扩展接口）
- **抗性表**：枚举 + 抗性配置，可扩展
- **命中/暴击/闪避**：属性驱动

### 4.3 Buff 系统（buffs.json）

- **类型**：增益 / 减益 / 异常 / 护盾
- 叠层 / 计时 / 持续伤害 / 控制（眩晕等无法行动）
- 战斗结束即清

### 4.4 战斗动作

- **普攻**：内置技能（倍率 1.0 物理无消耗）
- **技能**：消耗魔力（不足 → 失败反馈），冷却管理
- **道具**：战斗内使用（治疗/增益）
- **逃跑**：速度差概率

### 4.5 结算

- **胜利**：经验/金币/掉落 → 结算回写玩家档案
- **失败**：掉 10% 金币 + 回城满状态
- **探索战斗**：`__探索胜利`/`__探索返回` 特殊结果节点，回探索界面

### 4.6 战斗面板交互

- 信息条（回合 + 行动序旋转显示：当前金色/下一步钢蓝/排队正文色/已行动删除线）
- 文字血条卡牌 + 蒙版高亮选目标（可选/不可选着色）
- 技能/道具子菜单 → 选目标 → 结算；右键取消/回退
- 复用主日志栏记录战况

## 5. 探索系统（设计稿，待实现，见 specs/探索系统）

### 5.1 定位

深度分层的野外区域：浅层补给 → 中层战斗/拾取 → 深层剧情/Boss。

### 5.2 核心循环

```
进入区域 → 第1层 → 反复[搜索]触发本层事件表
  → 搜满阈值后随机触发"发现通路" → [深入]解锁 → 下探 → … → Boss层 → 通关
```

- **张力**：HP/MP 带入不恢复 → 血线下降 → 决策"再搜 or 见好就收"
- **通路机制**：层内搜索满阈值（默认3次）后，每次搜索掷通路概率（默认0.5）；成功 → "发现通路"解锁 [深入]；失败 → 正常走层内事件
- **岔路层**：进入时先选安全小路/危险捷径，锁定本层事件表

### 5.3 数据模型

```
区域: 标识/名称/描述/危险度/通关文案/层[]
层:  编号/描述/搜索阈值?/通路概率?/事件表 或 岔路{安全表,危险表}/Boss组?
事件表: 遭遇[] + 资源[] + 发现[] + 无事文本[]
```

### 5.4 结算与状态

- 战斗失败：掉10%金币 + 回城满状态（沿用现有）
- 通关：Boss 打败 → 区域标记通关（存玩家档案）→ 可再刷（Boss 不再出现）
- 发现地点 → 剧情节点 → 回到区域

### 5.5 面板

```
┌──────────────────────────────┐
│ 区域名 · 危险度:低    层 2/5   │ 信息条
│ 层描述/事件文本                │ 正文区
│ [搜索] [返回] / [搜索][深入][返回] │ 动作区
└──────────────────────────────┘
```

## 6. 设施系统

设施 = 城镇节点内部的功能物，通过三级导航进入：

| 设施 | 功能 | 实现 |
|------|------|------|
| 商店 / 武馆兵器 / 学堂魔法物 | 买卖（购买/卖出，按判定筛选商品） | 买卖逻辑 |
| 训练场 / 武馆 / 学堂 | 属性训练 + 技能熟练训练 | 训练逻辑 |
| 学堂 | 技能教学（属性前提） | 技能服务 |
| 任务板 | 任务接取/交付 | 任务服务 |
| 恢复点 | 付费恢复生命魔力 | 恢复逻辑 |
| 家/客栈 | 睡觉休息 | 睡觉逻辑 |

- 架构：`设施工厂` 创建逻辑类 → `功能接口`（教学/买卖/训练/恢复/睡觉）→ 设施功能面板基类（标题+内容区+返回）渲染

## 11. UI / UX

### 11.1 三级 UI 结构

```
L1 主菜单（进入/继续）
L2 常驻 UI：HUD条 / 主视窗框架 / 日志面板 / 底部状态栏 / 游戏时钟
L3 内容面板（主视窗内切换）：对话 / 战斗 / 地图(大/小/节点内部) / 探索 / 功能面板
```

### 11.3 视觉语言（"余烬"）

- **配色 Token**（游戏主题.cs）：炭黑背景、面板底、按钮底、羊皮纸白文字、暗淡灰、余烬金、血烬红、苔绿、暮紫、钢蓝（选中）
- **字体层级**：正文/标题统一，日志动态可调字号

### 11.4 音频（已实现）

| 音效 | 触发 |
|------|------|
| 背景音乐 | 循环播放（音效管理器，音乐源 loop） |
| 按钮成功音效 | 所有按钮点击成功（代码自动注册：场景扫描 + 创建点注册） |

- 接线：音效管理器单例，Inspector 拖 3 个 AudioClip

## 12. 技术架构（见 specs/modular-game-framework）

```
表现层（uGUI 面板） ← 事件 ← 应用层（服务） ← 领域层（纯C#） ← 数据层（JSON）
```

- **单向依赖**：逻辑永不调 UI，只发事件；UI 订阅事件路由
- **ServiceRegistry**：服务注册表；**EventBus**：事件总线（异常隔离、日志即事件）
- **领域层纯 C#**：零 UnityEngine 依赖，可快速单测
- **数据驱动**：所有内容 JSON（map/story/skills/items/enemies/encounters/buffs/regions/quests/training/facilities），启动全量校验
- **数据解析**：JSON 存中文枚举字符串，运行时解析为枚举（规避 JsonUtility 中文枚举坑）
- **设施**：定义 JSON + 逻辑类 + 面板（三块积木，核心零改动扩展）

## 15. 附：设计规范速查

- 命名：中文命名参数/函数/注释；`//` 行内注释（不用 `/// <summary>`）；不支持下划线前缀
- UI：场景手动搭建，代码只克隆模板 + 填数据 + 订阅事件；不用路径字符串查找（Inspector 拖拽绑定）
- 数据：JSON 存中文，运行时解析枚举；新增内容先过 DataService 校验
- 面板：继承 面板基类（内容区/刷新/回退/创建行）；全局右键 = 回退
- 交互：地图单击移动/双击进入；战斗点卡牌选目标；右键取消
