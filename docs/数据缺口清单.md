## 二、五类缺口（带证据）

### A 硬缺口：数据文件不存在，系统空转

1. **`Resources/Data/story.json` 不存在**：`DataService` 只打一句警告（`[数据] 缺失 Data/story.json`），
   剧情字典恒为空 → `DialogueService.进入节点()` 一定报"节点不存在"。
2. **`Resources/Data/quests.json` 不存在**：任务字典恒为空 → `QuestService.接取()` 恒返回 false。
3. **入口还只写了一半**：`Assets/Scripts/Services/玩家/PlayerService.cs` 新游戏时
   `档案.当前节点 = "开局_醒来";` —— 只是**记了个名字**，**没有** `进入节点()`，
   也没有发布 `打开对话事件`。→ 就算把 story.json 写好，序章也不会自动播（得补 1 行接线）。
4. **"获得物品"类任务是死链**：`QuestService.记录获得()` **全仓库 0 个调用方**
   （只有 `记录击败()` 有：`BattleService.伤害与结算.cs` 敌人死亡处）。
   → 现在写"收集 5 个绷带"这种任务，玩家永远完不成。

### B 有名无实：引用悬空（跑得起来，但永不生效）

`Tools/数据引用核对.ps1` §8 会把前两条打成 **⚠（只提示、不判失败）**，所以一直没拦住：

| 悬空项 | 处数 | 后果 |
|---|---|---|
| `职业.初始技能` | **4**：近战精通（退役军人）/ 制作（消防员·大学生）/ 侦察（记者） | 这 4 个职业**开局学不到东西**（`TryGetValue` 失败 → 静默跳过） |
| `职业.天赋` | **6**：战术本能 / 铁骨 / 美食家 / 职业嗅觉 / 学霸 / 职业操守 | 塞进 `档案.天赋` 但**永不生效**（`PlayerService.应用天赋` 查不到就 continue；角色创建面板也不显示） |

## 三、建议的补充顺序（按 demo 价值 ÷ 成本）

**P0 —— 一天内能让 demo "看起来是完整的"**
1. `story.json` 序章：`开局_醒来` 起一条链（醒来 → 搜刮 → 首次选择 → 强制战斗 `战斗:感染者伏击:节点` → `地图:` 进大世界 → `__结束`），**同时补新游戏入口那 1 行接线**。
2. `quests.json` 8~12 条：优先"击败"类（可用），"获得物品"类要么先不用、要么顺手把 `记录获得` 接到获得物品的唯一入口上。
3. **搜索表增补（性价比最高）**：把 16 件配件、8 把枪、基础防具（头盔/胸甲/背包）、两本配方书塞进对应的
   `搜索_地图类型.json` 容器里 —— 一次改动直接点亮 **改装 / 弹匣 / 书籍** 三个已做完的系统。

**P1 —— 让各系统"有东西可用"**
4. `职业.json` 10 处悬空：最便宜的一条（补 4 个技能 + 6 个天赋，或改成指向已有条目）→ 让 6 个职业都真的有开局差异。
5. `buffs.json` 3 → 10~12 条，并把 21 个技能按类别挂钩（中毒/骨折/感染/出血/麻痹）。
6. 敌人 9 → 14 只，掉落 5/9 → 9/9；敌人组补"夜间组 / 精英组 / Boss 组"。
7. `助战组` 2~3 组（剧情战斗的伙伴，字段与校验都已就绪）。

**P2 —— 厚度与长期**
8. `情报.json` 9 → 20 条；世界区域解锁条件（物品 / 天数）；`房间模板.敌人数量` 填区间。

## 四、怎么复算这些数字

```powershell
# ① 各表条数（UTF8 读，否则中文键会乱码）
$D="Assets/Resources/Data"; function J($p){ Get-Content $p -Raw -Encoding UTF8 | ConvertFrom-Json }
"enemies " + (J "$D/enemies.json").敌人.Count
"skills  " + (J "$D/skills.json").技能.Count
"buffs   " + (J "$D/buffs.json").Buffs.Count
"情报    " + (J "$D/情报.json").情报.Count
"story   " + (Test-Path "$D/story.json") + "  quests " + (Test-Path "$D/quests.json")

# ② 悬空引用（10 处）与数据可达率：直接看现成的门禁
powershell -NoProfile -ExecutionPolicy Bypass -File "Tools/数据引用核对.ps1"   # §8 报 10 处悬空

# ③ 可达率明细：把"引用来源"全收集一遍，再与 285 件物品对照
#    （字段名坑：搜索表的池子叫 `搜索表`，不是 `物品池`；区域模板的街上敌人字段叫 `敌人`）
```

⚠ 本文提到的 `Resources/Data/story.json`、`Resources/Data/quests.json` **是有意不存在的**（就是缺口的本体），
不要把它们当成"文档写错了路径"。
