## 二 家具

### 2.1 建造 / 升级 / 修复 / 拆除规则

1. **建造材料必须"开局就能凑"**（木板/钉子/金属零件 可造，铁皮能搜到）—— 否则第一个制作站就卡住。
2. **升级材料才逐步引入功能件**（电子/电力/贵重/日用品）—— 让"搜到的杂物"有去处。
3. **禁止循环**：家具的建造/升级材料，不许是"需要这台家具本身（或更高等级）才能做出来的东西"。
4. **门不可升级**：最大等级 **1**，`效果 [1]` —— **没有防护系统 → 升级无收益，索性不给升级入口**。
5. 家具效果均为**等级阶梯**（`效果` 数组按等级取值），升级只抬效果、不改变机制；**种植箱/晾晒架/厕所**是等级加速/加成类。
6. **修复 / 拆除**：家具按 `最大耐久` 消耗，修复按当前等级与受损量收材料（同建造/升级口径）；拆除返还按建造材料折算。

### 2.3 家具升级的"材料 → 收益"核对

> 升满总材料见 §2.2 各行累加。**必升**：工作台（解锁 Lv2/Lv3 全部配方）、医疗站（解锁 Lv2/Lv3 医疗）。
> 收益/成本比最划算的是储物箱（仓库 10 → 30 行，**+400 格**）；箱 冰箱 保鲜 ×3→×8 要配"熟食短保"才有意义；
> 收音机情报 Lv1→Lv3 要配 21 条情报才有内容；**门不升级，成本最低**。

### 2.4 家具的链路约束

- **`铁皮` = 前期最重要的搜刮目标**：`制作_铁皮` 需要 **工作台 Lv2**，而 工作台/灶台/冰箱/净水器 的**建造**都要铁皮
  → 玩家必须**先搜到铁皮**才能起步。搜刮里铁皮有 **7 个容器**（工厂/五金店/街区…）→ 够。
- **晾晒架**：与种植箱/净水器同类的**自动转化家具**，不在配方站之列。它和种植箱**共用一套字段 + 一个推进器**
  （`生长时间`/`成熟产物`），靠 `转化用途` 分开：种子归种植箱、生肉/兽皮归晾晒架（互不串门，见 `项目现状.md` §六 #58）。
