## 一、demo 的"一次完整游玩"（验收主线）

新游戏建档 → 安全屋（整理背包/工作台/灶台/睡觉）→ 出门进**大世界 100×100** → 搜索翻出临时建筑/容器 →
走到**区域副本**门口进入（32×22）→ 进**建筑楼层** → 进**房间** → 撞上敌人打一场（即时制行动条）→
搜刮尸体/容器 → 回安全屋存档 → 下一次出门带回更多东西。

**验收标准**：上面这条链**每一步都能走通、都有反馈、都不卡**，且全程 Console 无红字。

## 三、三个"空转系统"（**代码全在，只缺数据** → demo 最高性价比）

> 这三块是末日改造时"内容层待重建"留下的洞：服务、数据模型、UI 面板、存档字段**都写好了**，
> 但 `story.json` / `quests.json` / `affixes.json` 当年被删掉后没重建（`be721a7` 删了 26 个奇幻 JSON）。

| 系统 | 现状（实证） | 后果 | 补齐代价 |
|---|---|---|---|
| **装备词缀** | `词缀服务.抽取池` 遍历 `数据.词缀.Values`，字典为空 → `生成()` 返回 null | 打到/做出来的装备**永远没有词条**；`词缀条` 那套存档字段全在睡觉 | **小**：只写 `affixes.json`（数据模型已定：品质/属性/数值区间/权重） |
| **剧情对话** | `DialogueService` 查 `数据.剧情` → 空字典 → 每次进对话 `LogError 节点不存在` | 没有任何叙事、没有 NPC 台词；demo 只有"打和搜" | **中**：写 `story.json` + 找入口挂 NPC/事件 |
| **任务** | `QuestService` 读 `数据.任务` → 空；`剧情效果.接取任务` 无处可指 | 没有目标、没有奖励闭环；玩家不知道"该干什么" | **中**：写 `quests.json` + 在对话里接取 |

**这三块补完，demo 才从"沙盒"变成"有目标的游戏"** —— 排在内容工作的第一位。

## 附：本文数字的取得方式（可复现）

```powershell
# 物品/敌人/技能/区域… 条目数
Get-ChildItem "Assets\Resources\Data" -Filter *.json | ForEach-Object {
  $t = [System.IO.File]::ReadAllText($_.FullName, [System.Text.Encoding]::UTF8)
  "{0,-22} {1,4}" -f $_.Name, ([regex]::Matches($t, '"标识"\s*:')).Count
}
# 物品（含子目录）
(Get-ChildItem "Assets\Resources\Data\物品" -Recurse -Filter *.json |
  ForEach-Object { ([regex]::Matches([System.IO.File]::ReadAllText($_.FullName, [System.Text.Encoding]::UTF8), '"标识"\s*:')).Count } |
  Measure-Object -Sum).Sum
```
