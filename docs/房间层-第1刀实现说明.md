# 房间层 · 第 1 刀 实现说明

> 项目：《最后87天》 ｜ 范围：**只做「房间」这一层**（四层结构：世界 → 区域 → 建筑 → 房间）
> 状态：**已实现并通过离线验证**（600 房间 0 失败）｜ 设计依据：`docs/房间层-第1刀设计方案.md`
> 前情：**世界沙盒那一套已撤出**（见第九节），`右键菜单` + `小菜单工具` 保留并继续复用。

## 一、这一刀做成了什么

- 一个**完全中空的大房间**（不做安全屋式分割）：四周一圈墙，地板全空。
- **网格实体层**：墙 / 容器 / 尸体 / 敌人 / 玩家 同构 —— 都占格、挡路；玩家是「阵营 = 玩家」那一条。
- **容器摆放算法**：分区配额 → 约束采样 → 连通校验与重试（保底布局兜底）。
- **A\* 寻路**：点哪走哪，显示路径并沿路径走过去（四方向、固定展开顺序 → 路径可复现）。
- **战争迷雾**：**视线外纯黑**（半径 + 视线遮挡：可见的格子亮，其余一律不透明黑板）。
- **玩家抽象体**：占 1 格的令牌，走 1 格 = 1 游戏分钟（不耗行动点）。
- **敌人**：静态（不动），占格、挡路、只在可见时画；撞上 → 遭遇 → 切现有战斗沙盒；打赢在原地留一具**可搜尸体**。
- **房间网格面板**：继承 `网格面板基类`（与 `家具网格面板` 兄弟）+ 自建五层图层栈。
- **搜索**：右键容器/尸体 → 右键小菜单 →「搜索」扣 10 行动点 + 推时间 → 打开现有搜索面板。

## 三、规则定版（常量在 `房间探索服务`）

| 项 | 值 |
|---|---|
| 走 1 格 | **1 游戏分钟**，**不耗行动点** |
| 移动节奏（表现） | 走一格 = **0.30 现实秒**。令牌**自己走路**：`房间图层.推进移动()` 从**令牌此刻所在的位置**匀速走向"下一步的格子"，**逻辑格在令牌真的踩到格心那一刻才 推进一步**（同帧刷视野/迷雾）。直线走每段正好 1 格 = 0.30 秒；半路改向就从当前位置当场拐弯（多走一截 → 那一步略慢，但位置连续，永不瞬移）。**游戏时间仍是 1 游戏分钟/格**；改节奏只改 `房间探索服务.每格现实秒` |
| 搜索一处 | **首次**打开：**10 行动点** + 5 游戏分钟；**再打开（接着翻）不再扣** |
| 容器不是一次性的 | 容器的战局数据（已生成内容 / 已翻标记 / 拿走的不会回来）**存在 搜索服务 里**，进房间、离开房间都不清 —— 只在**回到安全屋**（`打开营地事件`，即 `地图服务.返回营地`）时整体作废。房间里的「✓ 灰化」问的是 搜索服务（战局进度），不是 `房间实体.已搜`。实例 id = **`房间种子#实体标识`**（同模板换个种子进去就是另一批实物；尸体用战利品容器自己的 id） |
| 视野 | **角色 + 时段**决定（`视野.json` 直接写最终边长：白天 **7** / 夜晚 **3** / 夜弱视野 **5** / 阴影压暗 **0.65**）：白天 7×7 亮 + 看过的地方留 65% 阴影（墙/容器/尸体可辨，敌人不画）；夜晚 3×3 亮 + **3~5 一圈弱视野（只看得见墙）**，看过的也全黑。**敌人永远只在亮区**里画 |
| 先手 | 相邻撞上 = **敌人先手**；视野内 ≥3 格先看见 = **玩家先手** |
| 房间尺寸 | 8×6 ~ 26×18（受 `格尺寸 = 90` 上限约束：一屏 16×10 最稳） |
| 容器 | 由 房间模板.容器池 决定（当前平均 7.0 个/间） |
| 敌人 | 由 房间模板.敌人组 展开后按区间裁剪（当前平均 2.2 只/间） |

## 四、交互（一屏之内只有这几件事）

| 操作 | 结果 |
|---|---|
| 左键点空格 | **点下去当场就有反应**：按钮音效 + 落点圈（金色圆环在目标格 0.30 秒收拢淡出）+ 路径立刻改画；令牌随后走（0.30 秒/格） |
| 左键点容器/敌人/墙 | 走同一条反馈路径（`房间网格面板.点格反馈`）：容器/敌人 = 走到**相邻格**停下（不自动搜）；墙 = 走到墙边，走不到就「那边过不去」+ 错误音 + 闪红 |
| 走的过程中点别处 | **当场拐弯**（不再等这一格走完）：新路径立刻生效、路径高亮立刻重画，令牌从当前位置直接转向前方那一格。视觉连续（永远不会"瞬移一格"）——老 bug 的根因是"固定周期插值 + 中途换方向"，现在令牌位置由自己走出来，换路径只是换目标 |
| 左键点未探索格 | 直接按 A* 走过去（迷雾只影响"看不看得见"，不影响"走不走得过去"） |
| 左键点自己脚下这格 | 站着 = 原地（只高亮这一格）；**正在走 = 不打断**（半路把路径缩成单点会掐断脚下这半步，令牌得往回跳） |
| **右键点容器/尸体** | **必须先走到它旁边（正交相邻）**：相邻 → 弹菜单 **搜索**（没翻过）/ **接着翻**（翻过，不再扣行动点）/ 查看（走日志播报）；太远 → 菜单只给「**移动到此处**」，且服务层直接拒绝搜索（"太远了——先走到旁边才能翻。"） |
| 方向键 / WASD | 逐格走（`方向移动` 已就位；场景输入还没接） |
| 侧边栏取消 / `Esc` | 离开房间（回上一个面板）——**不**清容器的战局数据 |
| 拖拽 | **无效**（房间里不搬东西） |

## 五、生成算法与不变量

三阶段：**定尺**（抽容器/敌人清单）→ **分区配额 + 约束采样**（4×3 区块轮流分配；锚点离墙 ≥1 格、占位物之间 ≥1 格走道、不压入口格）→ **连通校验与重试**（BFS：坏容器/坏敌人剔除 → 低于下限则整间重掷 ≤5 次 → 仍不行走**保底布局**：沿内墙隔格摆一圈 + 敌人中段）。

不变量（验证器逐颗种子断言）：

1. 确定性：同模板 + 同种子 = 同布局（结构指纹一致）；
2. 入口格可通行；容器/敌人不越界、不重叠、不压入口；
3. **每个容器至少一个相邻可站格且可达**；**每个敌人相邻可站格可达**（0 例外）；
4. 可站格连通分量 = 1（无孤岛）；
5. 数量不低于模板下限（保底布局也要满足）。

## 六、图层栈（房间网格面板 自己的五层）

z 从下到上：**底盘 → 底座层 → 地表层 → 线层 → 迷雾层 → 路径层 → 交互层 → 物品层 → 效果层**
（底盘/底座层/线层/物品层 = 基类；其余五层 = `房间图层` 自建）

三条规矩（都有理由）：

- **迷雾在物品层之下**：实体不靠"被遮住"，而是自己按可见性隐藏/压暗 —— 这样"已探索但看不见敌人的实时位置"才成立；
- **路径在迷雾之上、物品之下**：看得见往哪走，又挡不住柜子；
- **交互层在物品层之下**：Unity 取最上层命中 → 点实体优先给实体，空格才落到交互层。

效果层三件（都跟着鼠标/点击走）：**悬停格**（白 8%）/ **不可达闪红**（0.35 秒淡出）/ **落点圈**（点击反馈：金色圆环 `房间贴图.圆环()` + `路径终色`，1.45 格收拢到 1 格并淡出，0.30 秒）。

四个坑（读基类源码得到，改这块务必看）：

1. **面板类里不能再写 `void Update()`**：基类 `Update` 是 `private`，子类再写会隐藏它，基类的刷新调度整个失效 → 每帧逻辑都在 `房间图层`；
2. **路径高亮不能蹭基类的"投影格"**：基类无拖拽时会 `隐藏全部投影`，路径会被每帧抹掉 → 必须自建路径层；
3. **基类 `销毁网格结构` 只销毁它自己那四层** → 自建层由 `房间图层` 按 `渲染列/渲染行/物品层序号` 变化自行重建 + 重排；
4. **`形状解析` 必须能解析 墙/尸体/敌人/玩家 这些非物品标识**（返回 1×1），否则占格算错 → 由 `房间探索服务.同步网格()` 维护形状表。

## 八、接线与试玩

### 方式 A（推荐）：一键搭建（Editor 菜单，Unity 自己建对象+接线+存场景）

Unity 菜单：**`末日 / 房间 / 一键搭建面板（场景接线）`**

它会建出这样的层级，并把引用位全部接好（幂等：重跑只补缺，可 Ctrl+Z 撤销）：

```
房间面板（房间面板 + 深色背景）        ← 面板管理器.房间 引用位
└─ 网格容器（1440×900，居中）          ← 房间网格面板.网格容器
     └─ 房间网格面板（网格面板基类）+ 房间图层
```

另有一条 **`末日 / 房间 / 检查接线（列出未接的引用位）`**，运行后在 Console 打印每个引用位接没接。

> 为什么不直接改 `SampleScene.unity`：场景 984 KB / 308 个对象，且 Unity 正开着它——手改 YAML 既容易错，也会被 Unity 回写覆盖。交给 Editor 脚本用 Unity 自己的序列化来建与接，最稳。

### 方式 B：不接线也能进（零接线兜底）

直接 Play → 点屏幕上的「测试」按钮 → 左列 **「房间（第 1 刀）」** → 「进入 便利店门厅 / 药店后间 / 居民房客厅」。

## 十、已知缺口 / 下一刀

- 敌人**静态**（不动、不巡逻）；移动 AI 与警戒环状态未接。
- 不做**多房间分割**（走廊/连廊/广场/户型模板）—— 那是第 2 刀的入口。
- 尸体只有"遭遇的那一只"留一具（其余敌人被清掉不留尸体）。
- 房间不存档：每次进入都按新种子生成（结构靠种子复现，物资随实例走）。
- 移动时间按格数**一次性结算**（视觉上逐格走），不是逐帧推进时钟。
- 表现是**全程序化生成的"简单美术"**（无美术资源）：地板噪点+板缝、墙顶竖纹+转角闭合描边、容器按名称挑剪影（柜/冰箱/纸箱/货架）、尸体躺姿、敌人=圆盘+丧尸剪影+血条、玩家=圆盘+人形+圆环、路径=高亮格+圆点线+终点准星。
  美术给图后放到 `Resources/沙盒贴图/<同名>.png`（`地板` / `墙顶` / `柜子` / `冰箱` / `纸箱` / `货架` / `尸体`）即自动优先使用，不用改代码。

## 十一、基础层改动：物品边界线从「线层」搬到「物品自己身上」

> 触发：物品边界原本由 `线层` 逐格画（`物品边界色` + `物品边界线宽`），而实体框其实各自都挂了 `Outline`（黑描边）——同一件事两套画法；更要紧的是**每次"布局变化"都要把整层线销毁重建**。
> 结论：**只改"线归谁画"，不改任何样式数值**。

| | 改前 | 改后 |
|---|---|---|
| 分格线（`线层`） | 逐条格边查 `该格物品` 决定"亮 / 淡"与粗细 | **统一淡网格**（列+1 竖线 / 行+1 横线），与物品无关 |
| 物品边界线 | `线层` 逐条边画（`物品边界色` A120 / `物品边界线宽` 2px） | **画在物品自己身上**：实体框 4 条细条（同一组常量，数值未动），跟着物品走 |
| 实体框黑描边（`物品描边色` / `物品描边距离`） | 黑 A0.6 / 3px | **不变** |
| 口袋轮廓（容器/家具分块） | 逐块边界查 `块内有物品` 决定是否加粗 | 每块四边独立闭合框，粗细统一（`物品边界线宽`） |
| 物品移动时 | `重画分隔线()` —— 整层线销毁重建 | **不重画**，只改那个框（线是框的子物体，自己跟着走） |
| 删掉的代码 | `竖线边界 / 横线边界 / 块内有物品 / 重画分隔线 / 更新布局快照 / 上次布局` | 全部删除 |
| 新增的帮手 | — | `网格面板基类.建边界线(父)`：4 条拉伸锚点细条贴住实体框四边（尺寸一变线自动跟着变） |

**收益**：
1. 物品边界只由一个东西负责（物品自己），不再有两套可能打架的画法；
2. 去掉每次布局变化的整层重建 —— 16×10 房间每走一步原本要**销毁重建 346 个 Image** + 每条边 2 次 `该格物品` 查表，现在为 **0**；背包里挪一件物品同理；
3. 语义干净：**格线 = 格子参照（与物品无关），物品边界 = 跟着物品走的线**。

**谁调用 `建边界线`**：`物品网格面板`（背包/仓库/容器/穿戴/制作输入输出）、`家具网格面板`（安全屋房间网格）、`房间网格面板`（容器与尸体；墙连成一整片、令牌用圆盘，都不画）。

**留意**：淡网格**不能删** —— 背包空格没有参照就没法摆物品，所以保留"统一淡网格"，只是它不再按物品加粗/变色。
