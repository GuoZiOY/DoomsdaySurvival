## 1. 核心五维属性

每次升级 +3 自由属性点，自行分配（只能加不能减）。

| 属性 | 定位 | 派生影响 |
|------|------|---------|
| 体质 | 生存根基 | 生命上限、负重、饱食/水分耐受（下降更慢）、疲劳抗性 |
| 力量 | 近战与搬运 | 近战伤害、负重上限、破门撬锁 |
| 智慧 | 求生技能 | 制作成功率、医疗效果、侦察、枪械命中、经验获取 |
| 敏捷 | 行动能力 | 速度、闪避、暴击、弓命中、潜行、逃跑 |
| 意志 | 心理防线 | 士气/恐惧抗性、夜晚行动、震慑谈判 |

## 2. 生命与生存状态（基础均为 100）

### 2.1 生命
- 初始 100，`最大生命 = 100 + (体质-5)×8 + 等级×5 + 装备生命加成`
- 玩家只会被杀死（生命归零）；**无感染机制**

### 2.2 饱食度 / 水分度（0~100，基础 100）
| 项 | 下降速度 | 归零后果（不致死，只削弱） |
|----|---------|---------------------------|
| 饱食度 | 每小时 -3（约 1.5 天崩） | 生命恢复停止、命中 -30%、负重 -30% |
| 水分度 | 每小时 -4（约 1 天崩） | 速度 -40%、行动点消耗 +50%、每小时 -2 生命 |

- 一天正常活动约消耗 48 饱食 / 64 水分 → **每天必须补给**
- 进食（食物）/ 饮水（水）降低对应数值
- 体质每 +1：饱食下降 -0.2/小时、水分下降 -0.2/小时

### 2.3 行动点（基础 100）
- 睡觉/回营地恢复满
- 消耗：搜刮一处 **-10**、战斗一回合 **-5**、移动跨街区 **-3**
- 100 点 ≈ 一天去 2-3 个地点（每地搜 3-4 次）

## 3. 战斗系统（近战 / 远程）

### 3.1 伤害来源（本次定稿核心）
| | 近战（刀/斧/棍/匕首） | 远程（弓/枪） |
|---|---|---|
| 伤害公式 | `武器伤害 + 力量加成` | `武器固定伤害`（不吃属性） |
| 命中 | 吃敏捷 | 弓吃敏捷 / 枪吃智慧 |
| 暴击 | 吃敏捷 | 吃敏捷（弓）/ 吃智慧（枪） |
| 弹药 | 无 | 弓=箭矢、枪=子弹（消耗品） |
| 噪音 | 低（无声） | 高（引尸潮） |
| 风险 | 近身（可能被反扑） | 安全距离 |

### 3.2 武器类型
- 近战：刀、斧、棍棒、匕首、撬棍…
- 远程：弓、弩（敏捷）；手枪、步枪、霰弹枪（智慧）
- 武器规则（复用现有架构）：近战技能需近战武器、远程技能需远程武器

## 4. 网格背包（真 2D）

### 4.1 双限制
| 限制 | 决定者 | 说明 |
|------|--------|------|
| **体积上限**（网格尺寸） | 背包装备 | 腰包 4×2 / 战术背包 5×4 / 登山包 6×5… |
| **负重上限** | 力量属性 | `50 + 力量×10 + 体质×5`（初始 125） |

- 大而轻的卡体积（被子 4 格但轻）
- 小而重的卡负重（铁锭 1 格但重）
- 超重：速度 -50%、行动点消耗 +100%（不能移动/搜索直到减重）

### 4.2 物品形状（宽×高，可旋转 90°）
```
1×1：罐头、弹药堆、药品、零件
1×2：面包、水瓶、匕首、手枪
2×1：撬棍、绷带卷
2×2：斧头、医疗箱
1×4：步枪（竖放）、弓
3×2：霰弹枪
2×3：防具（折叠）
```

### 4.3 网格规则
- 物品占据连续格子；放置检测：越界 + 重叠
- 旋转：右键 / R 键切换方向
- 一键整理：按形状紧凑重排（可选）

### 4.4 存档结构（每个背包物品）
```json
{ "标识": "斧头", "数量": 1, "列": 2, "行": 0, "旋转": false, "词缀": [], "品质": "" }
```

## 5. 经济系统（以物易物）

- **移除铜币**，无货币
- 每个物品有 `价值`（1~100 整数点数）
  - 食物 1-5 / 弹药 3-8 / 药品 10-20 / 武器 30-80 / 稀有材料 40-100
- 交易规则：**等值交换**（无差价）
  - NPC 以物易物：双方物品价值总和对比，价值相等即换
  - 可加入"溢价/折扣"做后期差异化（暂不做）
- 物品类型：
  - 装备：武器、防具
  - 消耗品：食物、医疗品、弹药
  - 材料：各类（金属/布料/药品原料/零件）

## 9. 地图系统（重定义三级）

### 9.1 三级结构（与奇幻版语义的本质区别）

```
L1 城市图（街区节点图）
  营地（特殊安全节点）+ 旧城区/医院区/工业区/住宅区/市中心…
  ├─ 节点图渲染（复用地图面板基类：连线+节点按钮+拖拽缩放）
  ├─ 迷雾：未探索街区显示 "???"
  ├─ 角标：危险度/物资丰度/尸潮等级
  └─ 封锁线：地图边缘红色区域，每周推进
        ↓ 进入街区
L2 街区图（地点节点图）
  例·医院区：医院主楼/门诊/停车场/药房仓库/职工宿舍…
  ├─ 节点图渲染（同一套）
  ├─ 地点角标：危险度/剩余物资/已清空
  └─ 部分地点有"内部"（如医院主楼）
        ↓ 进入地点
L3 地点内部（区域节点图 + 多层结构）★ 重定义核心
  大型建筑多层（医院/商场/写字楼/居民楼/工厂），小型单层（便利店/加油站/民居）
  例·医院主楼：
  ┌─ 1F：大厅（入口）→ 急诊室 → 药房（医疗品集中）
  ├─ 2F：病房（丧尸密集）→ 护士站（药品）→ 手术室（医疗器材）
  ├─ 3F：办公区 → 档案室（线索/材料）
  └─ B1：停尸房（最危险）→ 仓库（最肥，精英守卫）
  ├─ 每层一个区域节点图（复用地图面板基类渲染）
  ├─ 层间连接 = 楼梯/电梯节点：双击换层（电梯可能停运/限层/需钥匙卡）
  ├─ 每层有"本层特性"（数据驱动，一层一条规则）：
  │    B1 全黑需光源 / 2F 通风差噪音传播远 / 仓库层必战精英
  ├─ 区域节点 = 可搜刮点：双击进入 → 搜索（耗行动点，触发事件/战斗/物资/陷阱）
  ├─ 区域连接 = 走廊/楼梯（单向门/被堵通道，如"电梯停运，只能走楼梯"）
  ├─ 区域状态：已搜空（只剩丧尸）/ 有精英 / 有幸存者
  └─ 深度：越深入越肥越危险（地下室 > 3F > 2F > 1F）
```

### 9.2 营地（L1 特殊节点）

- 营地在 L1 城市图上是一个特殊节点（安全区），从任何街区可"回营地"
- 营地内部用**常驻面板**（非地图节点）：
```
营地面板
├─ [睡觉]    恢复生命/行动点（推进时间到次日 6:00）
├─ [仓库]    网格背包管理（存取物资）
├─ [制作台]  制药/做饭/打造/改装（配方系统复用）
├─ [医疗]    治疗（用医疗品）
├─ [收音机]  幸存者委托/广播/传闻（任务系统复用）
└─ [交易]    与营地幸存者以物易物（等值交换）
```

### 9.4 交互与资产复用

- 三级全部复用 `地图面板基类`（拖拽缩放/单击移动/双击进入）——架构一致
- 地图设计器三级编辑能力**原样保留**（城市/街区/地点内部都是节点图）
- 双击进入：L1→L2→L3；L3 区域双击→探索面板（搜索/事件/战斗）
- 返回：侧边栏取消按钮（回上一级）

## 12. 叙事系统（纯事件驱动）

### 12.1 模式
- **玩家目标**：活下去（生存天数目标，如撑过 87 天 = 结局）
- **故事来源**：事件卡（随机）+ 传闻（线索）+ 抉择记录（因果）+ 幸存者（短事件）
- **无传统主线**：每个存档都是不同的故事
- 呈现：日志 + 探索面板正文 + 事件选项（复用现有对话/探索/日志系统）

### 12.2 幸存者（短事件）
- 遭遇的幸存者有名字/背景/诉求（"退役军医想要胰岛素救女儿"）
- 帮助 → 回报/交易/线索；每个幸存者独立短事件，不串长线

### 18.1 等级解锁 + 多种家具


## 19. 伤病系统（6 种）

| 伤病 | 成因 | 效果 | 治疗 |
|------|------|------|------|
| 疲劳 | 行动/战斗累积 | 行动点上限↓、速度↓ | 睡觉恢复 |
| 中毒 | 腐食/毒物/被咬感染伤口 | 持续掉血、行动点消耗↑ | 解毒剂/医疗品 |
| 感冒 | 淋雨/受寒（寒潮） | 行动点消耗↑、易疲劳 | 药/火炉供暖自愈 |
| 流血 | 被攻击（撕咬/割伤） | 持续掉血（随时间） | 绷带包扎 |
| 骨折 | 高处坠落/重击 | 速度↓、近战伤害↓ | 夹板固定（需材料）长期恢复 |
| 发烧 | 感染伤口恶化/重伤 | 全属性↓、持续掉血 | 抗生素/退烧药 |

- 伤病是独立状态（0~100 或存在/不存在 + 严重度），随存档
- 与"玩家只会被杀死"兼容：伤病只削弱/掉血，不转化（无感染变异）
- 战斗中的撕咬可挂 流血 + 中毒（两个 debuff，复用现有 Buff 系统）

## 20. 天气系统（7 种，每游戏日随机）

| 天气 | 影响 |
|------|------|
| 晴 | 正常 |
| 雨 | 水分不降（自动补水）、噪音降低，但移动慢（泥泞）、可能感冒 |
| 雾 | 能见度低：潜行加成、遭遇难发现（陷阱/丧尸更难看见） |
| 雷雨 | 噪音大引尸潮，但浇灭火源 |
| 寒潮 | 温度↓：需保暖否则感冒（火炉/厚衣可防） |
| 沙暴 | 视野极差：搜索效率↓、受伤风险↑、丧尸少 |
| 酷暑 | 温度↑：水分消耗↑、易中暑疲劳 |

- 每日开始时随机生成天气（可加季节权重：冬多寒潮、夏多酷暑）
- 天气影响探索/战斗/安全屋，全部数据驱动（每天气一个效果配置）

## 21. 开局构筑（属性分配 + 正负天赋）

### 21.1 开局属性

```
普通人 = 全 5（总和 25）
职业 = 直接给定五维分布（总和恒 25，区分职业强弱项）
自由分配 10 点 = 在职业分布基础上加
最终属性 = 职业分布(25) + 自由加点(10) + 天赋效果
例·退役军人：力量8 体质6 敏捷5 智慧3 意志3（合计25）
      → 自由点：力量+2 → 力量10（其余不变）
```

> 说明：职业"属性分布"直接给定五维具体值（总和 25），非加成；自由 10 点玩家自行分配叠加其上；天赋效果再叠加。三层关系：分布 → +自由 → +天赋。

### 21.2 正负天赋（PZ 式预算制）

```
开局预算 10 点
正面天赋（花点数）：12 种
  强壮 +2 力量（3点）/ 健壮 +2 体质（3点）/ 灵巧 +2 敏捷（3点）/
  聪明 +2 智慧（3点）/ 坚强 +2 意志（3点）/ 鹰眼 感知+2（2点）/
  快速学习者 经验+15%（2点）/ 无惧 夜晚恐惧抗性+50%（2点）/
  节俭 制作消耗-10%（2点）/ 医者仁心 医疗品+10%（2点）/
  大胃口→反向（见负面）/ 夜行者 夜晚行动点消耗-20%（2点）
负面天赋（返点数）：8 种
  体弱 -2 力量（+3点）/ 笨拙 -2 敏捷（+3点）/ 胆小 -2 意志（+3点）/
  胃口大 饱食下降+50%（+2点）/ 口渴快 水分下降+50%（+2点）/
  失眠 睡觉恢复-30%（+2点）/ 酗酒 需酒否则士气↓（+2点）/
  慢性病 感冒概率×2（+2点）
```

### 21.3 三层叠加关系

```
职业（6 种固有：属性分布(25点) + 初始技能 + 职业天赋 + 初始装备）
  → 职业分布直接给定五维（覆盖普通人全5）
  + 开局自由 10 点（在职业分布上叠加）
  + 正负天赋（10 点预算，负面返点换正面；五维效果再叠加）
= 每个存档独特的开局构筑
```

### 21.4 开局流程

```
主菜单 → 新游戏 → 角色创建面板（单页分栏）→ 确认 → 播开局文本 → 进入地图
```

## 22. 角色创建面板设计（单页分栏，待实现）

### 22.1 布局（1920×1080 基准）

```
┌────────────────────────────────────────────────────────────┐

├──────────────┬───────────────────┬─────────────────────────┤
│ 左栏·职业     │ 中栏·属性分配      │ 右栏·天赋               │
│ [退役军人]   │ 剩余自由点：X      │ 剩余预算：X             │
│ [消防员]     │ 体质 12 [−][+]     │ ——正面（花预算）——     │
│ [厨师]       │ 力量 10 [−][+]     │ [强壮] 3点 力量+2       │
│ [记者]       │ 智慧 9  [−][+]     │ [鹰眼] 2点 感知+2       │
│ [大学生]     │ 敏捷 8  [−][+]     │ ……                     │
│ [医生]       │ 意志 7  [−][+]     │ ——负面（返预算）——     │
│              │                   │ [体弱] +3点 力量-2       │
│ ——职业详情—— │                   │ [胃口大] +2点 饱食+50%  │
│ 描述/加成/    │                   │ ……                     │
│ 技能/装备     │                   │                         │
├──────────────┴───────────────────┴─────────────────────────┤
│ [随机角色]   [重置]                            [✓ 确认开始] │
└────────────────────────────────────────────────────────────┘
```

### 22.2 交互规则

- **职业**：点选高亮，底部显示完整详情（描述/属性加成摘要/初始技能/初始装备/开局文本预览）
- **属性分配**：每项 `[−][值][+]`；剩余自由点=10，用尽后 `+` 置灰；`−` 可回退
- **天赋**：正/负分栏列表，每行 名称+点数+效果；点击选中/取消；剩余预算实时显示，预算不足时正面天赋置灰
- **角色名**：输入框，默认"无名幸存者"，可跳过
- **随机角色**：随机职业 + 随机分配（满10点）+ 随机天赋（预算内）
- **重置**：清空全部选择回初始态
- **确认校验（严格）**：选了职业 + 自由点分配完（剩余0）+ 天赋预算≥0 → "确认开始"可点；否则置灰
- **确认后**：写 PlayerService 构筑参数 → 新游戏 → 播开局文本 → 进入地图（营地）

### 22.3 预览计算

```
最终五维 = 职业分布(25点，直接给定) + 自由分配 + 天赋五维效果
（未选职业时按普通人全5预览；天赋状态类效果如 饱食/经验/医疗 等不显示在五维，由档案派生读取）
```
