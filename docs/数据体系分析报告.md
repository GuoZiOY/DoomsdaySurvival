## 二、已封口的硬伤（原 A 级 7 条，逐条对照）

### A1 图纸链：3 条配方被拿不到的图纸锁死 + 3 张图纸成孤儿 → ✅ 已修

**原症状**：`制作_猎弓/手弩/军用肾上腺素` 需要零来源的图纸；`军刀图纸/消防斧图纸/撬棍图纸` 因对应配方被删而成了孤儿。
**修法**：3 张孤儿图纸**删除**；`猎弓图纸/手弩图纸` 补进搜刮表（体育用品店/图书馆）。图纸现共 **2 张**，都有配方消费。
**现读数**：物品里 `种类=图纸` **2 件**，零来源 **0**。

### A2 两条"链路陷阱"（种子链 / 配方链）→ ✅ 已修，且**口径写进了门禁**

**原症状**：`蔬菜` 的唯一来源是 `蔬菜种子`，而种子本身没有来源；`鸡蛋` 只出现在配方**材料**里（那是消费方）。
**修法**：`蔬菜种子/鸡蛋` 补搜刮来源；`蔬菜` 走种植链可达。
**★ 口径**（已在 `Tools/数据引用核对.ps1` 里落地）：
> **来源只算**：搜刮 / 配方产物 / 敌人掉落 / 职业初始 / 门锁投放 / 技能消耗物 / 种植成熟 / 腐坏产出。
> **`配方材料` 与 `家具建造·升级材料` 都是【消费方】，不是来源**；**种子自身不算来源**，它要自己另有来源，成熟产物才算可达。
> 这条口径是本轮最有价值的产出之一 —— 它先后逮住 `鸡蛋`（配方材料误当来源）与 `医药箱`（家具材料误当来源，导致医疗站建不出来）。

## 六、C 级：口径不一致 / 命名债 / 缺字段

### C1 命名与口径债

1. **`货币奖励` 语义漂了** —— 实际是"补给值"（`BattleService.伤害与结算`：面包 = 补给/4、水 = 补给/8）。建议改名为 `补给值`。
2. **`解析属性()` 默认返回"体质"** —— 已用门禁（天赋目标口径校验）兜住，但代码本身仍是"写错就静默"。
3. **两套"速度"口径并存**：`buff.属性` 里速度只能写"敏捷"（门禁 §8b 守着），而 `物品数据.速度加成` 是独立字段。
4. **`套装` 字段：47 件有值、全仓库 0 个读取方** —— 按拍板**保留为预留**（要么将来做"同套装 2 件小加成"，要么删字段）。它是每次体检都会被重报的那一条，已在门禁外单列。
5. **`容器形状掩码`：0 件在用** —— 旧兼容字段，留着无害。
6. **`容器允许类型` 只 2 件配值** —— 弹药箱/医药箱这类限制型容器很少，其余容器"任意"。

### C2 建议把两条口径做成门禁（防止再回退）

| **「物品落点 ≥2」** | A1 的 36 件就是这么回退的。做完一刀补源之后，必须靠门禁锁住 |

本文所有数字都可以用**一个 Python 脚本现读现算**（脚本放系统 temp，**不要写进仓库**）：

```python
import json, os, collections
D = r"Assets/Resources/Data"
L = lambda p: json.load(open(os.path.join(D, p), encoding='utf-8'))
物品 = {}
for root, _, fs in os.walk(os.path.join(D, "物品")):
    for fn in fs:
        if fn.endswith(".json"):
            for it in L(os.path.relpath(os.path.join(root, fn), D))["物品"]:
                物品[it["标识"]] = it

S = L("搜索_地图类型.json")["地图类型"]
来源 = collections.defaultdict(set)
def 记(tag, k):
    if k and k in 物品: 来源[k].add(tag)

# —— 来源：只算这 8 类 ——
for m in S:
    for r in m["房间"]:
        for c in r["容器"]:
            for e in c["搜索表"]: 记("搜刮", e["物品标识"])
for f in ["recipes_工作台.json", "recipes_灶台.json", "recipes_医疗站.json"]:
    for r in L(f)["配方"]: 记("制作", r["产物"])
    # ⚠ 不要记 配方.材料 —— 那是【消费方】。同理【家具材料】也不能当来源。
for e in L("enemies.json")["敌人"]:
    记("掉落", e.get("掉落物品"))
    for d in (e.get("掉落列表") or []): 记("掉落", d["标识"])   # 刀57 起的多掉落
for c in L("职业.json")["职业"]:
    for e in (c.get("初始装备") or []): 记("职业初始", e["标识"])
for r in L("房间模板.json")["房间"]:
    for d in (r.get("门") or []):        # 钥匙投放：塞进本房容器/敌人 → 算来源
        记("门锁投放", d.get("锁"))
for s in L("skills.json")["技能"]: 记("技能消耗", s.get("消耗物品"))
for k, v in 物品.items():
    if v.get("生长时间"): 来源[k].add("种植(自赋)")
for k in [k for k in 物品 if 物品[k].get("生长时间") and (来源.get(k, set()) - {"种植(自赋)"})]:
    if 物品[k].get("成熟产物"): 记("转化", 物品[k]["成熟产物"])
来源["腐坏食物"].add("腐坏产出")

零来源 = sorted(k for k in 物品 if not 来源.get(k))
print("总", len(物品), "零来源", len(零来源), 零来源)

# —— 单容器（脆弱）：同一件物品出现在几个不同容器里 ——
计 = collections.Counter(e["物品标识"] for m in S for r in m["房间"] for c in r["容器"] for e in c["搜索表"])
print("单容器", sorted(k for k in 物品 if 计.get(k, 0) == 1))

# —— 成本比（按类别分档）——
产 = {r["产物"]: r for f in ["recipes_工作台.json","recipes_灶台.json","recipes_医疗站.json"] for r in L(f)["配方"]}
for r in 产.values():
    c = sum(物品[m["物品"]]["价值"] * m["数量"] for m in r["材料"])
    v = 物品[r["产物"]]["价值"] * r.get("产物数量", 1)
    b = c / v if v else 0
    低 = 0.6 if 物品[r["产物"]]["类型"] in ("武器","防具","医疗","容器","配件") else 0.4
    if not (低 <= b <= 1.6): print("成本比越界", r["标识"], round(b, 2))

# —— 敌人威胁带 ——
带 = collections.defaultdict(list)
for e in L("enemies.json")["敌人"]:
    t = (e["攻击"] / max(0.1, e["攻击间隔秒"] or 5)) * (e["生命"] / max(1, e["防御"]))
    带[e["等级"]].append(round(t, 1))
for lv in sorted(带): print("Lv%d" % lv, len(带[lv]), min(带[lv]), "~", max(带[lv]))
```

**其它口径**（同一份脚本里加几行）：

- 品质分布：`collections.Counter(it.get("品质") or "普通" for it in 物品.values())`
- 死字段（0 件配值）：`sum(1 for v in 物品.values() if v.get("闪避加成"))`（换字段名即可）
- 技能空字段：`sum(1 for s in L("skills.json")["技能"] if s.get("武器种类"))` / `Counter(s.get("武器规则") for ...)`
- 腐坏清单：**只筛 `保质期 > 0`**（别信文档列举 —— A3 就是被旧文档的软清单坑过）
- 天赋是否真生效：`效果[].目标` 不在五维（体质/力量/智慧/敏捷/意志）时，去 `Assets/Scripts` 里
  grep `有天赋("<标识>")` 或 `Contains("<标识>")`，两边都没有就是死天赋
