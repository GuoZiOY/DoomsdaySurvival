# 《最后 87 天》——末日丧尸生存改造设计文档（GDD）

> 项目：《灰烬镇 · 余烬传说》→ 主题转型《最后 87 天》
> 类型：文字末世生存游戏（回合制战斗 + 地点搜索 + 生存决策驱动）
> 平台：PC（Unity 6000，uGUI）—— 现有架构复用
> 决策（已拍板）：① 先单人后小队（架构预留营地字段）② 保留回合制战斗并改造 ③ 资源枯竭 + 尸潮推进（《死亡日记》式）
> 日期：2026-08-20

---

## 1. 转型决策与定位

### 1.1 为什么转型

原奇幻 RPG 的核心短板：文字冒险需要**庞大世界观 + 连贯高质量叙事**，制作与 AI 能力均难以支撑，且内容线性扩展困难。
丧尸生存的核心优势：**系统驱动型**游戏——玩家玩"活下去 + 做抉择"，世界感来自**事件密度**而非连贯叙事；短事件（3-5 句）模板化生产，AI 与个人能力均可达标，且可无限扩展。

### 1.2 定位

- **一句话**：城市已沦陷，你在废弃超市仓库里醒来。食物在减少，声音会引来它们，而它们会在夜里靠近。你能活过第 87 天吗？
- **体验三词**：恐惧（未知/黑夜/尸潮）、抉择（救不救/抢不抢/开不开门）、稀缺（食物/药品/弹药/时间全缺）
- **核心张力**：城市资源逐日枯竭 + 尸潮每周推进 → 世界**越来越糟** → 逼迫玩家向更远更危险处推进（"再搜 or 见好就收"）

### 1.3 与奇幻版的核心差异

| | 奇幻 RPG（原） | 丧尸生存（新） |
|---|---|---|
| 玩家动机 | 变强、看剧情 | 活下去、做抉择 |
| 世界感 | 连贯叙事 + 人物弧光 | 事件密度 + 资源枯竭曲线 |
| 文字需求 | 长篇连贯（难） | 短事件卡（易批量生产） |
| 内容扩展 | 线性剧情 | 事件表组合爆炸 |
| 成长 | 数值变强 | 生存能力 + 装备 + 知识 |

## 2. 世界观（轻量背景板，够用即止）

- **起源**：城市爆发"灰疫"瘟疫——死者重新站起。没有解药，广播第三天停止。
- **玩家**：普通幸存者（可选背景：医生/军人/电工/普通人 → 影响初始技能与事件，预留字段）。
- **现状**：市中心尸潮最密；郊区安全但资源被搜空；郊区外是军方封锁线，墙外未知。
- **幸存者社会**：零星避难所、黑市、掠夺者团体、偶尔的短波广播。
- **世界观即玩法**：封城日（第 0 天）→ 玩家醒来第 1 天 → 第 87 天是"最终救援广播"的承诺（可选结局锚点，默认不做硬倒计时，见 §5.4）。

## 3. 核心循环

```
清晨（规划）：带多少物资出门？去哪搜？今天目标？
  → 地点探索（超市/医院/警局/居民楼/加油站/药店…每处：资源等级/危险等级/剩余物资/搜索深度）
  → 遭遇（丧尸/幸存者/陷阱/天气/突发）→ 抉择（战斗/谈判/搜索/逃跑/救助）→ 结果（收获/损失/感染/情报）
  → 回营（分配/治疗/包扎/制作/升级/睡觉）
  → 夜晚（守夜/休息/夜袭/夜事件）——夜里选择决定明天
  → 第 N 天（物资更少、尸潮更近、世界更糟）
```

**每一天 = 一次完整的"预算-风险-回报"决策**。

### 4.2 新增派生逻辑

```
健康上限 = 50 + 体力×5 + 等级×5 + 装备（保留公式）
疲劳上限 = 20 + 智力×3 + 等级×3
行动点上限 = 100 + 等级×2 + 体力×2（保留精力逻辑）
感染度：每 10% 一个档位 → 影响持续掉血 / 夜晚被锁定概率 / 治疗需求
噪音值：探索地点内累积 → 地点尸潮等级上升 → 回城时可能夜袭
```

## 5. 系统改造明细

### 5.1 战斗系统（保留回合制 + 改造）

**保留**：伤害管线（命中/暴击/抗性/下限1）、Buff 系统、敌人 AI 行动表、目标策略、助战机制（→ 幸存者同伴）、品质/词缀/武器规则、战斗面板全部交互与演出。

**改造**：
1. **护盾 → 护甲**：敌人护盾=护甲值（丧尸无护甲，精英/变异体有），破防机制保留
2. **伤害类型**：物理/魔法 → **近战/枪械/火焰**（枚举扩展，抗性表复用）
3. **感染机制**（新增）：
   - 丧尸"撕咬"技能挂 `感染Buff`：被击中 → 感染度+（普通丧尸+10%，精英+20%）
   - 战斗结束按感染度发 `感染变化事件` → 日志/状态栏
   - 治疗：抗生素（-40%）、消毒（-20%）、截肢（感染≥50%，损失身体槽，-50% 感染度）
4. **噪音机制**（新增）：
   - 枪械类武器攻击产生噪音（数值配置）
   - 战斗结束后噪音值累加进当前地点 → 地点"尸潮等级"上升
   - 噪音影响：地图上的遭遇权重、夜晚是否被夜袭
5. **逃跑**：保留速度差公式，失败后果加重（被追上 = 额外一次感染判定）

### 5.2 探索系统（区域 → 搜索地点）

**复用**：层状态机（进入/搜索/深入/返回）、事件表（遭遇/资源/发现/选择/无事）、权重抽取、岔路（→ 可选路线：正门/后门/通风管）、Boss 层（→ 地点深处精英/变异体）、通关可再刷（→ 搜空后仅剩丧尸）。

**改造**：
```
地点数据（替换 区域数据）：
  标识/名称/描述
  危险等级 1~5（决定丧尸强度与数量）
  资源等级 1~5（决定物资丰度）
  剩余物资 %（被搜递减，搜空 → 只剩丧尸）
  搜索消耗时间（分钟）
  层[]：外围/内部/深处（同 探索层数据 结构）
    深处 Boss：精英丧尸/变异体（同 Boss 层）
  尸潮等级（动态：搜索/噪音累积，随时间缓慢增长）
```
**关键改动**：`搜索()` 消耗"时间"而非仅精力——天黑判定（见 §5.5）；`资源事件` 产出从"金币"改为"物资项"（食物/药品/弹药/零件）。

### 5.3 地图系统（大地图 → 城市街区）

**复用**：三级导航（大地图→小地图→节点内部）、单击移动/双击进入、拖拽缩放、解锁门禁、地图设计器。

**改造**：
- 大地图 = 城市街区图：市中心（高危高资源）/ 旧城区 / 工业区 / 医院区 / 居民区 / 封锁线
- 街区 → 小地图 = 该街区的**搜索地点列表**（超市/药店/民居…）
- 节点内部 = 地点内互动（搜刮/撬锁/躲藏/陷阱拆除）
- 解锁门禁：危险等级 vs 玩家实力 / 封锁线推进
- **迷雾**：未探索街区不显示详情（用现有"解锁"机制）

### 5.4 时间与末日推进（新增核心）

```
游戏时钟（保留）：1 现实秒 = 2 游戏分钟
昼夜：6:00 天亮 / 18:00 天黑 / 22:00 深夜
  - 白天：正常探索
  - 黄昏（17:00 后）：提示"该回去了"
  - 夜晚在外：遭遇率↑、尸群事件、无火把时命中↓
  - 深夜：可露营（消耗燃料，风险事件）
资源枯竭：每个地点 剩余物资 每日 -15%（被搜 +额外扣）；整城物资每周 -5%
尸潮推进：每周日结算——封锁线后撤一格、市中心尸潮等级+1、部分郊区地点"沦陷"（不可进入）
结局锚点（可选）：第 87 天广播承诺救援（不做硬倒计时，仅叙事锚点 + 成就）
```

### 5.5 营地（第二版预留，架构先行）

玩家档案预留 `营地` 字段；第一版"家"设施 = 个人避难所（睡觉/储存/制作）。第二版：
- 招募幸存者（事件抉择）→ 分工（搜索/守夜/制作/医疗）
- 营地等级：床位/仓库/围墙/发电机
- 人口即负担：每人每天消耗食物/水
- 夜袭：尸潮推进时营地防守事件

## 7. 内容生产方式（事件卡模板）

```
事件卡 = 场景 × 威胁 × 资源 × 决策 × 结果

场景（10）：超市/医院/警局/居民楼/加油站/药店/地铁口/街角/仓库/公园
威胁（6）：零星丧尸/尸群/变异体/掠夺者/陷阱/天气
资源（6）：食物/水/药品/弹药/零件/幸存者
决策（5）：战斗/潜行/搜索/谈判/逃跑
结果（4）：成功收获/损失代价/感染风险/情报线索

产量：5 场景 × 4 威胁 × 4 资源 × 3 决策 ≈ 120 条带权重事件
（实际按区域聚焦，每街区 20-30 条 + 通用事件 30 条 ≈ 100-150 条 → 支撑 10+ 小时）
```

**模板化三大优点**：AI 批量生成质量可控；风格统一（3-5 句氛围 + 决策 + 结果）；新内容 = 新事件卡，零代码。

## 11. 设计规范（沿用现有约定）

- 中文命名参数/函数/注释；不用 `_` 前缀
- 数据 JSON 中文键名；新增内容先过 DataService 校验
- 面板继承 面板基类；全局右键 = 回退
- 逻辑永不调 UI，事件驱动刷新
- 领域层纯 C#，零 UnityEngine
