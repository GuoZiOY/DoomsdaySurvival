## 三、系统功能

| 系统 | 说明 |
| --- | --- |
| **HUD 状态栏** | 常驻顶栏 6 项：生命(红)/精力(金)/饱食(绿)/水分(蓝)/时间(灰蓝)/地点(灰)。事件驱动 + 轮询兜底双保险 |
| **世界时间管理器** | 时间中枢：挂机推进（1 现实分 = 30 游戏分，一天 48 现实分）、整点结算、制作/睡觉跳时、跨天天气、时钟同步防重复结算；另挂 腐坏结算 / 生长推进 / 净化推进 |
| **生存结算** | 每游戏时 饱食2/水分2；伤病持续/疲劳恢复/寒潮感冒（灶台豁免）；余数按比例折算 |
| **塔科夫式网格背包** | 3 穿戴容器 + 仓库 + 嵌套容器；拖拽/旋转/换位/堆叠；容器形状块 + 格子投影 |
| **物品体系** | 十大类型（武器/防具/饮食/医疗/材料/弹药/任务品/容器/书籍/**配件**）+ 二级分类 |
| **装备系统** | 8 槽位 + 穿戴容器；品质；耐久。装备**无随机词缀** → 改成**配件/改装件**（真物品、装装备配件槽、**没有耐久**）；词缀留给**敌人** |
| **弹匣** | **只做枪械**；射击先扣 `已装填`；**只自动换弹**（1.5 秒，期间行动条冻结、眩晕可打断但保留子弹）；出战/换武器自动装满；配件只在 `弹匣` 槽改容量 |
| **敌人词缀** | **只随机**（开战逐只掷：精英率 18% → 1 条，再 25% → 2 条，不重复）+ **Tier 1 属性型**（零战斗钩子）。8 条：迅捷/强壮/厚皮/凶暴/滑溜/远视/巨体/迟钝。名字不变、只显示 `[强壮]` 不解释数值 |
| **安全屋** | 程序化随机户型（种子存档）；家具建造/升级/修复/拆除（0 级破损 = 效率减半；容器家具拆除前必须取空） |
| **家具容器** | 家具 = 可打开容器（右键 → 容器面板/专用面板）：容器列行、允许类型/种类（`\|` 多值）、保质期倍率 [3,5,8]、容器分区（净水器） |
| **保质期/腐坏** | 生鲜随游戏时间变质 → 腐坏食物；冰箱内按等级倍率减速；变质自动重建物品框；旧档惰性初始化兼容 |
| **种植/生长 + 晾晒** | 种植箱（土豆种子24h / 蔬菜种子48h）与**晾晒架**（生肉 12 游戏时→肉干 / 兽皮 24→皮革）**共用** `生长时间/成熟产物`；`转化用途`（= 家具 `功能类型`）说清**归哪件管**（种子扔晾晒架上不转化，见 §六 #58）；按家具 `效果` 加速（0/25/50%）；右键 = 各自的面板（网格 + 进度条 + 倒计时） |
| **净水器（3 分区）** | 脏水区/过滤区(木炭)/净水区；**自动净化**：每 60 游戏分钟 脏水1+木炭1 → 水1（时间驱动，缺料/满冻结，进度随档）；灶台净化水配方并存 |
| **制作系统（会话版）** | 浮动面板：配方列表 → 材料拖入输入网格 → 点制作 → 进度条 → 产物入输出网格 → 拖回背包；一次做多个；关闭自动返还剩料+成品；制作中关闭 = 取消（回滚） |
| **书籍系统** | 技能书 / 配方书 / 蓝图；级别→难度（成功率 44/33/22/11%）；耗时阅读（逐帧，可中断）；成功率 = 基础 + 智力×1% + 失败叠加 12%；配方书按品质权重池抽（已习得 ×0.2 降权）；耐久 40，读满一次扣；`已习得配方` 永久随档 |
| **浮层面板体系** | 容器/净水器/制作面板统一浮动壳（Canvas 顶层、防重、拖拽、置顶、限屏）；底座空白拦截拖拽，不穿透下层网格 |
| **战斗（即时制）** | 行动条 = 世界时间驱动速度填充；意图读条（移动/攻击/技能/戒备 分色）→ 满条执行；蓄力/瞬发/位移技/打断/眩晕（秒制）；冷却秒制；弹挂腰封即时用道具；固定 6 技能槽；尸体搜刮 |
| **大世界敌人 AI** | 三态（**静默 / 巡逻 / 追踪**）+ 噪音感知：听得见但不过阈 = 吸引靠近，过阈 = 直接追踪；追踪走**流场**（以玩家格或噪音格为源）；追击有缰绳（超出 `追击上限` 强制回巡逻） |
| **探索四层** | 大世界（100×100 格子网格）→ 区域副本（32×22）→ 建筑（楼层）→ 房间；三态迷雾 + 相机跟随 + 逐格走 |
| **存档** | 磁盘多槽 + 版本迁移 + 整点基准 + **战局快照**（见 §四.6） |

## 四、信息链路

### 1. 状态变化链路（数据 → 事件 → UI）

```
玩家档案（数据源）↓ 修改（生存管理器 / 世界时间管理器 / 效果结算…）
EventBus（事件总线）→ 发布 → HUD面板 / 各浮动面板（订阅：生命/精力/生存状态/时间/背包变化…）
   ↓ 兜底：Update 轮询（对比档案缓存；净水器面板 0.5s 刷净化进度）
```

### 2. 时间链路（统一走 世界时间管理器）

```
世界时间管理器（唯一入口）
├── 推进(现实秒)          ← 挂机驱动（每帧）→ 净化推进 + 生长推进
├── 结算时间段(分,含饱水)  ← 整点结算 / 制作补副作用 → 腐坏结算（生长/净化不在此——已逐帧）
├── 跳时(游戏分钟)         ← 制作动画 → 净化推进 + 生长推进（两条时间流都覆盖）
└── 同步整点基准()         ← 外部跳时 / 取消回滚
        ↓ 玩家档案.游戏分钟数 + 饱食度/水分度(float) + 堆叠.新鲜/生长/净化分钟 → 事件发布 → HUD 刷新
```

### 3. 制作链路（会话版，两步 + 动画）

```
选配方 → 拖材料入 输入网格（真实移入会话）
   ↓ 点制作（数量 = 滑条/输入框）→ 开始制作_会话（校验 输入网格×数量 + 扣精力×数量）
   ↓ 动画（进度条 0→100% + 跳时推进时间）→ 结算制作_会话（输入网格扣料×数量 → 产物入 输出网格 ×数量）
   ↓ 输出区满 → 回滚（材料/精力/时间/饱水全返还）
   ↓ 关闭面板 → 输入剩料 + 输出成品 自动返还（背包/仓库）；背包满 → 拒绝关闭
```

### 4. 净化链路（时间驱动，无按钮）

```
世界时间管理器 推进/跳时 → 净化推进（净水器.净化分钟 -= 时间；惰性初始化补满）
材料齐（脏水区有脏水 且 过滤区有木炭）且 净水区可放 → 倒计时
   ↓ 到 0 → 自动：脏水-1 + 木炭-1 → 净水区 +水1 → 自动续下一批
缺料 / 净水区满 → 冻结进度（条件恢复继续，不浪费）→ 出水面板 0.5s 轮询刷新
```

### 5. 服务装配链路（GameBootstrap，幂等）

```
EventBus → DataService（校验）→ SaveService → v4 旧档一次性迁移
→ PlayerService（初始化 + 解析器接线）→ 世界时间管理器
→ 容器 / 搜索 / 安全屋 / 制作 / 对话 / 任务 / 战斗
→ 房间 / 区域 / 技能 / 书籍 / 天赋 / 大世界 探索服务
→ 自动存档器（订阅 跨天/主线/战斗结束/返回主菜单）→ 挂载时间驱动
```
> `DataService` 校验不过 → **中止装配业务服务**（`校验错误` 挡进游戏；`校验警告` 只 `Debug.LogWarning`）。
> 「解锁条件写了 `情报`」「`楼梯边` == 首间房 `入口边`」走**错误**；「职业/天赋悬空引用」运行时只报警告
> （数据问题不该让玩家进不去游戏），离线那一半（`Tools/数据引用核对.ps1` §8）已升成**失败**。

### 6. 存档链路（**当前实现 = v5**）

```
保存：战局快照(战局存档.取) + 玩家档案 + 存档头 + 整点基准
      → JsonUtility → 写 .tmp → File.Replace → 槽N.json（旧文件成 .bak）
读取：读文本 → 版本探测 → 版本检查（比本作新就拒收，给可读原因）→ 迁移链 → 接线解析器
      → 清理非法值 → 读档后对齐(整点基准) → 战局恢复.装回(局) → 发布初始状态
      装回 失败时按 战局.层 分流：层=安全屋(在家存的档) → 打开营地事件（回安全屋面板，不建世界）；
      老档没快照 → 打开默认世界()（重建废城，落营地门口）
槽位：槽0 = 自动（自动存档器 专用，绝不覆盖手动）+ 槽1..3 = 手动；位置 = persistentDataPath/存档/
版本：v5 = 磁盘文件 + 多槽 + 存档头 + 整点基准 + 战局快照
      v4 = 单键 PlayerPrefs（last87days_save_v4）→ 装配期一次性迁到槽1（不覆盖已有档，旧键保留兜底）
```

`存档数据.战局` 记 **你在哪一层哪一格 + 整趟战局**，`战局恢复.装回()` 分三步：① **由外向内把层造出来**
（结构本来就是种子的纯函数）：大世界 → 区域 → 建筑 → 房间，只填到玩家所在那一层；② **每层用快照整体覆盖**
（位置/已搜标记/门锁/敌人位置/已探索位图/敌人 AI 态）—— 这些重建不出来，且快照存**所有活着的层**
（世界时间管理器每帧喂三层；进楼/进区域时上层世界并不清空 —— 只有**回安全屋**才把三层都收掉，见 §六 #59）；③ **容器战局**（全局一份，
键 = `{当前种子}#{实体标识}`）：先按静态模板重抄实例副本，再装内容。

> 三条硬约束决定了它**必须是真快照、不能靠种子重建**：① 柜子内容来自**无种子** `System.Random`；
> ② 一次性临时建筑的种子不可复现（所以 `单间种子` 直接进档）；③ 三层同时活着。
> 一个必须躲开的坑：`网格实体.容器定义` 是**指向 DataService 模板的共享引用** → 快照里置空，只留
> `定义标识`，读档时按它回填（否则整张搜索表会被复制进存档）。`整点基准` 不存 → 读档第一帧补算
> 120 次 1 小时生存结算（**读档即死**：饱食/水分归零 + 掉满血 + 仓库全腐坏）；`推进()` 里另有自愈兜底。
> 装回返回 false（老档没快照 / 存档时人在安全屋）→ 调用方走 `打开默认世界()`。细节见 `docs/设计-存档.md`。

### 物品数据（十大类型）

```
标识(唯一=显示名=图标) / 描述 / 类型(10) / 种类(二级) / 槽位
攻击距离（只表射程：近战 1~2 / 远程 ≥3）—— "近战还是远程"由 武器种类 判定
攻击/防御/生命/负重/抗性 / 命中·暴击·闪避·速度·潜行 加成 / 恢复量·恢复目标

适用弹药[]  ← 这把枪吃哪些弹药（有序 = 优先消耗顺序；空 = 回退"按武器种类"的旧映射）

书籍种类(技能书|配方书|蓝图) / 书籍级别(低中高顶传奇) / 阅读时间分 / 配方池[] / 技能 / 熟练度点
```

### 物品堆叠（随档实例）

```
标识 / 数量 / 列行 / 旋转 / 当前耐久 / 词缀 / 品质 / 容器列行 / 容器物品（嵌套/分区）
新鲜分钟   ← 腐坏（≤0 变质为 腐坏食物）
生长分钟   ← 种植 / 晾晒（≤0 成熟替换产物）—— 由 世界时间管理器 扣减，按家具 效果 加速
```

### 配方数据

```
标识 / 名称 / 描述 / 类型(工作台|灶台|医疗站) / 产物 / 产物数量 / 材料[] / 解锁图纸 / 需习得 / 需要等级(1~3) / 品质

制作时间分 / 消耗倍率(0.5倍数) / 消耗精力
```
> `需要工具` 的现实依据：明火能烤不能煮（煮要 **铁锅**）、自己包扎不需要器械（动手术才要 **医用工具**）。
> 一种配方族一件工具：锤子（木工·成形）· 针线盒（织物）· 缝纫锥（皮革）· 剪刀（裁剪）· 磨刀石（刃具）·
> 扳手（电气）· 双头扳手（装弹）· 铁锅（煮类）· 医用工具（医用级）。
> `类型` **只有三站** —— 晾晒架 是**容器家具 + 就地转化**，**不是**第四个制作站（它没有配方）。

### 敌人数据（`enemies.json`）

```
标识 / 名称 / 描述 / 生命 / 攻击 / 防御 / 速度 / 等级 / 行动表[] / 目标策略
货币奖励（**实为"补给值"**：面包 = ÷4、水 = ÷8）/ 经验奖励
移动AI(冲锋|风筝|驻守) / 攻击距离 / 身形 / 移动·攻击·技能间隔秒
掉落物品 + 掉落概率          ← 旧口径：单件 + 单概率（列表为空时走这条，老数据零改动）
掉落列表[] { 标识 / 数量 / 概率 }  ← 新口径：**逐条独立掷概率**（Boss 3 条 / 精英 2 条 = 49 条）
```
> **为什么不是"权重抽 1"**：Boss 需要"必掉的招牌物 + 看脸的稀有物 + 耗材"同时成立，权重抽只能出一条。

### 家具数据

```
标识 / 名称 / 描述 / 材料[] / 最大等级 / 功能类型(睡觉|制作|仓库|情报|取暖|医疗|净化|种植|晾晒|防护|卫生)
形状宽高 / 升级[](材料+容器列行) / 效果[](按等级)
容器列行 / 容器允许类型(类型|类型) / 容器允许种类(种类|种类) / 保质期倍率[3,5,8]
容器分区[]（名称/列行/允许类型/允许种类）      ← 分区容器（净水器 3 区）
净化间隔分 / 净化材料A / 净化材料B / 净化产物 / 净化产物数量   ← 自动净化
0级=破损（可用但效率减半）；未建=无效果；储物箱例外不缩水
```
> **`效果[]` 的语义按 `功能类型` 解释**（免得出现"三级一样"或全 0 的死值）：床 = 恢复系数×100 `[100,130,150]` ·
> 储物箱 = 仓库行加成 `[10,20,30]` · 灶台 = 寒潮豁免等级 `[1,2,3]` · 工作台/医疗站 = 可做配方等级 `[1,2,3]` ·
> 收音机 = 可听情报等级 `[1,2,3]` · 冰箱 = 保鲜倍率 `[3,5,8]` · 净水器 = 净化批次 `[1,2,3]` ·
> **种植箱/晾晒架 = 生长·晾晒加速 % `[0,25,50]`** · 厕所 = 睡觉恢复加成 % `[5,10,15]`。
> **门 = 最大等级 1（不升级）** —— 没有防护系统，升级无收益，索性不给入口。

### 家具升级需求

```
材料 / 形状宽高(-1=不变) / 容器列行(-1=不变) / 容器分区[]（升级后 分区容器 各子区尺寸）
```
> 净水器 等分区容器升级：按 `升级需求.容器分区` 更新子容器网格 列/行（`容器服务.更新分区尺寸`），
> 允许 类型/种类 沿用 `家具定义.容器分区`。

### 关键约定

- **图标 = 标识**（`Resources/物品图标/<标识>.png`）；**网格格尺寸 = 90**；**块缝隙宽 = 10**；容器物品必须落单块内
- **浮动面板**：锚点居中、宽高以预制体为准（代码不覆盖）；显隐用父节点
- **时间速率**：1 现实分 = 30 游戏分；一天 48 现实分；**基础消耗**：每游戏时 饱食2 / 水分2（float 精确 0.1）
- **制作动画**：时长 = 制作时间分 ÷ 10 现实秒；**净化速率**：净水器 = 每 60 游戏分钟 1 单位（家具数据可调）
- **场景搭建**：UI 全场景手动搭建 + `[SerializeField]` 引用位（无代码找路径）

## 六、开发注意事项（坑与约定）

| # | 坑 / 约定 |
|---|---|
| 1 | **编码**：全中文命名；JSON/C# 必须 UTF-8 无 BOM；pwsh 读写中文需显式编码；字符串插值中文用 `${变量}` |
| 2 | **场景**：UI 手动搭建 + 引用位；浮动面板 宽高以预制体为准、锚点居中；代码不覆盖 sizeDelta |
| 3 | **数据**：改物品标识 → 同步 配方/图标文件名/快速测试面板/搜索容器引用；json+meta 成对（GUID 固定）；家具字段名变动会断预制体引用 |
| 4 | **时间**：任何推进时间必须走 世界时间管理器（禁止直接改 游戏分钟数）；腐坏 在 结算时间段、**生长/净化 在 推进+跳时**（两条流都覆盖；勿放回 结算时间段——会与逐帧双扣） |
| 5 | **存档**：物品堆叠新增字段缺省 0 → 惰性初始化兼容（无需升档）；结构破坏性变动才升版本 |
| 6 | **动态面板**：必须 OnDestroy 取消 EventBus 订阅，否则残留订阅撞已销毁实例（MissingReferenceException） |
| 7 | **网格**：改渲染前先查 块偏移 链路；**物品边界线画在物品自己身上**（`网格面板基类.建边界线`），线层只有统一淡网格、**不按物品变色加粗**；浮层命中判定找 `浮动宿主` 防穿透 |
| 8 | **验证**：Unity 刷新运行验证；数据校验看 GameBootstrap 日志（校验错误停装） |
| 9 | **HUD**：须挂 Canvas 顶层独立（非任何面板子物体），由 `面板管理器.HUD` 引用位控制显隐（主菜单/角色创建 隐藏） |
| 10 | **分区容器升级**：走 `家具升级需求.容器分区`（升级时 `容器服务.更新分区尺寸`），类型/种类沿用 `家具定义.容器分区` |
| 11 | **快速测试面板**：动态布局（屏宽高自适应 + 双列 + 按钮 300px 居中）；分区半透明块 + 组标题 |
| 12 | **日志语义**：8 类（徽章色 `游戏主题.日志色/日志标签`）；调试/接线错误走 Console 不发布日志事件；战斗逐条 = 过程消息（第三参 true），结果摘要才入历史；物品名着色用 `品质工具.名称着色` |
| 13 | **日志壳显隐**：空日志自动隐藏用 **CanvasGroup alpha**（勿 SetActive 含脚本的根——会停脚本，activeInHierarchy 检查将永久拦截事件，面板再也无法恢复显示） |
| 14 | **out var 短路**：`a != null && TryGetValue(..., out var x)` 视为 x 可能未赋值（CS0165）——先声明 `T x = null` 再 `TryGetValue(out x)` |
| 15 | **书籍**：阅读走 `世界时间管理器.阅读推进`（两流，同 生长/净化）；耐久复用 最大耐久(=40)+当前耐久；`已习得配方` 永久存档（区别于 持有图纸）；堆叠上限=0 + 保质期=0；`需习得=true` 必须读书习得才解锁 |
| 16 | **网格基类三条硬约定**：① 子类**不许再写 `void Update()`**（基类 Update 是 private，会被隐藏 → 刷新调度/拖拽全废；每帧逻辑放独立组件）；② 基类 `销毁网格结构` 只销毁它自己那四层，自建层要自己跟着尺寸重建；③ 路径/悬停这类临时高亮**不能蹭基类的 投影格**——自建层画 |
| 17 | **格尺寸全项目统一 90px**：不许按面板覆写、不做"等比缩小到一屏"——大地图靠**相机跟随**（视口 RectMask2D + 夹边） |
| 18 | **能吃点击的只有**：交互层每格透明图 + **非楼实体**的框根。**玩家令牌与楼必须 `raycastTarget = false`**（令牌会盖住脚下那一格：站在楼梯上点不到楼梯、踩在尸体上搜不了） |
| 19 | **RectMask2D 只裁画面、不裁 raycast**：窗口外的格子照样接得到点击 → 点击/悬停一律先问 `探索图层.在窗口内(列,行)` |
| 20 | **图层 z 序**（自下而上）：底盘 → 底座层 → 地表层 → 线层 → 交互层 → 物品层 → **迷雾层** → 路径层 → 效果层。**"看得见看不见"不由层级决定**，而是 `更新实体框` 按 `服务.档(列,行)` 算；迷雾只管"压暗/盖黑"，且 `raycastTarget = false` |
| 21 | **形状数据纪律**：`凹` 的凹口必须朝街（用 `朝向` 转，否则死格 → 连通分量炸）；`区域生成器.复制外形()` 加了新形状参数**必须同步补**；楼**别贴区域外墙**（`凸` 会出封闭死角） |

### 7.1 侧边栏与 HUD 的按钮

### 7.2 面板出口只有一个协议

- **`面板基类.回退()` 是唯一出口**：HUD 关闭按钮、各面板自己的按钮都调它。**本项目没有全局回退键**（取消按钮已删，且拍板不绑 Esc）。
- **可关闭**（决定 HUD 那颗按钮显不显示）= 面板**覆写了 `取消文本`**（覆写它就意味着有真退出口）。战斗沙盒面板没覆写 → 战斗里那颗按钮自动不出现。约定：**覆写了文案就必须让 `回退()` 真能退出去**。
- **换图**：`取消文本 ∈ {出门, 回安全屋, 回大地图, 离开}` → 返回图；其余 → 关闭图。**持有面板用关闭图**（它是"盖在上面的持有物总览"）。分界线收在 `HUD面板.是返回语义()` 一个集合里。
- **离开一层 = 自己走出去，不瞬移**：`回退()` 先试 `格子探索服务.自动走向出口()`（从各层 `收撤退点` 挑最近可达的出口，走 `点格()` 那条玩家同款路径）→ 走到出口那一刻图层回调再进 `回退()`，此时玩家正站在出口上 → 落到原逻辑真正离开。路上照常耗游戏时间、会遇敌。
- **出到外面那一层是确定性的**：房间 → 区域（若区域层活着）否则大世界；区域 → 大世界。**不再用 `返回上一面板()`**（见 §六 #55）。

### 7.4 游戏会话状态

`Domain/会话/会话阶段.cs`（枚举：主菜单 / 角色创建 / 探索 / 战斗）+ `Services/会话/游戏会话.cs`。

四处读它，取代原来各写一遍的推断：世界时间是否推进 · 常驻UI/HUD 显隐 · 侧边栏显隐 · 存档门禁。

### 7.5 那 47 个"组装面"文件（网格渲染件 / 列表行 / 贴图）怎么管

**不注册到任何中心**。管理模型 = **谁生谁管**（父子关系就是所有权，生命周期 = 宿主面板）+ 共享基类（`网格面板基类`）+ 三条约定：层序（探索 9 层 / 网格内部 4 层，两套独立）· 静态资源缓存收敛成一个出口 · **跨面板的临时顶层走 `Canvas` 的唯一出口**（拖拽代理）。
跨面板的东西（拖拽 static 状态、`背景模糊层`）才归管理器；`背景模糊层` 已加**引用计数**（原来"谁最后调谁赢"，A 面板关闭会把 B 正在用的模糊一起关掉）。

### 7.7 就地转化 面板族（种植箱 / 晾晒架）

- **一份逻辑两个壳**：`就地转化面板基类`（网格绑定 / 进度条 / 最早一件倒计时 / 状态文案 / 0.5s 轮询 / 背包变化订阅）→
  `种植箱面板`（文案 = 生长中…/可以收获了/等待播种）·`晾晒架面板`（晾晒中…/已经晾好了/架子空着）。子类只报**预制体路径 + 文案**。
- **两个预制体**：容器尺寸不同（种植箱 3×3 / 晾晒架 4×2）→ 面板尺寸也不同。**面板宽高以预制体为准**（代码不覆盖），
  `Prefab/晾晒架面板` 是照 `Prefab/种植箱面板` 复制的（同一个壳，网格更宽更矮）。
- **一个网格**：`就地转化网格`（原 `种植箱网格`）管"什么能放进来 / 什么能拖走"。
  ① 收不收 = `家具工具.可就地转化`（用途必须等于家具功能类型）；② **单株定根**（种植 = 一次一棵 + 种下不能动；
  晾晒 = 8 格各晾各的 + 晾晒中也能取下来）由**面板按家具 `功能类型` 设**（`[NonSerialized]`，不序列化——判据只有一个来源）。
- **标题写"家具名 2级"**（等级决定加速，值得写出来）；直接用实例标识会漏出 `晾晒架_2` 这种内部编码。
