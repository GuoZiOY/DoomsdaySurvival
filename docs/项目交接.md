## 3. 架构与信息链路

### 3.1 四层架构

```
UI（面板/交互/渲染）
  ↑ 订阅事件刷新，调用 Service 方法
事件层（EventBus：生命/属性/生存状态/背包变化/导航/战斗/探索/日志…）
  ↑ 发布
Services（应用层：流程/服务装配/跨系统协调）
  ↑ 调用
Domain（领域层：纯 C# 规则/校验/结算，零 UnityEngine）
  ↑ 读取
Data（JSON：物品/配方/职业/天赋/家具/地图…，DataService 加载校验缓存）
```

- **规则进 Domain**（如 网格服务.可放置、家具效果结算），**流程进 Services**（如 安全屋管理器.建造→扣材料→发布事件），**UI 只显示与交互**（发事件 / 调 Service）。
- 全部服务经 `GameBootstrap.装配()` 注册进 `ServiceRegistry`（单例容器），`DefaultExecutionOrder(-100)` 保证先于面板 Awake。
- 事件驱动示例：`安全屋管理器.建造()` → `事件.发布(背包变化事件)` → 持有面板/网格面板订阅刷新；`日志事件` → 日志面板追加（类型着色：系统灰/剧情白/操作金/反馈绿/反馈坏红）。

### 3.2 信息链路（示例）

```
[建造家具]
UI 建造面板.点击建造 → 安全屋管理器.建造(标识,列,行,旋转)
  → 校验：家具唯一 / 材料足够 / 网格可放置
  → 扣材料（跨 穿戴容器/仓库 统一扣）
  → 玩家.家具.Add(物品堆叠)  +  网格服务.可放置 校验
  → 事件.发布(背包变化事件) → 持有面板/网格面板 刷新
  → 事件.发布(日志事件.反馈) → 日志面板 显示

[生成新户型]
快速测试面板.生成新户型 → 安全屋管理器.重新生成户型()
  → 玩家.户型种子 = Random → 安全屋户型.生成(种子)（BSP 切块，确定性）
  → 网格缓存 立即同步尺寸 + 家具清空 + 确保基础家具(0级破损)
  → 事件.发布(背包变化事件) → 安全屋面板.强制重建网格()
```

## 4. 已完成系统（可运行）

### 4.1 网格系统（项目核心）
- **网格服务**（Domain，纯 C# 零 UnityEngine）：通用网格引擎——网格尺寸/物品列表/形状解析器注入；可放置/移动堆叠/换位/区域互换（整体搬迁+回滚）/布局安全/堆叠规则/智能旋转找空位。支持**塔科夫式多矩形形状**（`格可用`/`格所属块`/`形状块`——口袋/房间隔离）。
- **网格面板基类**（UI，4 partial：门面/渲染/拖拽/交互）：抽象引擎——底格/分隔线/块轮廓渲染、拖拽代理/落点投影/R旋转、点击/右键分派、**差异点钩子**（5 抽象 + 若干虚方法）。子类写实体语义：
  - **物品网格面板**：品质底/图标 cover/数量/耐久、跨面板转移/装备槽/合并/存入容器/搜索宿主（箱中箱）。
  - **家具网格面板**：家具色块框、右键菜单（使用/升级/拆除/详情）、中键拖拽面板、编辑模式保护。

### 4.2 持有 / 容器 / 仓库 / 穿戴
- **持有管理器**：统一持有入口——3 穿戴容器（弹挂/腰封/背包）+ 仓库 + 嵌套容器递归；放入优先穿戴容器→仓库兜底。
- **容器服务**：塔科夫式嵌套容器（物品内部网格，形状可自定义）；跨网格转移。
- **持有面板**（背包总界面）：装备区 + 装具区常驻 + 右区模式（仓库 / 搜索二选一）；返回按钮；背景模糊。

### 4.3 搜索容器（搜刮）
- 搜索服务：首次打开按权重随机生成（顺序摆放）；会话缓存 + 已搜状态持久；撤离清空。
- 搜索面板：容器黑幕倒计时 → 物品黑块逐个搜索（放大镜扫描动效）→ 显现动画；箱中箱（4 区原位替换）。

### 4.4 安全屋（营地）—— 最近重点
- **家具**：床/工作台/储物箱/收音机/灶台/门/厕所（数据驱动：建材/升级/每级效果/占格随级变化）；网格摆放/拖拽/R 旋转/换位。
- **基础家具 0 级破损**：床→主屋、灶台→厨房、厕所→洗浴间、门→门房 自动摆放为 0 级（破损无效），**修复（0→1 级）= 建造材料一半**，恢复功能。
- **建造面板**：家具行模板（预制体驱动）——名称（满级标记）/描述/占格+材料；材料不足红字+按钮灰显+失败音效；升级空间不足占格红警示；0 级家具显示"修复"按钮。
- **随机户型**（`安全屋户型`，最近重构）：
  - 固定 7 房间：**门/大厅/主屋/厨房/洗浴间/阳台/二间**（二间 三选一：客卧/杂物间/书房）。
  - **BSP 切块：递归二分网格 → 7 块，块 = 房间**（块尺寸即房间尺寸，利用率高，平均 ~70%）。
  - **门**：占格恒 2×1 或 1×2，**长边（2 格）贴网格边界**（2×1 贴上/下、1×2 贴左/右）。
  - **阳台**：长条（宽=1 或 高=1），**长边贴网格边界**（横条贴上/下、竖条贴左/右）。
  - 网格组合 2K 适配：高度 ≤10、宽度 9~15（横向为主，无竖长条）。
  - 块间留 1 格墙（可拆）；未覆盖格全部 = 墙（-2，可拆，暂无院子）。
  - **拆墙 = 打通**：拆除墙格（-2）→ 两侧房间合并成一个大房间（家具可跨原边界）。
  - 目标面积按类型随机微调（大厅 6×4/4×6、主屋 4×5/5×4…），房间大小 2×2~4×6。
  - 种子存档（玩家档案.户型种子）——同种子同户型，读档恢复。
  - 40 次尝试 + 固定布局兜底（随机镜像）；回归验证：贴边/重叠/空洞/尺寸违例 全 0。
- **安全屋面板**：场景手动搭建（网格容器/建造按钮/建造面板引用位）+ 编辑模式（建造/移动/旋转开关）+ 拆除模式（点击拆墙，悬停绿色投影）+ 摆放模式（跟手预览落格）+ 背景模糊 + **中键拖拽移动面板**（空白区，保持位置）。

### 4.5 战斗 / 探索 / 成长 / 职业
- **战斗**：回合制（近战吃力量+武器、远程吃固定伤害+命中判定），速度队列，无敌回合（钢铁意志），致命伤害事件→天赋响应（钢铁意志/医师仁心），战败惩罚（背包 10% 掉落），无感染（中毒/发烧是伤病非感染）。
- **探索**：区域探索（权重随机遭遇/发现/资源/无事），天气影响（雨=噪音低遇敌少、沙暴=行动点+5…），潜行偷袭，搜空标记。
- **成长**：五维属性（体质/力量/智慧/敏捷/意志），六职业（退役军人/消防员/厨师/记者/大学生/医生），25 点直给 + 10 点自由，升级 +3 点。
- **生存**：生命/饱食/水分（每小时下降，归零削弱不致死）、行动点（100 基础）、六种伤病（疲劳/中毒/感冒/流血/骨折/发烧，0~100 严重度）。
- **时间天气**：1 现实秒 = 2 游戏分钟；每小时结算；跨天随机天气（晴/雨/雾/雷雨/寒潮/沙暴/酷暑 7 种）；夜晚更危险，睡觉跳过夜晚。

### 4.6 装备与词缀（奇幻遗产改造复用）
- 装备 8 槽（主手/副手/头部/胸部/腿部/脚部/手部/背包），稀有度 6 档，随机词缀（攻击/防御/生命/抗性/暴击/命中/闪避/速度/负重/潜行）。

### 4.7 面板 / 导航 / 事件 / 数据 / 工具

## 8. 编码规范与约定

- 全中文命名；四层架构：UI ← 事件 ← Services ← Domain ← Data。
- if/else 不写单行；单语句缩进 1 Tab；多语句带大括号。
- 动态 UI 一律走 `UI工具`（创建物体/图/文本/设锚/铺满）；复杂行用**预制体模板 + 组件**（面板基类.创建模板<T>）。
- 配色一律走 `网格面板配色`（颜色/线宽/边距集中一处），禁止散落魔法颜色。
- 数据驱动优先（JSON + DataService）；逻辑层不碰 UI，发事件。
- 网格面板基类钩子原则：**基类复用后续 → 细钩子（小虚方法）；后续子类专属 → 粗钩子（整段方法 override）**；子类专属视觉走钩子，不污染基类。
- 单例：ServiceRegistry（服务）/ 面板管理器.实例 / 右键菜单.实例 等。
- 场景搭建：面板挂组件 + Inspector 引用位拖拽；动态挂载（网格面板 AddComponent + 绑定网格容器）。

## 9. 已知问题与坑（务必注意）

1. **不要用 pwsh/命令行写 .cs**：编码会损坏（GBK 乱码），必须用编辑器工具写 UTF-8。
2. **持有面板 Awake 陷阱**：初始 inactive 的物体 Awake 延迟到首次激活——Awake 里 SetActive(false) 会导致"第一次打不开、第二次才开"（已修复：删 Awake 关闭，初始隐藏由场景 inactive 控制）。
3. **网格强制重建**：必须销毁全部层（底盘 + 底座/线/物品层，`销毁网格结构()`），只销毁底盘会残留多层累积。
4. **户型缓存闭包**：网格服务的 `格可用` lambda 捕获安全屋管理器字段 `户型`——重新生成户型必须**立即生成**（不能置 null 等懒加载）+ **同步缓存网格列/行**（否则尺寸变化数组越界）。
5. **存档兼容**：字段改名/加字段会破坏旧档（户型种子、网格服务字段等）——开发期清档；正式需迁移逻辑。
6. **房间渲染**：家具网格用基类**容器版**块渲染（轮廓+缝）；不 override 基类画线逻辑。
7. **UI 锚点居中**：网格容器锚点 (0.5,0.5) + 保持 anchoredPosition（重建不重置），中键拖拽后面板停留。
8. **户型贴边语义**：门 2×1（长边横）贴**上/下**、1×2 贴**左/右**；阳台横条贴**上/下**、竖条贴**左/右**——曾写反导致"长边看着没贴边"，验证器可查。
9. **户型回归**：改 `安全屋户型.cs` 后把文件复制到 `Tools/户型验证/安全屋户型.cs` 并 `dotnet build` 跑一遍（网络受限时加 `--source "C:\Program Files\dotnet\library-packs"`，目标框架 net10.0）。

## 10. 快速上手

1. Unity 6000.4.8f1 打开 → `Assets/Scenes/SampleScene.unity`。
2. 菜单栏 奇幻RPG → 导入中文字体 + 一键搭建场景。
3. 运行后：顶部「测试」按钮 → 打开安全屋 / **生成新户型**（多次看随机户型）/ 加建材。
4. 安全屋操作：建造（编辑）→ 建造面板选家具「建造/修复」→ 摆放落格（R 旋转、左键放置）；空白处**中键拖拽**移动面板；右键家具（使用/升级/拆除/详情）；**拆除模式**点击墙格打通房间。
5. 背包：F1 或 测试面板 → 持有面板（装备+穿戴+仓库）；双击容器物品打开（箱中箱）。
6. 户型回归：`Tools/户型验证` 项目 `dotnet build`（offline source）+ 运行 exe 看统计。
