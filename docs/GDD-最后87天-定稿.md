> 项目：《灰烬镇 · 余烬传说》→ 主题转型《最后 87 天》（丧尸末日生存）
> 类型：文字末世生存（回合制战斗 + 地点搜索 + 生存决策驱动）
> 平台：PC，Unity 6000（6000.4.8f1），URP 2D，uGUI + TMP，1920×1080（Match 0.5）
> 状态：本 GDD 为转型后的**唯一权威总纲**，取代 `GDD-末日丧尸生存改造.md`；玩家档案细节以 `设计-玩家档案定稿.md` 为准，两者冲突时以本 GDD 为准。
> 日期：2026-08-23

## 0. 一句话与体验定位

- **一句话**：城市已沦陷，你在废弃超市仓库里醒来。食物在减少，声音会引来它们，而它们会在夜里靠近。你能活过第 87 天吗？
- **体验三词**：恐惧（未知/黑夜/尸潮）、抉择（救不救/抢不抢/开不开门）、稀缺（食物/药品/弹药/时间全缺）。
- **核心张力**：城市资源逐日枯竭 + 尸潮每周推进 → 世界**越来越糟** → 逼迫玩家向更远更危险处推进（"再搜 or 见好就收"）。
- **一天 = 一次完整的"预算-风险-回报"决策**。

**为什么是丧尸生存而不是奇幻 RPG**：文字冒险需要庞大世界观 + 连贯高质量叙事（制作与 AI 能力均难支撑）；丧尸生存是**系统驱动型**游戏——世界感来自**短事件密度**而非连贯叙事，3-5 句事件卡可模板化批量生产，可无限扩展。

## 1. 世界观（轻量背景板，够用即止）

- **起源**：城市爆发"灰疫"瘟疫，死者重新站起。没有解药，广播第三天停止。
- **玩家**：普通幸存者（6 种职业背景，见 §3），第 1 天在城市某废弃超市仓库醒来。
- **现状**：市中心尸潮最密；郊区安全但资源被搜空；郊区外是军方封锁线，墙外未知。
- **幸存者社会**：零星避难所、黑市、掠夺者团体、偶尔的短波广播。
- **87 天**：封城日 = 第 0 天；第 87 天是"最终救援广播"承诺的撤离日 = **结局锚点**。默认不做硬倒计时惩罚，但尸潮与资源曲线让世界自然趋紧。
- **无感染机制**：玩家只会被杀死（生命归零 = 死亡）。中毒/发烧等是伤病，不是感染。

## 2. 核心循环

```
清晨（规划）：带多少物资出门？去哪搜？今天目标？
  → 地点探索（超市/医院/警局/居民楼/加油站/药店…每处：资源等级/危险等级/搜索深度/搜空标记）
  → 遭遇（丧尸/幸存者/陷阱/天气/突发）→ 抉择（战斗/谈判/搜索/逃跑/救助）→ 结果（收获/损失/伤病/情报）
  → 回营（分配/治疗/包扎/制作/升级/睡觉）
  → 夜晚（守夜/休息/夜袭/夜事件）——夜里选择决定明天
  → 第 N 天（物资更少、尸潮更近、世界更糟）
```

## 4. 核心五维属性

基础全 5（合计 25），**职业直给 25 点分布**，开局另有 **10 点自由属性**，升级 +3 点。属性文本显示格式：`职业值+已加`（如 5+3）。

| 属性 | 定位 | 派生影响 |
|------|------|---------|
| 体质 | 生存根基 | 生命上限（+8/点超出 5）、负重、饱食/水分下降更慢、防御（×0.5）、疲劳抗性 |
| 力量 | 近战与搬运 | 近战伤害、负重上限、破门撬锁 |
| 智慧 | 求生技能 | 枪械命中、制作成功率、医疗效果、经验获取、侦察 |
| 敏捷 | 行动能力 | 速度（×2）、闪避、暴击、弓命中、潜行（×2）、逃跑 |
| 意志 | 心理防线 | 恐惧抗性、夜晚行动、震慑谈判、暴击/闪避微量加成 |

## 5. 生命与生存状态（基础均 100）

### 5.1 生命
- 初始 100；`最大生命 = 100 + (体质-5)×8 + (等级-1)×5 + 装备生命加成 + 词缀生命`。
- **玩家只会被杀死**（生命归零）；无感染。

### 5.2 饱食度 / 水分度（0~100）
| 项 | 基础下降 | 归零后果（不致死，只削弱） |
|----|---------|---------------------------|
| 饱食度 | 每小时 -3 | 生命恢复停止、命中 -30%、负重 -30% |
| 水分度 | 每小时 -4 | 速度 -40%、行动点消耗 +50%、每小时 -2 生命 |

- 一天（1440 分钟）正常活动约耗 48 饱食 / 64 水分 → **每天必须补给**。
- 体质每 +1：饱食/水分每小时下降 -0.2。
- 天赋/职业可修正（骆驼 -25% 水分消耗、铁胃 -20% 饱食消耗、饿死鬼/渴死鬼 +30%）。

### 5.3 行动点（基础 100）
- 睡觉/回营地恢复满；消耗：搜刮一处 **-10**（酷暑/沙暴 +5）、战斗一回合 **-5**、移动跨街区 **-3**、训练 **-15**。
- 100 点 ≈ 一天去 2-3 个地点（每地搜 3-4 次）→ 行动点归零只能回营。

### 5.4 伤病（6 种，严重度 0~100）
疲劳（活动累积，睡觉恢复）/ 中毒（腐食，解毒剂）/ 感冒（淋雨受寒，药/火炉）/ 流血（受击，绷带）/ 骨折（坠落重击，夹板长期恢复）/ 发烧（伤口恶化，抗生素）。
- 伤病影响派生数值（骨折减伤害/速度，疲劳>50 减速度）；发烧/流血持续掉血。
- **无感染**：被丧尸攻击只会造成 流血/中毒 类伤病。

## 6. 战斗系统（近战 / 远程，回合制）

### 6.1 伤害来源（定稿核心）
| | 近战（刀/斧/棍棒/匕首） | 远程（弓/弩/手枪/步枪/霰弹枪） |
|--|------------------------|------------------------------|
| 伤害 | `力量 + 武器加成 + 词缀攻击` | `武器固定伤害 + 词缀攻击`（不吃属性） |
| 命中 | 无命中判定 | 弓=敏捷判定 / 枪=智慧判定 |
| 特点 | 无消耗、风险贴身 | 安全、弹药稀缺、有噪音 |

- **无技能、无魔法、无五行、无增幅**——战斗是资源博弈（弹药/药品/生命）而非数值秀。
- 暴击/闪避/防御/速度/负重 等由 玩家档案 派生属性统一提供（含 词缀/伤病修正）。
- 弱点概念保留但简化：丧尸对头部类武器（棍棒/枪）更脆弱 → 由 武器种类 克制表驱动（数据可配）。

### 6.2 回合与死亡
- 行动顺序按速度队列；每回合行动点 -5。
- **无敌回合**：`战斗单位.无敌回合 > 0` 时免疫伤害（钢铁意志触发后 1 回合）。
- **致命伤害事件**：玩家生命即将归零时发布 → 天赋服务 检查 钢铁意志/医者仁心 → 未救回则死亡（存档结算，战败惩罚：背包 10% 物品掉落）。

### 6.3 胜利与战利品
- 掉落补给（面包/水/药品/弹药/材料）+ 小概率装备（带随机词缀）；经验/熟练度成长。
- 无货币奖励——物资本身就是战利品。

## 7. 背包与装备

### 7.1 真 2D 网格背包
- 网格尺寸由**背包槽位装备**决定：腰包 4×2 → 战术背包 5×4 → 登山包 6×5。
- 物品有形状（宽×高），可旋转 90°；网格放入/取出/堆叠（同类物品合并）。

### 7.2 装备 8 槽
主手 / 副手 / 头部 / 胸部 / 腿部 / 脚部 / 手部 / 背包（背包=网格尺寸）。

### 7.3 词缀与品质（保留的奇幻遗产，改造复用）
- 装备稀有度 6 档：普通/优秀/稀有/史诗/英雄/传奇（品质工具复用）。
- 随机词条（词缀）：攻击/防御/生命/抗性/暴击/命中/闪避/速度/负重/潜行（魔攻删）。
- 掉落装备按品质取池生成 1-N 条词缀；词缀数值随档存档。
- **删除**：附魔（魔法灵光）、镶缀（宝石）、合成（两件合品质）——末日装备只靠掉落与工作台维修/重铸。

## 8. 交易（以物易物，无货币）

- 每件物品有 **价值（1~100）**（替代金币，保留 价格 字段仅作兼容）。
- **交易额度**（会话内）：本次与交易对象可支配的价值上限；出售按背包总价值抵扣。
- 购买 = 消耗额度换物品；卖出 = 物品按价值折算进额度；额度不足时用最高价值物品抵扣。
- 黑市/交易站/幸存者 各有不同价值系数（稀有度溢价/压价）。

## 9. 探索（地点搜索）

- 地点（超市/医院/警局/居民楼/加油站/药店…）各有：危险等级 / 资源等级 / 层深结构 / 搜空标记。
- **搜索**：耗行动点 10（酷暑/沙暴 +5）→ 抽事件（物资/丧尸/幸存者/陷阱/无事）。
- **天气影响**：雨=噪音降低遇敌减少；雾=潜行加成；沙暴=搜索效率↓受伤↑；酷暑=行动点消耗↑；寒潮=感冒风险↑。
- **潜行**：`潜行值 ≥ 15` 或 雾/雨 天气可触发「偷袭」（战斗先手 / 绕开）。
- **搜空与再刷**：地点搜空后标记（已清空地点），随尸潮推进可能"再刷危险物资"。
- **深度结构**：沿用分层状态机（入口层→深处层→Boss 层），数据从 区域.json 换为 地点.json。

## 10. 时间与天气

- 1 现实秒 = 2 游戏分钟；游戏从第 1 天 6:00 开始。
- 每小时结算：饱食/水分下降、伤病恶化/恢复、行动点相关；跨天随机天气（晴/雨/雾/雷雨/寒潮/沙暴/酷暑 7 种）。
- 夜晚（20:00–6:00）：探索更危险（视野差/夜袭），夜行天赋可减消耗；睡觉跳过夜晚。

## 11. 安全屋（营地）

- **返回营地 = 睡觉**：恢复生命/行动点/疲劳，推进到次日 6:00。
- 安全屋等级 1~3，解锁/升级**家具**：床（恢复）、储物柜（仓库扩容）、工作台（制作/维修）、火炉（取暖/烹饪）、种植箱（食物再生）、凝水器（水分再生）、加固栅栏（夜袭防御）、医疗台（治疗伤病）。
- 营地设施（复用设施体系）：制作台 / 交易站 / 委托板 / 仓库 / 医疗 / 收音机（短波广播=主线线索与结局锚点）。

## 14. 成长

- 等级：经验 → 升级 +3 自由点 + 生命上限 +5。

## 15. 结局与难度曲线

- **第 87 天救援广播**：达成条件（可选：无线电修复 + 城市地标信号 + 幸存者支持 ≥ N）→ 结局 A 撤离；尸潮吞城 → 结局 B（默认未达成）。
- 资源曲线：城市总物资按 搜索量 衰减（已清空地点数）；尸潮每 7 天推进一级（夜间袭击概率↑、郊区地点危险度↑、市中心封锁）。
- 无硬倒计时压力：87 天是叙事锚点，玩家可以活过 87 天（广播后仍有"留在废土"的继续模式，待定）。

```
表现层（UI 面板，场景手动搭建） ←事件→ 应用层（Services，显式 DI） ←→ 领域层（纯 C# 档案） ←→ 数据层（Resources/Data/*.json）
```
- 事件总线 EventBus（类型化事件）；ServiceRegistry 显式注册；GameBootstrap 组合根（-100 执行序，幂等，数据校验失败阻止进入）。
- 数据驱动：全部内容 JSON + 启动跨引用校验（缺失/断裂引用列清单阻止启动）。
- UI 规约：按钮 Awake 绑定一次（禁 RemoveAllListeners，保音效）；刷新只改文本/显隐/缩放；无 DOTween。
