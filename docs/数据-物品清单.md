> 生成方式：脚本从 `Assets/Resources/Data/物品/**` 现读现算，**不改任何数据**。
> 用途：物品的「现状底表」—— 每行都带**关键数值 + 来源通路 + 问题标记**。

## 一 口径与不变量

### 1.1 来源口径（只管这 8 类）

**来源只算**：搜刮／配方产物／掉落／职业初始／**钥匙投放**（门锁钥匙由 `房间探索服务.钥匙投放` 塞进本房容器或敌人身上）／技能消耗／种植成熟／腐坏产出。

**★ 不算来源的**：
- `配方材料`、`家具建造·升级材料` —— 它们都是**消费方**（把配方材料当来源曾把 `鸡蛋` 误判可达；把家具材料当来源曾漏掉 `医药箱` 零来源）。
- `种子自身` —— 它要自己另有来源，**成熟产物**才算可达。

**验收口径**：**「零来源 = 0」且「无用途 = 0」**，两个数都由脚本现算，并进 `Tools/数据引用核对.ps1` 的 `[物品用途]` 一节**一票否决**。

### 1.3 设计原则（不变量）

1. **每件物品至少一条消费方**：直接使用 / 配方材料 / 家具建造·升级材料；做不到就**删掉**，不挂着当垃圾。
2. **梯度必须单调**：品质↑数值↑；敌人等级↑威胁↑；天赋点数↑强度↑；家具等级↑效果↑。
3. **取舍优于堆数值**：用负值制造选择（重甲潜行↓、消音器攻击↓潜行↑）。
4. **末日口径**：干燥/罐头/密封不腐坏、现做熟食短保；军用/警用/消防/战术款只能搜刮，低级基础款能自制。
5. **不发明机制之外的数据**：没系统的功能只用现成机制（家具材料/配方/区域解锁）承接。

**用途封口**（每件物品四选一）：① 能直接用（武器/防具/配件/饮食/医疗/弹药/容器/书籍）· ② 是配方材料 ·
③ 是家具建造/升级材料 · ④ **交易预留**（`种类=贵重物品` 走白名单，见 §1.4）。

### 1.4 奢侈品 = 交易硬通货

`贵重物品` 8 件（金币 · 金表 · 金项链 · 银戒指 · 钻戒 · 玉镯 · 珠宝项链 · 古董怀表）**不是生产资料，是商品** ——
用途是等交易/以物易物系统上线后当硬通货。

- **不进任何配方**、**不进任何家具建造/升级材料**；`价值` 就是它的用途（15~40，材料类最高）。
- 门禁给 `种类 = 贵重物品` 开**交易预留白名单**（不报缺口），但**同时硬校验它不许出现在任何
  `配方.材料` / `家具.材料` / `家具.升级[].材料` 里**。

### 1.5 品质与命名

`品质工具.倍率()` = 普通 1.0 / 优秀 1.2 / 稀有 1.5 / 史诗 1.8 / 英雄 2.2 / 传奇 3.0，该倍率**真的参与计算**（物品恢复量、技能伤害）。

> **命名口径**：装备的随机**词缀**系统早已按拍板删除；现在装在装备配件槽上的是**配件 / 改装件**（见 §2.3）。
> 其它文档若出现「词缀」指装备随机词缀的，一律按**配件/改装件**理解（`敌人特性` 的 Tier 1/Tier 2 是另一回事）。
