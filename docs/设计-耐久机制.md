# 设计 · 武器/防具耐久机制

> 实现进度：**数据层 + 初始化 + 攻防归零 + 换装卸下透传 + 背包/详情显示 + 战斗消耗** 已完成；**工作台修复** 待接。

## 一、数据层

| 字段 | 位置 | 说明 |
|------|------|------|
| `最大耐久` | items.json（`物品数据`） | 模板上限；0 = 无耐久（食物/材料等）。武器/防具配置 |
| `当前耐久` | `物品堆叠`（背包实例）/ `装备记录`（已装备实例） | 当前值，随档存档；<=0 = 损坏 |
| `有效最大耐久(标识)` | `玩家档案` | 优先取配置；缺省给"有攻击/防御加成"的装备默认 15 |

## 二、初始化

- 装备**获得**时（掉落/制作/合成）`物品堆叠.当前耐久 = 有效最大耐久`。
- 装备**到槽**（换装/职业初始）自动初始化（`装备到槽` 透传当前耐久，缺省则用模板）。
- **换装/卸下**：实例耐久在 背包堆叠 ↔ 装备记录 间透传（不丢失已损耗值）。
- **读档兼容**：旧存档无耐久字段（当前耐久=0），`清理非法值` 将"有最大耐久却 0"视为全新回满，避免全部损坏。

## 三、消耗（战斗）

`BattleService.造成伤害` 命中后（非真实伤害）：
- 玩家出手（`攻击者.是否我方`）→ 当前武器 `当前耐久 -1`
- 玩家被击中（`目标.是否我方`）→ 胸部防具 `当前耐久 -1`

## 四、归零失效

`装备数值` / `词缀总值` 遍历已装备时，若 `有效最大耐久>0 && 当前耐久<=0` → **该项加成与词缀不计**。因此：
- 武器损坏 → `近战伤害`/`枪械伤害` 归 0（仅剩力量基础）
- 防具损坏 → `总防御` 归 0（仅剩体质/2）
- 判定方法：`装备已损坏(槽位)`、`装备当前耐久(槽位)`

## 五、显示

- 网格背包物品格：底部小字 `当前/最大`，损坏显示红色"损坏"。
- 详情面板：`耐 当前/最大`。
