# 文字奇幻RPG（灰烬镇 · 余烬传说）

借鉴《小黑屋》(A Dark Room) 的**极简文字风格与渐进式叙事**，做的经典剑与魔法题材**探索向文字 RPG**。
Unity 6（URP 2D），全部 UI 运行时动态构建，内容数据 JSON 驱动，**全项目中文编码风格**（类/方法/字段/参数/注释/数据键名均为中文）。

## 如何运行

1. 用 Unity 6000.4.8f1 打开本项目（首次打开等待导入完成）。
2. 打开场景 `Assets/Scenes/SampleScene.unity`。
3. （推荐）菜单栏 **奇幻RPG → 导入中文字体**：从系统字体（微软雅黑）生成项目内 TMP 字体资产，中文显示最稳定。
4. 菜单栏 **奇幻RPG → 一键搭建场景**（自动创建游戏管理器，无需手动搭 UI）。
5. 按 Play。

> 提示：`一键搭建场景` 只会在场景里放一个 `游戏管理器` 物体，全部 UI 由代码在运行时生成。
>
> 字体兜底：即使未导入中文字体、也未导入 TMP Essential Resources，游戏仍会在运行时从系统字体（微软雅黑等）动态创建字体，保证中文可显示（不崩溃）。

### 常见问题

- **Play 时报 `NullReferenceException`（`TMP_Settings.get_defaultFontAsset`）**：这是 TMP Essential Resources 未导入导致的。本项目已做运行时兜底（系统字体），无需处理；若仍想导入，菜单 `Window > Text Mesh Pro > Import TMP Essential Resources` 即可。

## 界面布局

```
┌──────────────┬───────────────────────────────────┐
│   —— 日志 ——  │  标题（金色）                        │
│   （左栏）     │  正文滚动区（打字机效果）              │
│               │                                   │
│  系统信息 灰    │  ┌───────────────────────────┐    │
│  剧情正文 白    │  │  选项按钮 / 战斗行动按钮     │    │
│  玩家操作 金    │  └───────────────────────────┘    │
│  正面反馈 绿    │  状态栏（生命/攻击/防御/金币/背包）   │
│  负面反馈 红    │                                   │
│  内心活动 斜紫  │                                   │
└──────────────┴───────────────────────────────────┘
```

- **左侧日志栏**：小黑屋式的信息流水，按类型上色，自动滚动，可回看全部历史。
  - `[系统]`（灰）：存档、流程切换；`→ `（金）：玩家操作；`（内心）`（斜体淡紫）：角色内心活动；剧情正文白色；正面反馈绿色；负面反馈红色。
- **右侧主区**：当前场景正文（打字机逐字显示，点击可跳过）+ 选项按钮 + 底部状态栏。
- **中文字体**：运行时优先加载项目字体，否则从操作系统字体（微软雅黑等）动态创建 TMP 字体资产，保证中文正常显示。

## 当前可玩内容（垂直切片）

- **序章**：石屋醒来 → 查看四周 / 包扎伤口 / 休息 → 遭遇巨鼠（首场战斗）→ 探索灰烬镇废墟 → 酒馆接悬赏 → 讨伐哥布林营地 → 发现「黑石山 · 龙巢」羊皮纸线索。
- **区域探索**：从镇外路牌进入**橡木林**，反复「深入探索」随机触发——遭遇敌人（灰狼/哥布林）、发现地点（废弃猎屋/精灵泉水）、获得资源（金币/药水）、或无事发生；战斗中可逃跑，随时可返回。
- **战斗**：回合制（攻击 / 使用消耗品 / 逃跑），伤害公式 `max(1, 攻击 - 防御/2 + 随机(-1..1))`。
- **成长**：经验升级（生命/攻击/防御成长）、金币、背包。
- **存档**：任意时刻可保存（PlayerPrefs JSON），主菜单可继续冒险。

      剧情引擎.cs        # 文字事件引擎：节点推进 + 选项分支 + 效果
      战斗系统.cs        # 回合制战斗

## 剧情数据格式（story.json）

节点结构（键名全中文）：

```json
{
  "标识": "节点id",
  "文本": "剧情文字（\\n 换行，支持 <color=#hex> 富文本）",
  "效果": { "生命": 5, "金币": 2, "经验": 10, "获得物品": "id", "失去物品": "id" },
  "战斗": "战斗:敌人标识:胜利节点标识",   // 可选：进入即强制战斗
  "选项": [
    { "文本": "选项文字", "目标": "节点id", "效果": {...}, "需要物品": "id" }
  ]
}
```

- `目标` 特殊值：`__结束`（结束）、`战斗:敌人标识:胜利节点标识`（战斗）、`探索:区域标识:返回节点标识`（进入区域探索）、`区域:区域标识`（从地点返回区域）。
- 选项的 `需要物品` 满足才显示（条件分支）。
- 添加新剧情 = 往 JSON 加节点，无需改代码。

## 区域数据格式（regions.json）

```json
{
  "标识": "橡木林",
  "名称": "橡木林",
  "描述": "进入区域时显示的描述",
  "危险度": 1,
  "遭遇": [ { "敌人": "灰狼", "权重": 3 } ],
  "发现": [ { "节点": "地点_废弃猎屋", "权重": 1 } ],
  "资源": [ { "效果": { "金币": 4 }, "文本": "找到了铜币", "权重": 2 } ],
  "无事文本": [ "什么也没发现。" ]
}
```

探索时按权重随机抽取事件：遭遇（进入战斗，胜利/逃跑后回到区域）、发现（进入地点剧情节点，节点选项可用 `区域:标识` 返回）、资源（应用效果+文本）、无事。

## 编码风格约定

- **全中文标识符**：类、方法、字段、参数、局部变量、注释全部中文；Unity 生命周期（`Awake`/`Start`/`Update`）与框架 API 保持英文（语言约束）。
- **不使用 `_` 前缀**：私有字段直接用中文命名（如 `管理器`、`当前节点`），不加下划线。
- 数据键名（JSON）与代码字段名一致，均为中文。
- 命名空间：`奇幻文字RPG`。
