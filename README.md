# 《最后87天》— 末日文字丧尸生存 RPG

> 城市陷落后的第 87 天。水与电早已消失，街上只剩丧尸与废墟。你是安全屋最后醒着的人——活下去，是唯一的任务。

Unity 6（6000.4.8f1）｜ 塔科夫式网格背包 ｜ 即时制战斗 ｜ 全 JSON 数据驱动 ｜ **全项目中文编码**（类/方法/字段/参数/注释/数据键名均为中文）

借鉴《小黑屋》(A Dark Room) 的极简文字节奏与渐进式生存压力，题材为**现代末日丧尸求生**：以「营地建设 + 时间管理 + 外出搜刮 + 即时战斗」为闭环的文字生存游戏。

---

## 核心玩法

- **87 天期限（时间压力）**：`1 现实分钟 = 30 游戏分钟`，一天 = 48 现实分钟。搜刮、制作、睡觉都会推进时间——食物会腐坏、作物会生长、净水器会产水，你与丧尸都在和时钟赛跑。
- **生存循环**：生命 / 精力 / 饱食 / 水分 / 疲劳 / 伤病 / 天气。每游戏时基础消耗饱食与水分；睡觉推进次日；寒潮需灶台取暖，伤病持续恶化。
- **塔科夫式网格背包**：弹挂 / 腰封 / 背包 3 个穿戴容器 + 仓库 + 任意嵌套容器；物品按「形状块」占格，可**拖拽 / R 旋转 / 换位 / 堆叠 / 存入容器**，带格子投影逐格贴合口袋形状。
- **安全屋建设**：程序化随机户型；家具建造 / 升级 / 修复 / 拆除（储物箱 10×20→10×50、净水器 3 分区升级、冰箱保鲜倍率、种植箱种菜、灶台做饭、工作台/医疗站制作）。
- **时间驱动的世界**：生鲜按游戏时间**腐坏**（冰箱减速）、种子在种植箱**生长**、净水器每 60 游戏分钟自动产水——全部挂 `世界时间管理器`（推进/跳时两条时间流），全程无需手动按钮。
- **外出搜刮**：区域探索 → 地图搜索（箱中箱；冰箱/抽屉柜等家具容器各有产出），有战斗有物资。
- **即时制战斗**（v44/v45 重建）：行动条由世界时间驱动速度填充，满条自动执行「运动模式（前进/等待/后退）+ 行动模式（攻击/防御）」；主动操作（6 技能槽冷却 / 弹挂腰封道具 / 切武器）可即时打断重置行动条；**节点式轨道**贴脸/射程/风筝走位。
- **日志系统**：左下角 8 类彩色徽章消息流（探索/战斗/生存/获得/警告/系统/内心/角色），空日志自动隐藏；物品名按品质着色。
- **数据驱动**：全部内容（物品 261 件 / 配方 33 条 / 家具 11 种 / 敌人 / 技能 / 天赋 / 剧情 / 地图…）均为 `Resources/Data` 下 JSON，改数据不改代码。

## 如何运行

1. 用 **Unity 6000.4.8f1**（Unity 6 LTS 系）打开本项目，首次打开等待导入完成。
2. 打开场景 `Assets/Scenes/SampleScene.unity`。
3. 直接按 **Play**。

> 无需任何一键搭建：UI 已按「场景手动搭建 + `[SerializeField]` 引用位」接好；TMP Essential Resources 与中文字体（Silver SDF 等）均已入库，开箱即用。

## 架构

```
Assets/Scripts/
├── Core/        组合根：GameBootstrap 装配根、ServiceRegistry、EventBus
├── Data/        数据模型 + DataService（Resources.Load + 交叉校验）
├── Domain/      纯 C# 领域逻辑（玩家档案/生存/网格/容器/持有/装备/战斗单位…）
├── Services/    业务服务（世界时间/制作/安全屋/探索/搜索/战斗/书籍/天赋/技能…）
├── Events/      事件定义（剧情/导航/战斗/探索…）
├── UI/          面板层（场景手动搭建 + 引用位：背包网格/浮动面板/HUD/战斗轨道…）
└── Editor/      地图设计器（编辑器扩展）
```

- **四层数据流**：`UI ← Events ← Services ← Domain ← Data`；一切修改走 `玩家档案` → 发布 EventBus → UI 订阅刷新。
- **装配顺序**（GameBootstrap）：EventBus → DataService(校验) → SaveService → PlayerService → 世界时间管理器 → 各服务 → 自动存档器 → 挂载时间驱动。
- **硬约定**：任何推进时间必须走 `世界时间管理器`；动态面板销毁必须 `OnDestroy` 退订 EventBus。

## 编码与协作约定

- **全中文标识符**：类、方法、字段、参数、注释、JSON 键名全中文；仅 Unity 生命周期与框架 API 保留英文。
- **编码**：JSON / C# 一律 UTF-8 无 BOM；pwsh 读写中文需显式编码。
- 场景 UI 手动搭建 + 引用位；浮动面板宽高以预制体为准，代码不覆盖。
- 改数据前查「标识 → 配方/图标/引用」联动；json+meta 成对（GUID 固定）。
