> 项目：《最后87天》 ｜ 文档：世界沙盒 垂直切片（1 地区街道网格 + 多栋楼逐层房间）
> 状态：代码与数据已落地并通过离线验证；**待 Unity 场景接线**（见第四节）
> 上游设计：《世界沙盒设计报告.md》——本切片是它的收敛版第一刀，只做「能走、能看、能搜、能打、能撤」

| 做了 | 没做（留给后续刀） |
|---|---|
| 1 个地区街道网格（程序化：建筑门面 + 门 + 搜索点 + 敌人 + 障碍 + 出口） | 世界层（地区节点图）——**按你的决定搁置**，后续单独设计 |

| 上下层楼梯对齐 + 整栋楼同一 footprint（真实楼房的上下对齐） | 一栋楼多入口/后门、窗户 |

## 三、定版规则（常量都在 `探索沙盒服务` 顶部）

| 规则 | 值 | 备注 |
|---|---|---|
| 时间片 | 走 1 格 = **2 游戏分钟** | 探索期间挂机驱动暂停，时间由时间片统一推进（走 `世界时间管理器.推进`，整点结算/生长/净化 照常） |
| 移动行动点 | 1 / 格 | 回程越远越贵（贪心惩罚的第一颗牙） |
| 搜刮 | 10 行动点 + 5 游戏分钟 | 行动点不足则搜不动 |
| 视野 | 半径 5 格 + Bresenham 视线 | 墙/建筑体挡视线，**关着的门也挡**（推开门才看得见门后）；障碍不挡（掩体感） |
| 迷雾 | 未探索 / 已探索（记忆）/ 可见 | 地形与物件（门/容器/楼门/楼梯/尸体）进记忆；**敌人只在可见时显示** |
| 遭遇 | 走到敌人**相邻格**触发 | 移动前已看见该敌人 → 我方先手（偷袭）；贴脸撞见 → 速度序；逃跑过的敌人再遇 → 敌方先手 |
| 战利品 | 胜利 → 该格清空 + **原地留尸体容器**（占格，点它搜） | 失败/逃跑 → 敌人留在原地（逃跑的还会警觉） |
| 撤出 | 站在街道出口格按「撤离」 | 清空容器/已搜索/尸体/迷雾 → 回安全屋；**不调用 `地图服务.返回营地`**（那条会直接睡觉回满，抹平张力） |
| 容器实例 id | `地区#建筑#F层#房间#容器` | 确定性派生、跨会话稳定；**绝不能**拿容器定义标识当实例键 |
| 楼层 | 整栋楼**同一 footprint**，房间划分逐层独立 | 上楼不会"换一栋楼"；1F 有出口门，上层没有 |
| 楼梯 | 每层同一格（对齐 1F） | 上下是同一根楼梯；放不下就换一次布局重来 |

### 点击交互：点世界物件 → 弹右键小菜单

**没有按钮栏**（搜刮/进入/离开/上楼/下楼/撤离 六个按钮已删除）。点世界里的物件，弹出小菜单，菜单里只列**这一格当前能做的事**；点菜单条目才执行。

**菜单统一用场景里那一个 `右键菜单`**（和背包/装备/家具右键用的是同一个组件、同一套置顶/定位/取消规则），条目**全部按需实例化**（`右键菜单.显示动作(条目, 框)`，无标题）。
沙盒面板自己不再建菜单，只负责把"这格能干什么"交给它 —— 规则在服务层（`目标动作` / `执行动作`），UI 只列条目。

| 点什么 | 小菜单里出现 | 结果 |
|---|---|---|
| 相邻的**门**（关着） | 推开 | 推开（此后可通行、视线打通） |
| 自己脚下的**门**（开着） | 带上 | 关门（**关着的门挡视线**——做巡逻 AI 后就是战术动作） |
| 相邻的**楼梯** | 上楼 / 下楼（有几层就给几条） | 切层，不必先站上去 |
| 自己脚下的**楼梯** | 上楼 / 下楼 | 反向切层 |
| 相邻/脚下的**楼门**（街上那扇） | 进去 | 进屋，落在 1F 门口内侧 |
| 相邻/脚下的**出口门**（楼里那扇） | 出来 | 出楼，回到街上楼门旁边 |
| 相邻的**家具/尸体** | 搜刮 | 打开搜索面板（家具占格，人站不进去） |
| 自己脚下的**撤离点** | 撤离 | 回安全屋 |
| 其它相邻可通行格 | 走过去 | 走一步（关门/家具/墙 会拦住并给提示） |
| 不相邻的格 | ——（给提示"一次只能点相邻的一格"） | 不弹菜单 |

实现分工：`探索沙盒服务.目标动作(列,行)` 判定"这格能干什么"（含可用性），`执行动作(动作id,列,行)` 执行；面板只负责把条目交给 `右键菜单`。
所以**规则永远在服务层**，UI 换皮不用碰玩法。

菜单取消规则由 `右键菜单` 统一管：点菜单外、滚轮、Esc（回退）、或地图刷新（走一步/开关门/切层）都会收起。
**没挂 `右键菜单` 也能玩**：退化为"点一下直接执行首选动作"。

### 生成器不变量（离线验证器与 Unity 自检都在查）

1. 同种子两次生成 → 结构一致（确定性）；
2. 街道出生点 = 出口格且可通行；建筑入口（**真门**）/搜索点 从出生点可达；
3. 每层出生点可通行；每层所有对象（容器/敌人/楼梯/门）从出生点可达（不会被墙围死）；
4. 楼层外墙圈除门洞外全为墙；多层楼每层都有楼梯，且**上下层楼梯在同一格**；每层至少一扇门；
5. 容器实例 id / 楼梯组 不缺失；**家具不得堵路**（把家具当阻挡后，门/楼梯/楼门仍可达，且每件家具旁有落脚点——不满足就撤掉那件家具重算）；
6. 整栋楼各层同 footprint；1F 有出口门、上层没有。

最近一次验证结果：

| 验证 | 结果 |
|---|---|
| ① 离线生成器（`Tools/沙盒验证`，400 种子） | **0 失败、0 兜底**；平均每层 62.7 格可走面、2.9 件容器 |
| ② 引擎内结构自检（2 地区 × 60 种子） | **0 失败**；120 次生成、629 楼层、1961 个容器实例；数据校验 0 错误 |
| ③ 运行期端到端冒烟 | **65 项断言全通过**：进区/视野/移动扣点 → 点家具·菜单「搜刮」（实例 id 链路、首开生成、二次一致）→ 点楼门·菜单「进入」→ 点房门·菜单「开门/关门」（关门挡路且挡视线）→ 点楼梯·菜单「上楼/下楼」→ 点出口门·菜单「离开」→ 点撤离点·菜单「撤离」（且不触发睡觉）→ 遭遇开战（棋盘按场景传入）→ 胜利清格 → 同种子重建一致 |

## 四、Unity 场景接线清单（需要手动做）

1. **建面板物体**：在场景里与其它面板同级新建 `世界沙盒面板`（默认放到非激活状态也行，面板管理器会管），挂 `探索网格面板` 组件。
2. **子物体**：`网格容器`（RectTransform，格子父级；尺寸会被代码写成 `列×行×格尺寸`，建议给它一个固定大小的父级视口）+ `信息条`、`提示`（两个 TMP_Text）。**不需要任何按钮**。
3. **引用位**：只需 `网格容器` / `信息条` / `提示` 三个。
4. **右键菜单（统一那一个，改一次全家受益）**：
   - 删掉 `菜单根` 底下那 **8 个 Button**（旧的使用/装备/打开/拆分/分解/丢弃/详情/家具升级/家具拆除），只留 `背景框`（可留着，代码会给它 `ignoreLayout`，不参与条目排布）；
   - 接上 `菜单按钮预制体`：一个"一行按钮"的预制体（内含 Button + TMP_Text 即可）。不接也能跑（回退共享按钮预制体 → 代码兜底建行）；
   - `菜单列表` 可留空（代码会用 `菜单根` 自身并自动补 `VerticalLayoutGroup` + `ContentSizeFitter`）；
   - **菜单不显示标题**（只有条目）。
5. **面板管理器**：把沙盒面板拖进「世界沙盒」引用位。
6. **营地面板**：撤离会发 `打开营地事件`——请确认面板管理器的「营地」引用位已接（安全屋面板），否则撤离后没有下一屏。
7. 进游戏 → 快速测试面板 → 「世界沙盒」分区 → 进入老城区。

调参建议：`格尺寸` 44、`格间距` 2、`铺满容器` 勾上（按容器实际大小自适应）。

## 五、已知取舍与未做（有意留白，不是漏）

1. **敌人不会自己走**：本刀只做「相邻触发」。`enemies.json` 的 `移动间隔秒` 已在手，巡逻/追击是第 2 刀的核心增量（做好之后「关门挡视线」才真正有战术价值）。
2. **门能开能关，但还不能撬**：破门耗时/噪音/需要撬棍（物品已在战利品表里）留到第 2 刀；上锁的门也没有。
3. **光照未接**：夜晚/断电压低视野半径 + 手电/火柴/电池，是性价比最高的一条，留第 2 刀。
4. **负重/回程成本未接**：目前只有行动点。塔科夫 loop 的牙齿（负重 → 移速/时间片、回程越贵、搜刮噪音）留第 2 刀。
5. **结构不存档**：只存 `世界种子 + 生成器版本`；生成算法一改，同种子展开的世界会变——所以**任何会改变「种子→结构」映射的改动都必须把 `沙盒种子.生成器版本` +1**（读档时的行为：明确重掷，不做静默重建）。
6. **搜索的"黑布倒计时"仍是现实秒**，没有吃时间片；等巡逻 AI 落地后一起改（否则时间片与搜索时长的关系说不清）。
7. **旧文本闯关式 `探索服务` 保留未动**（`regions.json` 一直没数据，实际处于休眠）。世界层定型后再决定它的去留。
